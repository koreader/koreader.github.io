2 基本用法
2.1 傳輸檔案

KOReader 支援 PDF/PDB/XPS，EPUB/MOBI/FB2，DJVU，CBR/CBT/CBZ，DOCX/RTF，HTML/HTMLZ，TXT/MD 和 CHM 等格式的檔案，還可開啟 ZIP 壓縮檔並顯示圖片檔案。

有許多方法可以將書籍傳輸到閱讀裝置。請注意，KOReader 可能需要重啟（如果是在 Pocketbook/Android 上則是重新整理目錄）以完成對新傳輸檔案的索引。

除了以與內建閱讀器應用程式相同的方式傳輸檔案外，根據你的裝置不同，還有其他選項可供選擇：

  1. KOReader 內建的 USB 大容量儲存模式：KOBO 及部分 CERVANTES 型號支援該功能。
  2. 雲端儲存（Dropbox/FTP/Webdav）：使用該功能前，須透過下方展示的選單項登入雲服務帳號。詳細操作步驟可在新增帳號時點擊選單中的說明按鈕檢視：
    （檔案瀏覽器中的）頂部選單 / / 雲端儲存
  3. SSH/SFTP 存取：KOReader 可作為 SSH 伺服器，以便使用電腦傳輸文件（該功能支援 Kobo、Kindle、Cervantes 的閱讀器）請使用 SFTP 軟體（如 Filezilla）或檔案瀏覽器（部分作業系統內建）請查閱維基頁面瞭解具體操作流程；另請注意下方的警告註釋欄內容。
  4. Calibre 傳輸：藉助 Calibre 外掛，可透過 Wi-Fi 直接從 Calibre 書庫將書籍傳送到 KOReader 中。請查閱維基頁面瞭解操作方法。
  5. 新聞下載器：該外掛可以 HTML 格式下載 RSS 及 Atom 訂閱源提供的文章。請查閱維基頁面瞭解操作方法。
  6. OPDS（開放出版發行系統）書目：你可以存取公共書目，或使用自己的伺服器存取書庫。更多資訊見 使用 OPDS 書目
  7. Wallabag：此外掛可以從 Wallabag 中拉取文章，這是一款自託管的類 Pocket 稍後閱讀軟體。請查閱維基頁面瞭解更多資訊。
 在不設定密碼的情況下使用 SSH 功能應當額外謹慎，因為這將使閱讀裝置可被公開存取。不過如果只是臨時開啟裝置 Wi-Fi 且接入的是家庭 Wi-Fi 網路，這個風險是可以忽略的。

  • 最愛 - 由使用者選定書籍組成的清單，可在檔案瀏覽器中長按書籍新增
  • 歷史記錄 - 曾經開啟過的書
  • 收藏清單 - 由使用者自行建立的書籍清單。請點擊收藏清單詳細瞭解

閱讀模式：切換到頁面連續模式，可以像瀏覽網頁一樣滑動閱讀書籍。該模式更適合配備非電子墨水螢幕（LCD、OLED）的閱讀裝置。在頁面連續模式下，頁面的頂部和底部頁邊空白將被裁切，因此首行和末行文字可能會被裁掉。啟用頁面重疊可以避免這一問題：

頂部選單 / / 頁面重疊

渲染模式：該選項決定 KOReader 如何呈現頁面。預設設定為網頁且通常無需改變。當某本書籍（或快取的網頁）使用了複雜排版（指定了頁面寬度或頁邊距，使用了負邊距或浮動元素等），版式出現錯亂或內容超出螢幕時可嘗試其他渲染模式。

縮放（dpi）：該選項可視為文件全域縮放比例（不會影響字型大小）。在預設設定 96 dpi 下，書籍中的圖片將以原始尺寸呈現。簡單來說該選項可以在放大圖片的同時保持文字大小不變。

文字間距和文字擴展這兩項設定彼此關聯，共同決定文字在兩端對齊時的樣子。文字兩端對齊時，詞與詞之間的空白會被加大，使每行文字的左右邊緣都與頁邊距對齊。由於每行的字數並不總是相同，兩端對齊時文字需要被壓縮或拉伸以填滿一行。

文字間距：為容納更多文字，一行文字中的空白允許被壓縮的程度。該選項不會影響文字，只會改變文字的間隔。

文字擴展：當一行文字中有太多空白時，將這些空白分拆到字母之間而使單詞被拉伸的程度。該選項將影響單詞的樣式。若不希望單詞被拉伸，請將該選項設定為無。

請自行探索各種選項組合，讓文字呈現自己喜歡的樣式，然後在各選項對話方塊中將所選設定儲存為預設值。

對比度和字重影響文字筆畫濃淡。這兩個選項都可以讓文字呈現某種樣式，但它們的技術原理不同。當然，這兩項可以同時生效。

兩個選項間的區別可以這樣概括：

對比度

+ 不改變字型寬度，不影響書籍總頁數

+ 無需重新繪製書籍，調整速度快

- 在 LCD 或低 DPI 螢幕上可能影響觀感

字重

+ 如果已安裝，將使用適當字重的字型

+ 在 LCD 和低 DPI 螢幕上觀感更佳

- 需要重新渲染字型，調整速度慢

字距微調是調節特定字母組合之間的間距以提升視覺效果的功能。預設的最佳選項可能會拖慢書籍開啟速度（受閱讀裝置效能影響），但對連字（如下圖所示）、連筆阿拉伯字形及某些書體的支援更好。若閱讀裝置效能較差可將改為較好選項，在保證拉丁字母書體正確顯示的前提下提升裝置響應速度。

字型微調是一種排版技術，透過調整字型中的字形來適配低解析度的像素網格（例如電子墨水螢幕）。啟用後字形會更清晰、更易辨認，代價是原始字型設計會略微變形。

字型微調的差異在標準解析度螢幕上或使用較小字型大小時更明顯。在解析度非常高的螢幕上，由於像素足夠小，差異要小得多。

下面是更詳細的對比：

關閉字型微調

  • KOReader 按字型真實的數學輪廓顯示字形，不強制它對齊到像素網格。

開啟字型微調

  • 字型會被調整以適配螢幕的像素網格，字形可能與原始字型略有差異。
  • 字型可能顯得略微柔和、模糊或不夠均勻（例如字母「M」的兩條豎線看起來粗細不一）。
  • 字型顯得更清晰、更銳利、更紮實，各字母的筆畫粗細一致。

在 KOReader 中，字型微調預設啟用，並使用 FreeType 庫的微調演算法，而非字型內建的指令（出於穩妥考慮，字型內建指令可能存在缺陷）。不過也可以改用字型設計師嵌入字型檔案中的指令，看看效果是否更好：

  1. 關閉 已停用字型微調。
  2. 原生 KOReader 使用字型內建的微調指令。
  3. 自動（預設開啟）KOReader 使用 FreeType 的微調演算法，忽略字型內建的微調指令，對中日韓文字的處理更好。

4.5 頁碼編號

KOReader 狀態列中的頁碼會因文件類型而異；有些是固定的，另一些則會動態調整。下圖概覽了 KOReader 的頁碼編排體系。閱讀本節時，可隨時回看這張圖表。

如圖所示，KOReader 能夠開啟的文件可分為以下兩類，下文將分別說明：

固定版式文件

PDF, DjVu and CBR/CBZ 都屬於這類文件。這類文件又稱不可重排文件，其版式是靜態的。這意味著頁面上的每個元素（文字與圖片）都有精確定位，無論在大屏還是小屏裝置上閱讀，位置都不會改變。您所看到的版式始終與印刷頁面完全一致。

固定版式文件只有靜態頁碼。在 KOReader 中開啟這類文件時，狀態列中看到的頁碼屬於文件本身。靜態頁碼不會隨閱讀裝置的類型或螢幕尺寸而改變。

可重排文件

EPUB、MOBI、AZW、HTML 都屬於這類文件。這類文件的版式並不固定。也就是說，文字及其他內容會自行調整（重排），以適配您閱讀文件時所用螢幕或視窗的大小。

可以把這類文件想像成很長的純文字檔案或網頁，它們本身自然沒有分頁。開啟這類文件時，KOReader 會在首次開啟時把這份長文件切分為螢幕大小的頁來計算頁碼。因此，若在 10 英寸閱讀器上開啟文件，書的總頁數會少於 6 英寸閱讀器，因為更大的螢幕單頁能容納更多文字（每頁字數越多 = 總頁數越少）。

這也意味著，如果您改動文字外觀，例如把字型調大，頁碼也會隨之變化。因為字型大小變大後，螢幕能容納的文字變少，總頁數就會增加。

固定頁碼

由於頁碼會不斷變化，可重排文件的頁碼並不太適合用作引用參照。如果您同時在電子書閱讀器和電腦上開啟某個 PDF 檔案（固定版式文件），第 42 頁在兩臺裝置上顯示的內容始終相同。但對 EPUB 檔案而言，一臺裝置上的第 42 頁與另一臺並不相同。

此時您可能會問：「像 EPUB 這樣的可重排文件，能不能擁有固定不變的頁碼？」可以，藉助 固定頁碼功能即可實現。KOReader 提供兩種固定頁碼：


- 出版商頁碼：

KOReader 支援出版商頁碼功能，出版商可利用該功能把印刷版書籍的頁碼直接嵌入電子版中。啟用該功能後，KOReader 不會自行計算頁碼，而是顯示出版商提供的內嵌頁碼。這樣一來，您在狀態列中看到的頁碼便與印刷版一致。

若要啟用該功能，請按照下列路徑操作：

頂部選單 / / 設定 / 固定頁碼 / 使用固定頁碼

如果同時勾選了該選單中的在邊緣顯示固定頁碼選項，這些出版商頁碼將以小號字型顯示在正文旁。


- 每頁字元數：

如果您的書沒有出版商頁碼（大多數書都沒有），卻仍需要固定頁碼，該怎麼辦？

此時可以啟用 KOReader 的 每頁字元數功能。使用該功能後，KOReader 會按照設定的 每頁字元數來計算頁碼，而不再依據螢幕尺寸。例如，您可以把 KOReader 設為「把 1500 個字元算作一頁」（這是該設定的預設值，大致相當於英文 250 個單詞）。而約 250 個單詞正是標準大眾市場平裝本/PA5 開本圖書一頁的容量。

因此啟用該功能後，書的總頁數會接近按上述尺寸印刷的實體書。當然，您也可以在選單中調整 每頁字元數設定，以模擬不同開本的書籍。

如果您手頭有某本書的紙質版，可以調整 每頁字元數的數值，使總頁數與紙質版一致，這樣便更容易在另一版本中定位到同一段落。

啟用固定頁碼功能後的變化

為某份文件啟用固定頁碼後，會發生以下變化：

  • 狀態列中的已讀、剩餘及總頁數會切換為固定頁碼。
  • 檔案瀏覽器會按固定頁碼顯示這份文件的總頁數。
  • 書籤、目錄和頁面瀏覽器也會顯示固定頁碼。
  • 若從這份文件匯出劃線，匯出檔案中劃線與筆記的位置資訊將使用固定頁碼。

5.1 如何儲存設定

設定完這些之後，您可能會問：「我的其他書也會變成這樣嗎？」不會，並不會自動生效。因為所有這些改動只對當前書籍有效。

在其他閱讀器應用中，當你更改某項設定（例如書籍所用字型）時，更改會全域性生效。也就是說，如果你把預設字型改為 Verdana，此後開啟的所有書籍——包括你正在閱讀的——都會以這種 Verdana 字型顯示。

KOReader 的做法與此不同。外觀設定是按書籍分別儲存的。這使你可以靈活地更改當前書籍的設定，而不影響其他書籍。例如你有一些奇幻小說，可以只把這些書的字型換成中世紀風格。也可以將某些書籍設為以橫屏或雙欄模式開啟。

KOReader 的機制是這樣的：

  1. 字型大小、行間距等 KOReader 設定都有預設值。
  2. 開啟一本新書時，KOReader 會參照這些預設值來設定書籍外觀。
  3. 在某本書裡所做的改動（例如調整文字大小）只影響這一本書。因為這些改動不會修改預設值，所以新開啟的書不受影響。
  4. 不過你也可以把改動儲存為預設值，這樣一來，新開啟的書籍同樣會採用這些設定。

來看一個例子：

因此，要讓某項設定長期生效，必須把它設為預設值。KOReader 提供兩種設定預設值的方法：

  2. 一次性將所有設定設為預設值

KOReader 字型系統的技術細節與故障排除 

如果在向 KOReader 新增字型時遇到字重方面的問題，本節可幫助你理解 KOReader 的字型處理機制：

  1. 啟動時，KOReader 會讀取各字型內嵌的字型元資料/資訊來整理可用字型，並按字型系列和字重分類。KOReader 會嘗試從字型所含元資料中判斷字型系列資訊，因此把字型複製到裝置時字型名稱並不重要。
  2. 如果某個字型系列有多個字型檔案，KOReader 會嘗試把它們歸入以下 4 類之一：Regular, Bold, Italic & BoldItalic。理想情況如下：
    • Luciole-Regular.ttf 對映到 字重：0 (Regular 400)
    • Luciole-Bold.ttf 對映到 字重：+3 (Bold 700)
    • Luciole-Regular-Italic.ttf
    • Luciole-Bold-Italic.ttf
    如果某個字型變體不存在，或需要進行小數級的微調，KOReader 會從最接近的可用字重合成得到。
  3. 如果某款字型只提供一個檔案、且並非 Bold，KOReader 會把它指定為 (Regular 400) 的 字重：0，並自行合成其餘所有字重與變體。換句話說，KOReader 會為這款字型「偽造」斜體和粗體。（如果這唯一的字型檔案是 Bold，KOReader 則會由這個粗體合成出 Regular 字重。）

 如果在底部選單中長按 字重標籤，就會顯示當前字型提供了哪些字重級別。

 如果你的字型還有其他變體，情況就可能變得複雜。假設你把一整個字型系列複製到了裝置上，啟動時 KOReader 讀到了該字型的以下變體，順序為：Light、Thin、Normal、Medium、ExtraBlack、SemiBold、Bold、Black。你可能以為 Normal 變體會被用作文件的正文字型（因為它的名字就叫 Normal），但 KOReader 實際會選用 Light，因為它是清單中第一個不帶粗體標記的字型。而 Thin、Normal 和 Medium 變體會被忽略，因為 KOReader 已經為文件找到了一個「非粗體」字型。

同樣按這個清單，ExtraBlack 會被用作粗體字型，因為它是清單中第一個帶有粗體標記的字型。而 SemiBold, Bold, Black 變體會被 KOReader 忽略，因為它已經找到了所需的「粗體」字型。

小結一下：我們複製了整個字型系列，本以為會選中 Normal 和 Bold 變體，結果 KOReader 卻用了 Light 和 ExtraBlack。這是因為字型送入 KOReader 的順序不受我們控制，只能「先到先得」。

解決辦法是只傳入你希望使用的字型檔案，例如：

  • Thin、Extra Light、Light、Normal、Medium 中只保留一個：它會被用作常規字型（如果你的 Regular 字型太細，且手頭有 Medium 字重，換成它即可）。
  • Semi Bold、Bold、Extra Bold、Black、Extra Black 中只保留一個：它會被用作粗體字型。
  • 也可以額外加入同字重的斜體變體（例如 medium/medium-italic）。
5.3 樣式微調 

KOReader 的樣式微調功能允許你修改 KOReader 顯示書籍的方式。我們不會在這裡進行完整的 CSS 課程。我們只想向你展示一些基本的東西，這樣當你看到一個樣式微調時，你至少會有一個大致的概念。

什麼是樣式微調？

我們可以將 EPUB 文件描述為 HTML 檔案 + 一些 CSS 規則。這些 CSS 規則決定了書籍的不同部分（標題、粗體文字、引用等）在閱讀應用中的顯示方式。藉助樣式微調，你可以透過新增新規則和/或覆蓋書籍中嵌入的、由出版商編寫的規則，來更改書籍的呈現方式。

讓我們看一個樣式微調的例子：

img { width: 10px !important; height: 10px !important }

用通俗的語言來說，這條規則是：忽略它們的原始大小，讓這本書中的所有圖片都有 10 個像素寬，10 個像素高。因此，如果你將此樣式微調新增到 KOReader，你書中的所有圖片都將顯示的很小。

現在讓我們逐項解釋這個調整：

  • img - 這是一個 CSS 選擇器，目標是書籍中的所有 img（圖片）元素。
  • { width: 10px !important; height: 10px !important; } - 這是宣告塊。它包含將應用於所選 img 元素的樣式。
  • width: 10px !important; - 第一部分將目標 img 元素的寬度設定為 10 像素。!important 宣告是一個覆蓋開關，它確保您的寬度值優先於應用於這些圖片的任何其他現有 width 宣告。
  • height: 10px !important; - 這部分將目標 img 元素的高度設定為 10 像素。同樣，!important 是一個覆蓋開關，可確保您的高度值優先於應用於這些圖片的任何其他現有 height 宣告。

總之，這個 CSS 規則旨在將你的書中的所有 img 元素設定固定寬度和高度為 10 像素，並忽略其原始樣式。

一些有用的樣式微調範例

這些是一些有用的樣式微調，你可以直接使用或根據自己的喜好修改。下一個標題解釋了如何在 KOReader 中使用它們。

  • 在書籍中的每個標題上方新增分隔線：

    H1, H2, H3, H4 { border-top: 2px solid black; }

  • 在標題上方新增一些邊距：

    H1, H2, H3, H4 { margin-top: 2em !important; }

  • 或者，如果書的標題上方的邊距過多，請將其刪除：

    H1, H2, H3, H4 { margin-top: 0 !important; }

  • 在段落之間新增一個小間隙，使文字更具可讀性：

    p + p { margin-top: 0.5em !important; margin-bottom: 0.5em !important; }

  • 停用 EPUB 中的所有圖片：

    img { display: none !important; }

  • 使圖片非常小，而不是停用它們：

    img { width: 10px !important; height: 10px !important }

  • 使電腦科學書籍中的程式碼塊部分更整潔、更易讀（在這裡你可以看到一個例子）：

    pre,code { font-size: 0.6em !important; line-height: 1.8em !important; background-color: #eee !important; margin: 1em 0 !important; padding: 1em 0 !important; }

  1. 在要劃線文段的首字上長按
  2. 移動手指到要劃線文段的末尾
  3. 抬起手指

編輯被劃線的文段文字

除了新增筆記，KOReader 還支援直接編輯書籤清單中顯示的劃線文字。在某些情況下，這可能比為劃線新增筆記更實用。比如要標記包含多項日期的句子但其中一項日期有誤，而要新增一條筆記來指出錯誤，得在筆記中明確寫明。但如果可以直接編輯被劃線文字，就可以直接在有誤的日期後寫上「該日期需要再次核對」。

請注意，此編輯操作不會改變頁面上顯示的被劃線文段，閱讀時看到的仍是書籍原文。編輯內容要在書籤清單介面檢視；在匯出劃線時，被匯出的文字會是編輯後的版本。

要編輯被劃線的文字，請按如下步驟操作：

  1. 點擊劃線文段
  2. 在彈出選單中點擊詳情
  3. 在詳情對話方塊中點擊編輯文字

你也可以從書籤視窗中進行操作：

  1. 透過點擊選單或手勢開啟書籤清單
  2. 長按想要編輯的被劃線文段
  3. 在選單中點擊編輯文字
  4. 在彈出對話方塊中修改文字，然後點擊儲存按鈕

若要將編輯後的文字撤回到書籍原文，按上方所屬步驟操作但在第三步時不要點擊編輯被劃線文字，而是點擊還原原始文字按鈕。

KOReader 中普通劃線的工作原理

當使用者在 KOReader 中劃線文段，不管是在 EPUB 還是 PDF 文件中，這段劃線會被寫入一個設定檔案。例如在閱讀 Alice in Wonderland.epub 時，在書籍檔案所在目錄會生成一個名為 Alice in Wonderland.sdr 的資料夾。劃線資料會儲存到這個 .sdr 資料夾中的檔案裡。倘若這個與書籍關聯的 .sdr 資料夾被刪除，書籍中的劃線也會丟失。


KOReader 中 PDF 文件劃線的工作原理

PDF 文件的劃線功能與上述說明有所不同。如前所述，儲存 PDF 劃線時，劃線資料會被直接寫入到 PDF 文件中，成為文件的一部分。這就是為何該 PDF 被發送給其他使用者後對方可使用相容的 PDF 閱讀軟體檢視劃線。對方無需獲得包含了劃線記錄的關聯 .sdr 資料夾，因為劃線已被直接嵌入 PDF 文件中。

讓我們透過一個例子來解釋使用此功能時可能出現的問題。想像一下，你正在使用 KOReader 在電子閱讀器上閱讀 PDF 書籍:

  1. 若將劃線儲存到 PDF 文件選項開啟，KOReader 會在做下劃線的同時將劃線寫入 PDF 文件。
  2. 你想繼續用 KOReader 在你的手機上閱讀這本書，所以你把這個 PDF 檔案從你的電子閱讀器複製到你的手機上（但是你沒有複製 .sdr 資料夾，只有 PDF 檔案）。
  3. 當用手機上的 KOReader 開啟書籍，可以看到劃線仍保留在書籍中。

此時兩處裝置上的情況是一致的，電子書閱讀器和手機上的 KOReader 都能檢視 PDF 文件中的劃線。但兩者僅是看起來一樣，實際卻有很大不同。

電子書閱讀器上的 KOReader 知道此 PDF 文件中的哪些劃線是由 KOReader 新增的，因為它有關聯的 .sdr 資料夾。但手機上的 KOReader 則不知道這些資訊，它只能讀取 PDF 文件。

在嘗試刪除或匯出 PDF 劃線時差異就更大了。電子書閱讀器上的 KOReader 即可刪除也可匯出劃線，但手機上的 KOReader 則不能。如前所述，它缺少文件關聯的 .sdr 資料夾，所以它無法區分哪部分是劃線，而只能將劃線視作原文的一部分。

所以簡單來說，如果打算之後匯出 PDF 劃線，務必在備份或複製 PDF 文件到其他裝置時將關聯的 .sdr 資料夾一併複製。

匯入劃線的方法：

  1. 用 KOReader 開啟你的 PDF 檔案
  2. 從此處開啟書籤對話方塊：
    頂部選單 / / 書籤
  3. 點擊左上角的  按鈕。
  4. 在開啟的對話方塊中，選擇匯入內嵌標註。你的劃線將被新增到書籤清單中。

匯入完成後，PDF 中的劃線將轉換為普通的 KOReader 劃線。這意味著，你可以：

  • 為它們新增筆記
  • 更改它們的樣式和顏色
  • 刪除它們（參見下方說明）
  • 以各種格式匯出它們

刪除的原理： 匯入劃線時，KOReader 不會修改 PDF 中原有的劃線，而是將匯入的劃線作為一層疊加在原有劃線之上。因此，刪除某條匯入的劃線時，只會刪除這新增的一層。PDF 檔案中的原有劃線不會被刪除，用其他閱讀軟體開啟該 PDF 仍可看到原有劃線。

 如果啟用了將劃線儲存到 PDF選項，刪除某條匯入的劃線時，PDF 檔案中嵌入的劃線也會被一併刪除。

8.4 最佳化漫畫

對喜歡在電子墨水螢幕裝置上閱讀漫畫的使用者，下面有一些提升閱讀體驗的小技巧。若漫畫在裝置上的呈現方式不盡如人意，對漫畫書檔案進行預處理是最佳解決方案。

使用哪種檔案類型

MOBI 和 EPUB 等檔案類型不適合主要處理圖片內容（例如漫畫/漫畫）。KOReader 中的 MOBI 支援幾乎為零，而 EPUB 的文字渲染優先順序在顯示整頁圖片時可能會導致問題。有關更多技術細節，請存取對應 GitHub 議題。

最好的選擇是建立一份在 KOReader 中效果更好的 CBZ 格式檔案。.cbz 副檔名的檔案本質上是將未壓縮處理的圖片集打包而成的 ZIP 壓縮檔，內含通常為 .png 或 .jpeg 格式、按照漫畫頁碼排序的多個圖片檔案。KOReader 也支援開啟 CBT 格式檔案，它與 CBZ 相似，區別是使用 TAR 格式打包。

將漫畫轉換為 CBZ 的最簡單方法是從各種網站獲得漫畫圖片，然後使用 Kindle Comic Converter 轉換它們。有一些有用的設定，如自動將跨頁雙頁旋轉為橫向並應用抖動，使墨水螢幕渲染的漸變平滑抖動，沒有鋸齒層。

使用哪種解析度

透過將圖片大小調整為電子閱讀器螢幕尺寸，可以獲得最佳效果。特定於螢幕的 CBZ 針對裝置的確切螢幕尺寸，可防止在讀取期間重新縮放。KOReader 在閱讀時將圖片縮放到螢幕尺寸，但不建議這樣做，因為 KOReader 在縮放之前添加了抖動通道，這會導致品質損失。

但是，如果你想在多臺裝置上使用手工製作的 CBZ，或者你想保留高解析度以備將來使用，那麼最好的選擇可能是為你的最高解析度裝置製作 CBZ。或者選擇可能與源解析度匹配的"高"解析度。300 PPI 或更高（450 甚至 600），當然，除非來源較低。我們假設螢幕尺寸為8"，1500×2000，這是一個不錯的目標解析度。對於較大的圖片，你應該在你的裝置上嘗試一下，看看它是否可以處理它。例如，記憶體不足的舊 Kindle 可能會難以處理 3000×4000 等大小。如果你要自動化該過程，則可能需要考慮建立較低和較高品質的兩個版本（例如 200/400 或 300/600 DPI）。

頂部選單 / / 輕觸與手勢 / 翻頁方式 / 交換左右兩側翻頁功能 / 相關按鈕
對漫畫書籍進行高階預處理

以下是處理一個漫畫檔案的示例過程：

  • 下載 Kindle 漫畫轉換器（KCC）（連結https://github.com/ciromattia/kcc）
  • 從你選擇的來源下載你的漫畫（如：HakuNeko）

  1. 解壓縮CBZ檔案，即之前用KCC建立並準備好的那份，

     下一項操作將會使目錄中的圖片被替換為處理後的版本。若想保留原件，請確保這些檔案已在別處存有副本。
  5. 執行 _magick_manga_ditherN_resize.bat 調整圖片大小和抖動。

- 第三種方式：透過檔案搜尋功能篩選書籍。該方式可十分高效地處理分散於多處目錄的多本書籍。例如，要將收藏清單中所有作者是托爾金的書籍移至同個資料夾，請按下列步驟操作：

  1. 從頂部選單按搜尋選項卡（帶有放大鏡圖示）並選擇檔案搜尋。
  2. 如果你也想在資料夾中搜尋，請選中包含子資料夾選項。如果你想讓 KOReader 在搜尋書籍的元資料，你可以選擇搜尋書籍元資料。否則，KOReader 只會搜尋檔名。
  3. 你可以透過按相應的按鈕從庫主資料夾或當前資料夾開始搜尋。
  4. 在執行檢索後，將列出符合條件的檔案清單（若存在關鍵詞匹配的結果）。現在可點擊漢堡選單（位於螢幕左上角），進入連續選擇模式。
  5. 點擊所有要處理的檔案，然後點擊勾號圖示（√）。該圖示位於螢幕左上角，點擊後會彈出對話方塊，其中包含在檔案瀏覽器選擇選項。選擇該選項。
  6. 現在，你將回到檔案瀏覽器，你在搜尋對話方塊中選擇的檔案也將在此處選擇。
  7. 點擊勾號圖示（√），它位於螢幕右上角。現在可從彈出的對話方塊中選擇要對這些檔案執行的操作。
資料夾捷徑

KOReader 允許你將最喜歡的資料夾新增到快速存取的資料夾快速選單中。例如，如果你的庫中有一個 Archive 資料夾，位於 Home>Articles>Scientific>Archived 下，你可以為這個 Archived 資料夾分配一個資料夾捷徑，即使在閱讀書籍時也可以快速存取它。

新增資料夾捷徑：

有兩種方法可以將資料夾新增到資料夾捷徑清單中：

  1. 當你在檔案瀏覽器中時，點擊右上角的+（附加）選單按鈕，然後點擊新增到資料夾捷徑項，並為此捷徑輸入描述性名稱。這將新增你當前所在的資料夾
  2. 在檔案瀏覽器中，長按資料夾名稱可開啟內容選單。點擊新增到資料夾捷徑項，然後為此捷徑輸入一個描述性名稱。這將新增你按下的資料夾

資料夾捷徑清單中的資料夾會顯示星號（★）標記，這一標記出現在檔案瀏覽器中。

你可以以相同的方式從捷徑中刪除資料夾，方法是長按資料夾並選擇從資料夾中刪除捷徑。


檢視資料夾捷徑：

你可以在閱讀書籍時從檔案瀏覽器或閱讀螢幕開啟資料夾快捷方式。

  • 從檔案瀏覽器：右上角+（附加）選單，然後選擇資料夾捷徑或指定手勢。
  • 從閱讀螢幕：透過為其分配手勢。

它位於手勢管理員的檔案瀏覽器部分。你可以在本指南的相關部分學習如何設定手勢。

9.2 瀏覽其他格式的檔案
檢視純文字檔案

如果你有 .txt 格式的書籍（在中文和西里爾文語言中更常見），你可以嘗試啟用自動偵測 txt 檔案佈局功能。在某些情況下，它可以改善渲染效果，使文字更"像書"。啟用後，渲染引擎將使用啟發式方法（文字被包裹在一些最大行長下，標記段落的單行或雙空行，縮排或被視為標題的居中文字…）來猜測如何更好地渲染文字，並嘗試建立一個目錄。

你可以在此處啟用此功能（僅當你正在讀取 .txt 檔案時才可見）：

頂部選單 / / 樣式 / 自動識別TXT檔案的版式

請注意，此功能可能會弄亂 ASCII 藝術繪圖和基於空格字元的格式。如果你的書籍具有這些功能，最好使用預設模式，在該模式下，純文字檔案以等寬字型按原樣呈現。

檢視存檔檔案

KOReader 可以讀取儲存/壓縮在 ZIP 壓縮檔中的檔案。你可以使用封存檢視器開啟 ZIP、CBZ 和 EPUB（因為它們也是 ZIP 壓縮檔）檔案以檢視包含的檔案：

  1. 在檔案瀏覽器長按檔名
  2. 點擊開啟方式…
  3. 點擊封存檢視器

ZIP 壓縮檔案可以包含多種類型的文件，如 HTML、TXT 或圖片。只有當你提示 ZIP 壓縮檔中的檔案類型時，KOReader 才能正確開啟你的 ZIP 壓縮檔。如果你只給檔案一個 .zip 副檔名，KOReader 將假定該壓縮檔僅包含圖片，並嘗試像 CBZ 檔案一樣開啟它。

預設情況：檔名.zip，假定為圖片的 ZIP 壓縮檔（並由 MuPDF 引擎開啟）

如果你的 ZIP 壓縮檔含這些類型之一（而不僅僅是圖片），請相應地命名它：

  • FB2格式（FictionBook） - 檔名.fb2.zip
  • HTML - 檔名.htm.zip / 檔名.html.zip
  • 文字記錄檔案 - 檔名.log.zip
  • Markdown 檔案 - 檔名.md.zip
  • 富文字格式 - 檔名.rtf.zip
  • 純文字 - 檔名.txt.zip

如果文件沒有這樣命名，則可能使用了錯誤的讀取器/格式引擎，你將看到此檔案沒有讀取器引擎或檔案無效訊息。你可以按照上述說明重新命名此檔案，也可以長按檔名，然後選擇開啟方式…選擇正確的引擎。

檢視圖片

你可以使用圖片檢視器開啟圖片檔案，而不是作為書籍開啟。像這樣開啟的檔案不會出現在你的歷史記錄中，並且具有更好的縮放和旋轉支援。

  1. 在檔案瀏覽器長按檔名
  2. 點擊開啟方式…
  3. 點擊圖片檢視器
檢視 Markdown 檔案

KOReader 提供了兩種讀取 Markdown 文件的選項。

  1. 你可以透過點擊它直接開啟文件就像一本書。此模式不提供格式設定。所以你的 .md 檔案看起來就像在文字編輯器中開啟一樣。
  2. 你可以將 Markdown 文件轉換為 HTML。此操作將呈現具有正確格式的 Markdown 文件中的 HTML 檔案，並根據標題建立目錄。

要轉換 .md 檔案，請在檔案瀏覽器中長按該檔案，然後從彈出選單中點擊轉換按鈕。將在同一目錄中建立一個同名但副檔名為 HTML 的新檔案。請注意，轉換可能需要一段時間，具體取決於你的 Markdown 檔案和裝置速度。

設定檔案關聯

你還可以為 KOReader 無法自動識別的檔案類型設定檔案關聯。要將檔案與 KOReader 提供程式之一相關聯，請首先在檔案瀏覽器中長按你的檔案，然後選擇一個提供程式引擎來處理此檔案。你可以選擇：

  • 始終對此檔案使用此引擎僅將此提供程式與此特定檔案相關聯
  • 或者選擇始終對檔案類型使用此引擎，將此提供程式與所有與此提供程式具有相同副檔名的檔案相關聯
  • 在同一對話方塊中，你可以透過點擊檢視預設檔案類型來檢視所建立的關聯
9.3 收藏清單

KOReader 的收藏清單功能可以讓個人書庫的管理更加高效。簡單來說，收藏清單就是由使用者建立的書籍清單。例如可以建立標題分別為文學和非文學的收藏清單，將對應的書籍編入其中。當然按資料夾存放書籍也可實現類似目的，但收藏清單用起來更加靈活。

使用收藏清單整理書籍相比資料夾的一些優勢：

  • 將書籍編入收藏清單並不會移動書籍檔案位置，因此存放在不同資料夾中的多本書籍可以被編入同一份收藏清單。
  • 同一本書可以被編入多份收藏清單，這很難透過資料夾實現。例如，一本書可以同時被編入科幻題材收藏清單和戰爭文學收藏清單。
  • 設定檔 可以應用於收藏清單。如果對 KOReader 的設定檔功能不熟悉，請查閱下文說明。（當然，設定檔也可應用於資料夾，但收藏清單無需移動書籍檔案即可臨時套用設定檔。）

使用者可建立多份收藏清單來對應各種書籍分類方式，例如：

  • 作品體裁：虛構文學、非虛構文學、報告文學等。
  • 閱讀狀態：在讀、想讀、已讀、擱置等。
  • 叢書：《指環王》、《哈利·波特》等。
  • 文件類型：書籍、科研論文、網頁等。
建立並編輯收藏清單

若要建立收藏清單，請按照下列路徑找到收藏清單對話方塊：

頂部選單 / / 收藏清單

該對話方塊可在閱讀檢視或檔案瀏覽器中使用。開啟時選單會列出現有收藏清單。預設情況下將顯示一份標題為最愛的收藏清單，其中包含已被新增到最愛清單的書籍。

  • 建立新收藏清單：點擊螢幕左上角的漢堡狀選單鍵 ⇨ 點擊建立新收藏清單
  • 刪除收藏清單：在收藏清單標題上長按 ⇨ 點擊刪除該收藏清單
  • 修改收藏清單標題：在收藏清單標題上長按 ⇨ 點擊修改收藏清單標題
  • 更改收藏清單順序：點擊螢幕左上角的漢堡狀選單鍵 ⇨ 點擊收藏清單排序
將書籍新增到收藏清單

有三種方式可以將書籍新增到收藏清單中：


一、透過檔案瀏覽器及歷史記錄檢視

可以在檔案瀏覽器或歷史記錄檢視中將書籍新增到收藏清單。歷史記錄檢視下可將書籍逐本新增到收藏清單中。在書籍上長按，選擇收藏清單…，然後可以選擇將該書新增到一份或多份收藏清單中。

若要一次性新增多本書籍，請在檔案瀏覽器中按照下列方式操作：

  1. 長按某本書
  2. 在彈出選單中點擊多選
  3. 選擇其他書籍
  4. 點擊右上角的勾號（✔️）圖示
  5. 點擊收藏清單

要新增單本書籍，只需在檔案瀏覽器中長按該書，在彈出選單中選擇新增到收藏清單。


二、透過收藏清單管理選單

該方法可以將一本或數本書籍新增到收藏清單中。與在檔案瀏覽器中操作不同，這種方法可以將整個資料夾及下層資料夾內的全部書籍一次性新增到收藏清單。如果書籍文件已經按照資料夾分類，該方法將十分高效。例如，如果全部科幻類書籍都在同一個資料夾內，可以建立標題為科幻題材的收藏清單，然後將該資料夾新增進去。

如上圖所示，方框 1 標出了新增書籍選項。該選單可點擊當前收藏清單的漢堡狀選單鍵呼出：

頂部選單 / / 收藏清單 / 收藏清單標題 /
  • 將整個資料夾加入收藏清單：如選項標題所示，該選項可以將所選資料夾中的全部書籍一次性編入當前收藏清單。請注意，所選資料夾的次級資料夾中的書籍不會被新增。例如，使用者選中名為虛構作品的資料夾，其中包含名為科幻作品和戰爭文學的兩個次級資料夾，這兩個次級資料夾內的書籍不會被新增到當前收藏清單中。
  • 將所選資料夾及次級資料夾中新增到收藏清單：該選項會將所選資料夾的次級資料夾一同加入收藏清單，使用時應當謹慎，因為該功能會遍歷所選的資料夾目錄。若其中包含多個目錄層級，新增的書籍數量可能會遠超使用者預期。
  • 新增書籍到收藏清單：該選項可以將單本書籍新增到當前收藏清單。
從收藏清單中移除書籍

可以透過檔案瀏覽器、歷史記錄檢視或收藏清單將書籍從收藏清單中移除。在檔案瀏覽器和歷史記錄檢視中長按書籍，選擇收藏清單，可以看到書籍所屬的收藏清單標題前有勾選標記。點擊該標記取消勾選即可將書籍從對應收藏清單中移除。另外在收藏清單介面長按書籍選擇從收藏清單中移除也可實現相同操作。

給收藏清單中的書籍排序

收藏清單可能十分冗長，因此 KOReader 提供多種篩選方式以便更容易地找到要讀的書籍。如前圖所示，方框 2 和方框 3 標出了書籍篩選選項。方框 2 可以按照書籍閱讀狀態（未讀、在讀、已讀、擱置）篩選；方框 3 可以透過書籍元資料（作者、叢書、語種、關鍵詞）篩選。兩種篩選方式還可組合使用，你也可以像這個例子一樣組合這兩組篩選器："向我展示這份收藏清單中 Isaac Asimov（按作者 -> Isaac Asimov）編寫的我還沒有開始閱讀的新書（按狀態 -> 未讀）。"

在檔案瀏覽器中長按某本書，可以更新書籍元資料或檢視書籍資訊。在彈出的對話方塊中長按任意項，可以編輯作者或關鍵詞等書籍元資料。該操作也可透過 Calibre 完成，這是一款便捷管理書籍元資料的第三方軟體。

 請注意，Calibre 會改寫書籍內部的元資料，因此將檔案從 Calibre 中匯出後，修改過的元資料仍然有效；但 KOReader 不會修改書籍檔案，而是將自訂的書籍元資料以獨立檔案的形式儲存於與書籍關聯的 .sdr 資料夾中，因此這些改動的元資料僅可使用 KOReader 檢視。
在收藏清單中檢索

在收藏清單中有兩種不同的搜尋操作：在書名及元資料檢索關鍵詞，或者在書籍內文搜尋。搜尋對話方塊可透過下列路徑呼出：

頂部選單 / / 收藏清單 / / 在收藏清單中檢索

在檢索書籍全文時有以下幾點需要注意：

  • 這種搜尋僅在透過檔案瀏覽器開啟收藏清單時才可用，在閱讀檢視下不可用。
  • 這種搜尋可能非常緩慢（收藏清單中的每本書大約耗時 2 秒），如果收藏清單很長，搜尋耗時將會非常久。

搜尋功能會因當前所處的收藏清單視窗層級而不同。當處於瀏覽全部收藏清單的根目錄檢視下，搜尋範圍將包含全部收藏清單。若要在特定收藏清單內搜尋，請點擊進入該收藏清單後再執行搜尋操作。如果同時檢索了書籍內文，這種區別將十分關鍵，因為那是一項頗為耗時的操作。

執行一次搜尋操作後，搜尋結果將自動生成一份新收藏清單。

根據資料夾自動更新收藏清單

在建立收藏清單並新增書籍後，使用者可能希望收藏清單可以與資料夾內容保持同步。例如，使用者使用科幻資料夾存放所有科幻作品，並用它建立了一份科幻題材收藏清單。如果希望在向該資料夾中新增檔案後，科幻題材收藏清單可以自動更新，可以使用收藏清單的關聯資料夾功能。

該功能可以將一個或多個資料夾關聯到收藏清單，KOReader 將在下列幾種情況下重新掃描這些資料夾，以便將書籍檔案的變化反應到收藏清單中：

  • 為收藏清單新增關聯資料夾後
  • 向關聯資料夾中添加了次級資料夾
  • 檢視該收藏清單時
  • KOReader 啟動時

將資料夾關聯到收藏清單的方法：

  1. 前往如上圖所示的收藏清單介面。
  2. 長按想要關聯到資料夾的收藏清單標題①。
  3. 在彈出選單中選擇關聯資料夾②。
  4. 此時會顯示已關聯的資料夾清單。
  5. 點擊螢幕左上角的加號圖示，在彈出的選擇資料夾視窗中選擇要新增的資料夾。
  6. 重複最後一步以新增多個資料夾。

9.4 最佳化文件

KOReader 的設計目標是在電子書閱讀器有限的硬體條件下也能高效執行。但總會遇到格式糟糕、拖慢 KOReader 的文件。下面將按檔案類型給出一些最佳化文件的建議。

EPUB 檔案
  • EPUB 檔案基本上由文字和圖片組成，並帶有一些規則來確定這些項目在螢幕上的格式。在理想情況下，這是一個相當簡單的過程，因此 EPUB 檔案在 KOReader 中通常速度很快。但是一些 EPUB 書籍添加了大量格式規則，KOReader 必須進行許多計算才能顯示哪怕是一個句子。這將減慢開啟書籍、翻頁和更改外觀屬性（如字型粗細或行間距）的速度。
     KOReader 不支援固定版式 EPUB 文件。這類文件仍可在 KOReader 中開啟，但會作為可重排 EPUB 渲染，版面可能會錯亂或難以閱讀。
  • EPUB 檔案格式本質上是包含 .html 檔案的 ZIP 壓縮檔。有的書籍僅包含單個 .html 檔案，而有的則由多個 .html 檔案構成，比如每一章節都被拆分為了獨立的 .html 檔案。如果當前書籍僅包含單個 .html 檔案，分段渲染功能就無法啟用，因此樣式調整會比章節拆分的書籍更慢，因為每次調整 KOReader 都需要對整本書籍進行處理，而不是僅渲染當前章節。
  • 另一種罕見的緩慢情況是內容被包裝在 HTML 表格標籤中。KOReader 必須在每次翻頁時渲染/繪製每個單元格，因此如果一個單元格（包含許多段落）跨越 50 頁，這將使翻頁速度非常慢。有關解決方案，請參閱下文。

解決方案：

  • 你可以在底部選單中將內建樣式設定為關閉，看看忽略所有文件樣式表是否會使其更快（當然，你可能會丟失任何漂亮的格式，但你會知道罪魁禍首是什麼）。
  • 如果你具備 HTML 和 CSS 知識，你可以直接從 KOReader 檢查 HTML 和 CSS 檔案，並自行判斷它們的品質或不必要的複雜性。為此，你可以長按某些文字並在彈出選單中選擇檢視 HTML。
  • 如果你有上面問題部分提到的"內容包裝在表格中"的問題，你可以將這個 table, tr, td { display:block; } 僅本書樣式調整新增到：
    頂部選單 / / 樣式微調 / 僅本書調整
  • Calibre 的電子書編輯器可以檢查 EPUB 檔案是否存在問題，並具有修復某些問題的工具。

    Calibre 可從其項目頁面下載。

    書籍檢查工具的使用說明可以在 Calibre 的使用指南中查閱。

  • EPUBCheck 軟體可用於檢查 EPUB 文件的有效性並偵測多種類型的錯誤。可參閱這條使用 EPUBCheck 檢測問題的範例議題。

PDF 檔案

PDF 檔案可能因以下問題而變慢：

  • PDF 檔案本身對於你的裝置記憶體來說可能太大。
  • PDF 文件可能內嵌大尺寸圖片檔案。即使帶有正常文字層的文件（可選中並劃線），仍可能疊加了另一個圖片層（頁面的整體掃描件）；這會拖慢文件開啟及翻頁速度，因為大尺寸圖片需要被壓縮到螢幕尺寸以供顯示，而該過程非常消耗 CPU 算力。
  • PDF 檔案可能包含許多需要精確定位的單個元素，例如包含大量圖片和文字框的雜誌頁面。在這種情況下，KOReader 必須計算和繪製所有這些元素，這可能需要時間。
  • 自動拉直功能（允許你調整頁面的傾斜）也可能會減慢你的閱讀器速度。
  • 如果你將繪製品質設定為高品質，而重排是開啟，文字將更令人愉悅，但它可能比預設慢得多（每頁翻幾秒鐘），具體取決於你的文件。
    底部選單 / / 繪製品質

不幸的是，對於糟糕的 PDF 檔案，沒有太多解決方案。通常，處理有問題的 PDF 最好的辦法是嘗試找到更好的版本。或者，如果有其他檔案類型可供下載，例如用 EPUB 代替 PDF（或反過來），也可以嘗試該格式。

你也可以嘗試把文件轉換為更靈活的 EPUB 格式。以下幾款軟體可在處理 PDF 時提供幫助：

  • Calibre 可以將文件轉換為多種格式。它的內建編輯器還可直接修改 EPUB 和 Kindle 等常見電子書格式並修正文件錯亂。
  • K2pdfopt 可以為便攜閱讀裝置及手機改善 PDF 和 DJVU 文件。該軟體可以對分欄的文件進行編輯，甚至對掃描版 PDF 檔案進行文字重排。同時，它可以作為一款通用的 PDF 複製、裁切、調整大小、OCR 等的編輯軟體。
  • OCRmyPDF 是一款為掃描版 PDF 文件新增 OCR 文字層的命令列軟體，使處理後的文件可以檢索及複製貼上。在閱讀掃描版舊書時格外有用。它也可用於壓縮圖片檔案大小。

TEXT 檔案

KOReader 擁有非常高效的文字處理引擎，並且會在首次開啟書籍時將其快取，以便下次更快開啟。但即便有這些最佳化，異常龐大的純文字檔案仍可能耗時更久才能開啟。例如，網路上的中文小說動輒數千萬字，且通常儲存為純文字檔案。

大型純文字檔案的問題在於首次渲染書籍以及後續修改文字外觀時的延遲。若嘗試修改一本非常大的 .txt 書籍的字型大小，每次調整後都可能明顯卡頓，因為整本書都要重新渲染。KOReader 帶有分段渲染機制，可大幅縮短此類延遲。但該功能無法用於純文字檔案，因為這類檔案沒有按章節拆分（關於分段渲染的更多說明見此處）。

若要享受分段渲染帶來的提速，可把大型純文字檔案轉換為 EPUB 格式，方法是使用 Calibre 軟體。Calibre 會在轉換時自動把純文字檔案切分為多個較小的獨立檔案，並打包成標準的 EPUB 檔案。轉換完成後，更改書籍外觀的速度會快得多。可從 Calibre 的頁面下載，並尋找有關TXT 轉 EPUB 操作的線上教程。

9.6 同步閱讀進度

如果你在電子書閱讀器、手機、平板或桌上型電腦等多個裝置上使用 KOReader，它可以在這些裝置之間同步閱讀進度。藉助進度同步功能，例如從家裡的閱讀器切換到通勤路上的手機時，也能無縫續讀。

該功能由進度同步外掛負責。同步的設定包含以下三個步驟，下面逐一說明：

  1. 建立同步帳號
  2. 在希望同步的所有裝置上登入你的同步帳號
  3. 自動或手動同步閱讀進度
1. 建立同步帳號

要建立同步帳號，請先讓裝置連線網路，然後開啟 KOReader 中的進度同步外掛：

頂部選單 / / 進度同步

然後點擊註冊/登入按鈕。

在彈出的視窗中輸入使用者名和密碼，然後點擊註冊按鈕。這會在 KOReader sync server 上建立一個帳號，用於儲存你的閱讀進度。

2. 登入同步帳號

在希望同步的裝置上開啟同一選單，輸入使用者名和密碼，這次點擊登入按鈕。之後，這些裝置就會連線到你的同步帳號。

你可以為裝置設定便於辨識的名稱。同樣在該選單中，點擊裝置主機名，為當前裝置輸入一個名稱。

3. 同步閱讀進度

全部設定完成後，即可自動或手動同步閱讀進度：

  • 自動同步：要自動同步，請啟用自動同步文件選單項。此後每當關閉書籍或休眠/喚醒裝置時，KOReader 都會把閱讀進度傳送到伺服器（當然這需要可用的網路連線）。
  • 手動同步：如果裝置因省電或網路條件無法持續聯網，可選擇手動同步。觸發同步的方式有很多種：
    1. 透過選單：在進度同步外掛的選單中，點擊立即上傳本裝置的進度選單項，可把當前裝置的進度傳送到伺服器；點擊立即從其他裝置拉取進度選單項，可取得伺服器上的最新進度。
    2. 透過手勢：這些操作（推送/拉取進度）可在手勢管理員中找到，你可以把它們指定給任意喜歡的手勢。
    3. 使用快速選單：你可以將這些操作新增到快速選單中。
    4. 透過設定檔：你可以把這些操作新增到設定檔中。尤其配合設定檔的自動執行功能，還能用各種篩選條件觸發同步。
文件匹配方法選項

要在兩臺不同裝置上同步某個文件的進度，KOReader 首先必須判定這兩個檔案是「同一個」。有時這並不容易，因此提供兩種方法供你根據使用習慣選擇。可在文件匹配方法選項中更改，它位於進度同步選單內。


二進位制匹配（預設）

預設情況下，進度同步使用二進位制匹配方法來識別檔案。此方法會為檔案內容生成一段部分 MD5 雜湊（形如 0b229176d4e8db7f...）。檔案哪怕只有極小的改動，也會徹底改變這段雜湊，因此二進位制匹配方法只在兩個檔案完全一致時才有效。

如果你手動把完全相同的檔案複製到所有裝置，這種方法應該可行。但如果用 Calibre 向裝置傳送書籍，二進位制匹配就會失效。

因為 Calibre 會把自己的資訊（如閱讀進度）直接寫入檔案，從而改變檔案雜湊的計算結果，KOReader 就會把這兩個檔案（原始檔案與經 Calibre 修改的檔案）當成兩本不同的書。若遇到這種情況，可改用下面介紹的替代方法。


檔名匹配

這是一種「更寬鬆」的匹配方法，專為那些檔案在不同裝置間可能略有差異的使用者設計——如上文所述，Calibre 等軟體對文件的修改會造成這種差異。

在此方法下，KOReader 只檢查兩份文件的檔名（含副檔名）是否相同，以此判定匹配。因此，如果你使用 Calibre 或其他書庫管理軟體跨裝置管理書庫，可以改用檔名匹配。

同步過程的隱私與安全性
  • KOReader sync server 是負責處理 KOReader 同步流程的軟體，屬於開源項目。你可在其GitHub 頁面檢視更多資訊及源程式碼。
  • 同步伺服器不儲存檔名或檔案內容。也就是說，伺服器無法知道你在讀什麼。同步某個文件的進度時，只有以下資訊會被傳輸並儲存在伺服器上：
    1. 使用者名（由你自己選定）
    2. 文件的唯一標識（檔案的 MD5 雜湊，形如 0b229176...）
    3. 本文件的最遠閱讀位置
  • 你的密碼不會儲存在伺服器上（僅保留其 MD5 雜湊）。
  • KOReader 與同步伺服器之間的所有通訊均透過 HTTPS 加密保護。

9.7 書籍元資料存檔

我們先說明 KOReader 的檔案刪除行為，以便你更好地理解書籍元資料存檔功能：

通常，當你把文件複製到裝置並首次開啟時，KOReader 會新建一個名稱類似 your_document_name.sdr 的目錄，用來儲存該文件的設定、標註和閱讀進度。

當你使用 KOReader 的檔案瀏覽器刪除文件時，KOReader 也會一併刪除這個 .sdr 目錄。這意味著該文件的所有設定、標註和閱讀進度都會丟失。如果之後再把這份文件複製到閱讀器並用 KOReader 開啟，就等同於第一次開啟它。

但舉個例子：如果你想刪掉已讀完的書（也許是不想讓書庫雜亂，或者儲存空間不足），卻又不想丟失這些書裡的劃線，該怎麼辦？書籍元資料存檔功能就能幫你做到。


此功能的工作原理：

  1. 首先需要在下列位置選擇一個存檔位置以啟用該功能：
    頂部選單 / / 文件 / 書籍元資料存檔 / 存檔位置：
  2. 此後，當你從檔案瀏覽器刪除文件時，確認對話方塊中會出現已啟用的該選項：[ ] 儲存書籍元資料以歸檔
  3. 刪除時若勾選該選項，KOReader 會把該文件的設定檔案複製到你在第一步所選的存檔目錄中。
  4. 隨後 KOReader 會刪除該文件及其關聯的 your_document_name.sdr 目錄。

文件雖已刪除，但其設定仍儲存在存檔中。如果再次把該文件複製到裝置並開啟，KOReader 會發現存檔中存有它的設定，並提示：「此書曾在本裝置上開啟過。是否從存檔恢復其元資料？」點擊恢復按鈕即可用這份存檔設定為該文件找回設定、標註和閱讀進度。

你可以在此處檢視已歸檔文件清單：

頂部選單 / / 文件 / 書籍元資料存檔 / 已歸檔書籍清單

在此清單中，點擊文件名稱即可檢視已歸檔文件的資訊/元資料和書籤；也可以把該文件從存檔中刪除。


當關閉書籍時將元資料儲存至存檔

如果在上述同一選單中啟用該選項，KOReader 會在關閉每份文件時儲存一份設定檔案的副本。此後即使你在 KOReader 之外（例如透過 Android 的檔案應用，或連線電腦時）刪除了文件及其 .sdr 資料夾，仍會保留該文件設定的備份。

 如果啟用了當關閉書籍時將元資料儲存至存檔選項，卻在檔案刪除對話方塊中取消了儲存書籍元資料以歸檔選項，KOReader 將刪除此前為該文件建立的設定存檔檔案。

 KOReader 透過檔案雜湊識別被刪除的檔案。這意味著重新複製回裝置的檔案必須與被刪除的檔案完全一致。任何改動（例如寫入檔案的 Calibre 元資料或新增的 PDF 劃線）都會改變檔案雜湊。此時 KOReader 無法提供恢復選項，因為它會把該檔案視為另一份檔案。更詳細的資訊請參閱本指南的下一節：書籍元資料儲存
9.8 書籍元資料儲存

KOReader 將與書籍相關的設定和額外資訊儲存在與書籍檔案相同的目錄中。我們稱之為元資料，它包括：

  • 書籍的顯示設定
  • 全書閱讀進度
  • 劃線、書籤與筆記

在最近的一次更改中，我們添加了儲存此元資料的新方法，以解決與裝置之間同步相關的某些問題。目前有三種不同的方法來儲存元資料，每種方法都有自己的優缺點。

你可以從此選單更改此設定：

頂部選單 / / 文件相關 / 書籍元資料存放目錄
 強烈建議在改動任何設定前閱讀下面的章節，瞭解各選項的功能及工作原理。否則可能面臨丟失書籤、閱讀進度及標註的風險。
1.書籍檔案旁邊的單個元資料資料夾-預設設定
頂部選單 / / 文件 / 書籍元資料存放目錄：書籍所在資料夾

這是 KOReader 新安裝時使用的預設方法。在此方法中，當你將 Alice In Wonderland.epub 複製到裝置並首次開啟時，將在同一目錄中建立一個名為 Alice In Wonderland.sdr 的資料夾。此目錄包含本書的設定、標註和書籍進度的檔案。

好處

  • 你可以手動備份和還原每本書的設定。
  • 當你使用 Syncthing 或 Dropbox 等系統執行目錄同步或備份時，你的設定將與你的書籍同步。
  • 你可以重新命名書籍所在的父目錄，這不會導致 KOReader 混淆。

壞處

  • 如果你在 KOReader 檔案瀏覽器之外透過其他方式移動/重新命名書籍檔案或其附帶的 .sdr 資料夾來重新組織你的庫，你將在沒有任何警告的情況下丟失這些書籍的元資料。
  • 當你使用其他檔案瀏覽器或從計算機瀏覽庫目錄時，這些 .sdr 資料夾將可見，這可能會使你的檢視變得混亂。
2.單個 KOReader 目錄下的元資料目錄
頂部選單 / / 文件 / 書籍元資料資料夾：./docsettings

此方法與上面的預設方法基本相同。不同的是，在這種方法中，你的所有書籍的 .sdr 資料夾都將位於 KOReader 主目錄結構下的單個目錄下，而不是書籍檔案旁邊的庫目錄下。

好處

  • 書籍.sdr 資料夾僅對 KOReader 可見並由其使用。當你使用另一個檔案瀏覽器或從計算機瀏覽庫時，它們不會打亂你對庫目錄的檢視。

壞處

  • 如果你透過在 KOReader 檔案瀏覽器之外移動/重新命名移動/重新命名庫目錄、書籍檔案或其附帶的.sdr資料夾來重新組織你的庫，你將在沒有任何警告的情況下遺失這些書籍的元資料。
  • 由於你的書籍元資料不在庫資料夾中，因此庫的任何同步或備份都不會包含它們。
3.單個 KOReader 目錄下的單個 HASHED 元資料目錄
頂部選單 / / 文件 / 書籍元資料資料夾：./hashdocsettings

此方法與前一種方法類似，因為 .sdr 資料夾將位於內部目錄下。但這種方法是為了解決以前方法的缺點而開發的。因為，通常如果你在 KOReader 之外重新命名一本書（使用裝置的本機檔案瀏覽器/閱讀器或從連線的計算機），其 .sdr 資料夾名稱將不再匹配，並且該書的元資料將丟失。如果你只使用 KOReader 檔案瀏覽器進行檔案操作，則會自動處理，因此不會產生任何影響。

在這種 HASHED 方法中，.sdr 資料夾不是由書籍的檔案路徑/檔名標識的。相反，將使用部分 MD5 雜湊將書籍連結到其設定。此雜湊用作書籍的唯一 ID，並根據書籍檔案的內容計算。同樣的雜湊也用於命名其 .sdr 資料夾。

好處

  • 書籍 .sdr 資料夾僅對 KOReader 可見並由其使用。當你使用另一個檔案瀏覽器或從計算機瀏覽庫目錄時，它們不會弄亂你對庫目錄的檢視。
  • 你可以使用其他檔案瀏覽器或從計算機重新命名、移動和複製書籍。經過這些操作後，KOReader 仍將識別這些書籍。
  • 在這種方法中，KOReader 將同一個 .sdr 資料夾與書籍的所有副本相關聯，即使這些副本位於不同的裝置上。例如，如果你正在使用 Syncthing，此方法使你能夠在安裝了 KOReader 的許多裝置上同步你的 /hashdocsettings 資料夾以及你的書籍檔案。儘管這些書在每個裝置上的相對路徑不同，但你仍然可以在裝置之間同步標註和進度。這在其他方法中是不可能的。

壞處

  • 任何直接修改檔案的操作（如將劃線寫入 PDF 文件或從 Calibre 下載劃線）都會使檔案發生變化，導致檔案的 MD5 校驗值發生變化（不過重新命名檔案或移動檔案對此沒有影響）。此時 KOReader 無法識別該書籍，因此該書籍的元資料將會丟失。
  • 在瀏覽較大目錄時，計算檔案 ID 可能會減慢檔案瀏覽器的導航速度。

11.1 快速選單

快速選單是 KOReader 的最新功能，它允許你擁有一個快速存取的個人化選單，如下圖所示。你可以將此選單分配給一個手勢，並透過一次滑動存取它。你甚至可以有一個比你的螢幕更長的選單，它是可捲動的。

基本上，你可以指定手勢的任何操作都可以新增到快速選單中。其優點是：

  1. 你不需要為每個動作記住很多手勢。
  2. 一些不常見的動作可能不值得一個手勢，但在選單系統中找到它可能太麻煩了。你可以將這種很少使用的操作新增到此選單中。
  3. 如果你正在為親戚或朋友安裝 KOReader，則可以將他們喜歡的操作新增到此選單中，以便他們在使用 KOReader 時甚至不需要進入選單系統。

快速選單範例：

建立快速選單有兩種方法：簡單方式和高階方式。如果你只需要一個選單，簡單方式應該足夠你。如果你想用不同的手勢顯示不同的選單，你需要使用高階方式。高階方式的另一個優點是更容易進行手勢重新分配。如果要更改選單的手勢，可以使用高階方式選單輕鬆將其移動到另一個手勢。如果你想在使用簡單方式時使用其他手勢，則必須在新手勢下重新建立選單。

簡單方式
  1. 透過以下方式轉到手勢管理員選單：
    頂部選單 / / 輕觸與手勢 / 手勢管理員
  2. 決定開啟選單的手勢並點擊它。
  3. 從手勢設定選單中選擇要在選單中顯示的動作。當然，你可以一次選擇多個操作。
  4. 選擇所有動作後，你將告訴 KOReader 將此手勢視為選單。你可以透過在第二頁上啟用顯示為快速選單項來實現這一點，如下圖中所示。
  5. 你可以使用同一選單中的排序操作和快速選單分隔符選項對選單項進行排序。

現在，你可以使用所選的手勢啟動選單。如果要更改選單項，可以開啟手勢頁面並新增/刪除項目。

高階方式
 如上所述，如果不打算新增多個快速選單，則無需閱讀本節。

快速選單本質上是一套設定檔，只是以選單形式顯示在螢幕上。使用該功能須先對設定檔有所瞭解。若是如此請繼續閱讀，否則請轉至設定檔一節（即下一節），建立一套包含若干項的設定檔再回來繼續閱讀。

在繼續之前，我們假設你已經按照上一段中的說明建立了設定檔。現在，我們將把設定檔轉換為快速選單。

（1）轉到新建立的設定檔，在下圖所示的選單中啟用顯示在操作清單中，這將使該設定檔列入手勢管理員清單中。在同一選單中啟用顯示為快速選單，這樣該設定檔會顯示為選單清單，而不是在後臺靜默執行。

（2）現在，我們需要一種存取選單的方法。轉到手勢管理員，並從清單中選擇一個手勢以分配給選單。假設我們想點擊螢幕的一角來顯示選單。現在點擊在螢幕四角點擊，然後選擇左下角。現在點擊一般並轉到第二頁。你將發現你的設定檔顯示為「設定檔 X」，其中 X 是你為此設定檔指定的標題。點擊其核取方塊，將你的設定檔分配給該手勢。

完成所有步驟後，現在當你點擊左下角時，應該會看到你的選單。你可以透過轉到其設定檔頁面來編輯選單，你可以在其中新增或刪除項目。此外，那裡還有一個排序項，因此你可以更改選單項的順序。

如前所述，快速選單實際上是一套設定檔。這意味著你可以有多個選單。如果需要，可以建立另一個設定檔，並按照相同的步驟建立另一選單。

使用後保持選單開啟

通常快速選單會在選擇選單項後從螢幕上消失。有時，你可能希望在選擇項目後保持選單開啟。這允許你像以下範例一樣調整設定：

  • 增量更改，如亮度增加/減少、較大/較小字型大小、上一頁/下一頁或章節等。
  • 你連續啟用的一組選項（但不是同時啟用），如開啟 Wi-Fi，之後啟動 SSH 伺服器

如果你具有基於手勢管理員（簡易方法）的快速選單，則可以從以下選單中啟用此選項：

頂部選單 / / 輕觸與手勢 / 手勢管理員 / 「使用者指定的手勢」 / 保持快速選單開啟

若已建立基於設定檔（高階操作）的快速選單，請在下列選單中選擇：

頂部選單 / / 設定檔 / 「使用者指定的快速選單設定檔」 / 編輯行為 / 保持快速選單開啟
在手勢位置開啟快速選單

通常，快速選單在螢幕中間居中開啟。如果你用一只手使用電子閱讀器，則可以啟用一個設定，該設定將在手勢位置開啟選單。這樣，選單將更接近你的手指，更容易存取。要使用此功能，請啟用此選項：

頂部選單 / / 輕觸與手勢 / 手勢管理員 / 「使用者指定的快速選單手勢」 / 將快速選單錨定在手勢位置
 此選項僅適用於透過手勢管理員（即前文的簡單方式）建立的快速選單。
將設定檔作為選單項新增到快速選單

除了向快速選單新增操作外，你還可以將設定檔作為選單項新增進去。這樣，透過這一個選單項就能一次執行多項操作。

假設你已經有一個可用的快速選單和一個想要新增到該選單的設定檔。準備就緒後，請按以下步驟操作：

  1. 前往要作為「選單項」使用的設定檔的設定，啟用顯示在操作清單中。這將使該設定檔顯示在手勢管理員中。
  2. 現在可以在手勢管理員中將該設定檔作為常規操作新增到快速選單。該設定檔位於一般子選單（手勢管理員內）的最後一頁。

將設定檔新增為選單項後，你可以開啟快速選單並點擊該項，以執行該設定檔中的所有操作。你也可以將設定檔新增為子選單，從而形成巢狀選單。下一節將介紹這一方法。

建立巢狀快速選單

你還可以將一個快速選單作為選單項新增到另一個快速選單中，從而形成巢狀選單結構。當你有多個快速選單卻不想給每個都分配不同手勢時，這一功能很有用。

  1. 前往要作為「子選單」使用的設定檔的設定，啟用顯示在操作清單中。這將使該設定檔顯示在手勢管理員中。
  2. 然後進入編輯操作選單（位於該設定檔的同一設定中），並針對該子選單設定檔啟用位於第二頁的顯示為快速選單選項。這樣 KOReader 就會把該設定檔當作另一個可進入的選單，而不是在點擊它時執行其中的所有操作。
  3. 現在可以將該設定檔作為常規操作新增到父級快速選單，就像在手勢管理員中新增其他操作一樣。該子選單設定檔位於一般選項卡的最後一頁。
 如果上述第二步中沒有為子選單啟用顯示為快速選單，你仍可在父選單中長按子選單的名稱來存取其選單項。這還會在子選單頂部提供一個全部執行項。
11.3 設定檔

設定檔本質上是一套操作集合（就像巨集命令），可透過單個手勢觸發。

例如在閱讀某種類型的書籍時總會應用如下設定：

  • 將螢幕切換到橫向顯示模式

  • 開啟螢幕前光

藉助設定檔外掛，只需執行單次操作即可完成這些調整。

 啟用另一套設定檔後，前一套設定檔所執行的修改將不可撤銷。例如，使用者啟用了一套設定檔將字型大小從 20 改為 24，然後又啟用了另一套設定檔調整了前光，此時字型大小將保持為 24。KOReader 沒有退出或撤銷設定檔的操作選項。

  • 將裝置倒置時啟用夜間模式。
  • 將所有漫畫新增到一份收藏清單，然後建立一套設定檔在開啟收藏清單內的漫畫時自動套用，將翻頁方向改為從右向左並交換左右兩側的翻頁點擊及滑動手勢。
  • 將漫畫書新增到套用設定檔的收藏清單，閱讀該收藏清單內的書籍時將頁面重新整理間隔降低到逐頁重新整理以避免殘影。
  • 首次從期刊資料夾開啟檔案時，套用設定檔以調整字型、字型大小並設定雙欄模式。
  • 將有問題的 PDF 文件編成一份收藏清單，在閱讀這些文件時套用設定檔觸發自動 OCR 或者啟動頁面重排模式。
  • 在檔案瀏覽器中開啟特定資料夾時，切換檢視為封面顯示、詳情清單等。
  • 開啟《參考類書籍》收藏清單中的書籍時停用閱讀統計，並在關閉書籍時重新啟用閱讀統計。
  • 在手勢管理員中呼出樣式微調選單，可以建立一套設定檔以根據指定條件啟用或停用對應樣式。例如，可以建立一套「禁用出版商樣式，並應用我的自訂樣式調整」的設定檔，根據書籍檔案存放目錄、被編入的收藏清單或書籍元資料中包含的關鍵詞等條件自動套用。請查閱樣式微調一節詳細瞭解。
逐一執行設定檔中的操作

通常執行設定檔時，其中的所有操作會按照你在排序操作選單中選定的順序依次執行。

但你也可以選擇讓它們逐一執行。也就是說，每次呼叫該設定檔時，只執行其中一項操作（下一項），而非全部執行。

下面舉一個實用的例子：

  1. 建立一套包含以下操作的設定檔
    • 轉到鎖定頁
    • 返回前一位置
  2. 為其指定一個簡便的手勢，例如點擊右下角
  3. 從設定檔的編輯操作選單中啟用逐一執行選項

現在，每次點擊右下方邊角，你都會在鎖定頁與當前閱讀位置之間切換。例如，這可用於快速跳轉到參考文獻章節再返回。

設定檔問題排查

為避免與 KOReader 的其他操作/事件相互干擾，設定檔在自動執行時會帶有極小的延遲。但在某些情況下（例如關閉文件時），設定檔必須立即執行才能完成其操作。

可透過以下路徑啟用該即時執行選項：

頂部選單 / / 設定檔 / 「你的設定檔名稱」 / 自動執行 / 立即執行

啟用此選項後，例如對於觸發條件為關閉書籍時的設定檔，該設定檔將在文件關閉之前執行。在這種情況下，這一執行順序是正確執行所必需的。

每當為設定檔啟用自動執行時，建議同時啟用立即執行選項。如果發現設定檔工作不正常，可以嘗試停用此選項。

 此設定也可能引發（未知的）問題，因為設定檔中的操作組合幾乎是無限的，我們無法預知它們會如何相互影響。因此該選項預設不啟用。
設定檔與快速選單的技術細節 

KOReader 有操作組/設定組的概念，這種成套的操作組合可以透過兩種方式建立：

  1. 「高階操作」編製成設定檔（保存於 settings/profiles.lua 中）
  2. 「簡單方法」作為指定手勢的操作項（保存於 settings/gestures.lua 中）

操作組合也可以透過兩種不同的方式執行：

  1. 在觸發後按照指定的順序依次逐項執行（作為設定檔）
  2. 將其顯示為快速選單

對操作組合進行新增/刪除及對快速選單項進行啟用/排序都是透過相同的操作選單完成。唯一的區別是，手勢管理員中的操作選單還有兩個項目（忽略），導致顯示為快速選單和排序這兩個選項被擠到第二頁上。

 你可以將設定檔備份並轉移到其他裝置。詳情請參閱備份 KOReader 設定一節。

  • 它們由我們的開發人員檢查，因此它們被認為是安全的。
  • 它們會隨 KOReader 更新而自動更新。

  • 它們應當被手動更新。
  • 它們在新增到儲存庫時由我們的開發人員進行檢查，因此它們被認為是安全的。

12.3 使用者補丁 

使用者補丁是用 Lua 語言編寫的小檔案。他們可以更改 KOReader 的功能，而無需永久修改你的安裝。它們可以由開發人員、其他使用者編寫，也可以自己編寫（如果你對 KOReader 內部結構有必要的廣泛瞭解）。

當前可用的使用者補丁清單可以在項目的維基頁面上查閱，或檢視 Github 議題清單中帶有 User patch available 標籤的議題項，請點擊此連結存取。

基本用法 – 將已編寫的補丁新增到 KOReader：
  1. 在裝置上的 KOReader 目錄下建立名為 patches 的目錄（在 Android 上，該資料夾位於 SD 卡上）
  2. 下載擴展名為 .lua 的補丁檔案並將其放入此 patches 目錄中
  3. 重新啟動 KOReader
補丁管理器

按照說明建立補丁目錄並重新啟動 KOReader 後，在外掛選單中將出現名為補丁管理的新外掛。透過使用此外掛，你可以檢視使用者補丁的清單和狀態並啟用/停用它們。你可以點擊關於補丁管理器選單項以檢視更多資訊。

命名補丁

補丁的執行順序由補丁名稱中數字的第一位數字決定。例如：2-TOC-title-patch.lua 如果有多個以同一數字開頭的補丁，則執行順序為自然順序（1<10<11<12<13<…<109<…<10010）。如果你只是下載已製作的補丁，則無需更改檔名。

名稱以：

  • 0 - 最早執行，並且僅在更新後執行一次
  • 1 - 在每次啟動 KOReader 時很早執行（但在 0 之後，如果適用）
  • 2 - 在每次啟動 KOReader 時 UIManager 準備就緒後執行
  • 3-7 - 保留
  • 8 - 在退出之前和儲存設定之前執行
  • 9 - 在退出前執行

如果使用者補丁有問題，可以透過刪除補丁檔案來恢復到以前的配置。

13 閱讀能力提升

本節先介紹兩款可能提高閱讀速度的 KOReader 外掛，隨後列出一些有助於提升閱讀速度與理解力的字型。

13.1 快速閱讀外掛
1. 感知擴展器外掛

啟用後，該外掛會在閱讀區域靠近左右邊緣處新增兩條豎線，如下圖所示。閱讀一行文字時，這兩條線充當眼睛的起止標記。該外掛的原理是：你其實不必直視一行的首尾單詞，稍加練習就能用周邊視覺感知到它們。

  • 灰色豎線：感知擴展器指示線
  • 紅線：眼睛正常跟隨文字移動
  • 藍線：眼睛在指示線之間跳動（距離更短）

要使用該外掛，需先透過以下路徑啟用：

頂部選單 / / 更多工具 / 外掛管理 / 感知擴展器

啟用外掛後，此處會新增一個選單項：

頂部選單 / / 快速閱讀模組 — 感知擴展器

你可以在此選單中切換擴展線的顯示，並根據自己的喜好和周邊視覺熟練程度配置指示線。啟發這款外掛的 Tim Ferriss 影片可在此觀看。

2. FastReader 外掛

這款外掛是一個 RSVP（快速序列視覺呈現） 閱讀器。該技術的做法是在螢幕中央快速閃現單詞。這樣閱讀時眼睛無需移動，因此閱讀速度可以更快。熟練之後還能一次感知多個單詞，進一步提升閱讀速度。

要使用該外掛，需先透過以下路徑啟用：

頂部選單 / / 更多工具 / 外掛管理 / FastReader

啟用外掛後，此處會新增一個選單項：

頂部選單 / / 更多工具 / FastReader

你可以從此選單啟動該外掛，並配置以下設定：

  • RSVP 速度 - 以 WPM（每分鐘詞數）計的閃現速度
  • 預覽字數 - 一次顯示多少個詞

你可以先用單詞模式和低 WPM（較慢）開始，熟練後再逐步提高。

這些字型的安裝方式與其他字型相同。若不清楚如何為裝置新增字型，可參閱使用自己的字型一節。

本節字型概覽（注意，圖中所有字型大小相同，均為 11 pt，但寬度、行高和可讀性差別很大）：

Atkinson Hyperlegible

該字型系列由 Braille Institute 設計，旨在提升低視力人群的易認性與可讀性，字母和數字清晰且辨識度高。可從 Braille Institute 檢視並下載該字型。


B612

B612 是一款易認性極高的字型系列，最初為空客飛機駕駛艙螢幕設計。其清晰的字形特別適合條件欠佳的閱讀環境，可減輕視覺疲勞與認知負擔。這些設計原則同樣使它適合電子閱讀器。可在 Google Fonts 檢視並下載該字型。


Lexend

這款字型的設計源自旨在提升學生閱讀表現的教育研究結論。可在此瞭解該字型，並從 Google Fonts 下載。


Luciole

這款字型遵循十餘項專門的設計準則，力求為視障人士提供最佳閱讀體驗。它強調字母的「內部」空間，數字與數學符號極為清晰易辨。可在此檢視並下載該字型。


Open Dyslexic

這款字型專為提升閱讀障礙讀者的可讀性而設計。字母底部加重以強調方向，每個字母的獨特字形可避免翻轉、混淆。可在此下載。


Shantell Sans

這款字型由一位有閱讀障礙的設計者打造，易認、易用、便於閱讀。得益於較寬的字母和寬鬆的字距，它在小字型大小下表現也很好。可從 Google Fonts下載。


Fast Font

這是一種特殊字型，會把單詞開頭的幾個字母替換為粗體變體（字母數量按單詞長度計算）。 This bold letters then act as artificial fixation points for the eye to jump on as you can see in this sentence. 理論上這可能提高閱讀速度，但當然實際效果因人而異。有趣的是，ADHD 讀者普遍反映有所獲益。

這款字型依賴 KOReader 支援的特殊 OpenType 特性，因此只需下載字型、複製到裝置即可像其他字型一樣使用。可在其 GitHub 檢視示例並下載該字型及其變體（襯線、等寬和點陣版）。

閱讀豎排書籍

目前官方 KOReader 尚不支援渲染豎排文字的書籍（tategaki，即日文「縦書き」），但有一位使用者做出了可實現該功能的分支。它基本上是 KOReader 的復刻，額外加入了豎排文字渲染。

日文豎排書寫是該分支的主要目標。但由於其實現在渲染引擎層面支援 EPUB writing-mode: vertical-rl，它也可能適用於其他豎排書寫的語言。據中文使用者回饋，它至少也能渲染中文。

請注意，這是一個分支（不是外掛，也不是使用者補丁），會完全替換你現有的 KOReader。不過普通橫排書籍的表現與官方 KOReader 基本一致，因此這種替換在功能上應當是等效的。

無需先解除安裝當前的 KOReader 即可切換到該分支，只需按照該分支倉庫中的說明操作。我們倉庫中的開發討論在此。

若切換到該分支，與豎排文字相關的問題/議題請提交到該分支的倉庫，而不要提交到 KOReader 官方倉庫。

電池耗電問題

KOReader 的耗電非常克制。因此，如果在使用 KOReader 時閱讀器電池開始異常掉電，通常首先要懷疑的是電池老化。

但如果你確認電池狀態良好，且掉電只在使用 KOReader 時發生，原因可能是：

  • 有問題的韌體更新
  • 某個第三方外掛
  • 一個使用者補丁

若遇到掉電問題，可按以下步驟排查：

  1. 將裝置更新到最新韌體版本。若裝置沒有可用的韌體更新，請跳到下一步。
  2. 若更新韌體仍未解決掉電問題，請移除已安裝的所有第三方外掛和使用者補丁，然後重新啟動 KOReader。
  3. 若前兩步之後掉電問題依舊，最後的辦法是將裝置恢復出廠設定並重新安裝 KOReader（別忘了備份主書庫資料夾）。

如果問題仍然存在，可以在我們的 GitHub 頁面新開議題。

我的書很慢

請參閱指南的最佳化文件一節，取得特定檔案執行緩慢時的建議和解決辦法。

如果所有書籍都執行緩慢，則問題可能與裝置有關：

  • CPU 速度非常慢或 RAM 不足。
  • 你的快閃記憶體（你的書籍所在的位置）可能會退化，這通常是由於裝置老化造成的。
  • 你的儲存空間可能不足。
  • 如果你使用的是基於 Android 的裝置，你的 Android 系統可能會干擾 KOReader 的執行，或者某些背景程序可能會使用你的系統資源。

新開議題：

如果你要就這個問題提交一個議題，對我們來說檢查有問題的檔案非常重要。你可以在將其壓縮成 ZIP 壓縮檔後，直接透過拖放的方式將檔案分享到你的 GitHub 訊息中。如果你的書是 EPUB，並且由於版權或隱私問題，你不想共享該檔案，有一個名為 ScrambleEbook 的 Calibre 外掛，你可以從Mobileread 論壇頁面存取下載和說明。

此外掛將讀取未加 DRM 保護的電子書檔案（EPUB/KEPUB/AZW3），並建立一本文字被隨機字元替換的書的副本。你可以在你的議題中與我們分享這個混亂版本。書中的文字將無法閱讀，也不會有任何版權侵犯，但我們仍然可以使用此檔案進行診斷目的。

你可以在此處看到這個涉及非常有問題的 EPUB 檔案的實際問題的過程。

翻頁時的重影

即使 KOReader 設定為在每頁完整重新整理，你仍然可能在翻頁後看到一些重影/殘留。這是電子墨水螢幕技術的侷限性，可以在最新一代裝置上觀察到，尤其是在閱讀混合內容（文字+圖片）文件時。作為解決方法，你可以在翻頁後再次手動重新整理，以消除這些偽影（預設為短對角線滑動手勢）。

在 Android 裝置上重設 KOReader

在 Android 裝置上，KOReader 將設定儲存在 Internal Storage/koreader/ 目錄下。這是有意設計，與其他 Android 應用不同。該目錄使用者可直接存取，便於備份和同步 KOReader 設定。

但當你解除安裝 KOReader，或在 Android 系統設定選單中清除其資料時，這個 KOReader 設定目錄並不會被刪除。因此，解除安裝後重新安裝 KOReader，它仍會沿用舊設定啟動。

若想把 KOReader 徹底重設為出廠預設狀態，需手動刪除該目錄。刪除後再次啟動 KOReader 時，它會自動以預設設定重新建立。

在 Amazon Kindle 裝置上停用廣告

這在技術上可行，但遺憾的是我們無法更改這些閱讀器上預設的螢幕保護行為。因為這可能引發 Amazon 的負面反應，進而封鎖 Kindle 生態（Kindle 上將不再能用 KOReader），甚至危及整個項目（KOReader 不復存在）。更多資訊可在此檢視我們與開發者的討論。我們的立場與 MobileRead 論壇一致，可在此閱讀。

文字縮排問題

如果標題、小標題或分隔符沒有正確居中，或者出現意外的文字縮排，請嘗試切換文件的樣式，把 epub.css 改成 html5.css。發生這種問題是因為一些出版方認為他們的書只會在基於網路瀏覽器引擎的閱讀器上閱讀，因此他們不會費心「重設」樣式。

頂部選單 / / 樣式
  • 預設 HTML/EPUB (epub.css) 是我們面向書籍的樣式表，帶有 text-align: justify, text-indent on P。它更適合無樣式的書籍，並且可能會使具有樣式的書籍更具可讀性。
  • 如果您的書籍存在上述縮排問題，您可以嘗試切換到 HTML5 (html5.css)，這種樣式提供了一個基本樣式表，就像 Web 瀏覽器在渲染時所做的那樣： text-align: left, no text-indent on P, spacing between P。但是當出版方沒有做任何樣式時，它看起來並不漂亮。
刪除書籍封面快取資料庫

KOReader 會快取書籍封面以更快地顯示。在正常情況下該快取不會佔用過多空間。在刪除大量書籍或對資料夾重新命名後，可能需要刪除書籍封面快取資料庫以回收一些空間。該操作可透過下列選單中執行：

（檔案瀏覽器中的）頂部選單 / / 設定 / 陳列及詳情檢視設定 / 書籍資訊快取管理
刪除檔案快取

當您閱讀 PDF/DJVU 文件時，KOReader 會保留您閱讀的最後一頁的快取。所以當你重新開啟這本書時，它會更快。但是，如果您長時間使用 KOReader 並閱讀許多 PDF/DJVU 文件，則此快取可能會變大。這些快取檔案儲存在 KOReader 安裝目錄下的快取資料夾下。要刪除此快取並回收空間，您可以轉到：

（檔案瀏覽器中的）頂部選單 / / 更多工具 / 開發者選項 / 刪除快取
 請僅在確實需要騰出空間時才清除此快取。若空間充足，清除快取不會帶來任何好處，反而會降低效能，因為閱讀器必須重新渲染這些頁面。
什麼是每夜版？

KOReader 有兩個不同的版本分支：

  • 穩定版 該類版本是 GitHub 上 Releases 釋出頁提供的主力版本，其檔名形如「KOReader 2024.11」，意為該版軟體釋出於2024年11月。該類版本大致上按月度釋出，但有時釋出間隔也會更久。
  • 每夜版 該類版本會每天持續編譯釋出以便及時合併最佳化和修復。每夜版面向嚐鮮者及開發者這類小群體使用者，因此軟體穩定性可能欠佳。

通常來說，穩定版是適合普通使用者的版本。但某些特殊情況下，使用者可能需要每夜版：

  • 你的裝置非常新（例如最近釋出的 Kobo 型號），並且剛剛在最近的一個晚上添加了 KOReader 支援。
  • 存在特定於你的裝置的錯誤或問題，該錯誤或問題已修復但尚未釋出。而且你不想等待穩定版本進行此修復。
  • 更新 KOReader 後，你注意到你正在使用的功能已被刪除。你不想丟失此功能，因此你可以安裝仍然具有此功能的夜間版本。當然，你也可以返回到以前的穩定版，但每夜版會更新，因此可能會有更多功能和修復。

本節只是對該主題的一般介紹。有關每夜版的詳細資訊和尋求幫助，你可以存取討論頁面：FAQ: 如何追蹤最新的每夜版

 在 Android 裝置上使用 KOReader 時，可利用 Android 系統的 Work Profile（工作資料） 功能測試每夜版，而不會影響主力安裝的 KOReader。Shelter 和 Island 等開源應用可以幫你實現這一點。
