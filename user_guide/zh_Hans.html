2 基本用法
2.1 传输文件

KOReader 支持 PDF/PDB/XPS，EPUB/MOBI/FB2，DJVU，CBR/CBT/CBZ，DOCX/RTF，HTML/HTMLZ，TXT/MD 和 CHM 等格式的文件，还可打开 ZIP 压缩包并显示图片文件。

有许多方法可以将书籍传输到阅读设备。请注意，KOReader 可能需要重启（如果是在 Pocketbook/Android 上则是刷新目录）以完成对新传输文件的索引。

除了以与内置阅读器应用程序相同的方式传输文件外，根据你的设备不同，还有其他选项可供选择：

  1. KOReader 内置的 USB 大容量存储模式：KOBO 及部分 CERVANTES 型号支持该功能。
  2. 云存储（Dropbox/FTP/Webdav）：使用该功能前，须通过下方展示的菜单项登录云服务账号。详细操作步骤可在添加账号时点击菜单中的说明按钮查看：
    （文件浏览器中的）顶部菜单 / / 云存储
  3. SSH/SFTP 访问：KOReader 可作为 SSH 服务器，以便使用电脑传输文档（该功能支持 Kobo、Kindle、Cervantes 的阅读器）请使用 SFTP 软件（如 Filezilla）或文件浏览器（部分操作系统内置）请查阅维基页了解具体操作流程；另请注意下方的警告注释栏内容。
  4. Calibre 传输：借助 Calibre 插件，可通过 Wi-Fi 直接从 Calibre 书库将书籍发送到 KOReader 中。请查阅维基页了解操作方法。
  5. 新闻下载器：该插件可以 HTML 格式下载 RSS 及 Atom 订阅源提供的文章。请查阅维基页了解操作方法。
  6. OPDS（开放出版发行系统）书目：你可以访问公共书目，或使用自己的服务器访问书库。更多信息见 使用 OPDS 书目
  7. Wallabag：此插件可以从 Wallabag 中拉取文章，这是一款自托管的类 Pocket 稍后阅读软件。请查阅维基页了解更多信息。
 在不设置密码的情况下使用 SSH 功能应当额外谨慎，因为这将使阅读设备可被公开访问。不过如果只是临时开启设备 Wi-Fi 且接入的是家庭 Wi-Fi 网络，这个风险是可以忽略的。

3 认识本软件用户界面

KOReader 采用简洁的以黑白为主的用户界面，这是因为渐变色和不同深浅的灰色会导致电子墨水屏出现闪屏和残影现象，从而影响阅读体验。

KOReader 有两套核心界面：阅读界面及文件浏览器。接下来将先介绍阅读界面；文件浏览器请前往本指南对应章节了解。

3.5 底部菜单项
 长按底部菜单中的选项名称，KOReader 就会显示该选项的说明。

阅读模式：切换到页面连续模式，可以像浏览网页一样滑动阅读书籍。该模式更适合配备非电子墨水屏（LCD、OLED）的阅读设备。在页面连续模式下，页面的顶部和底部页边空白将被裁切，因此首行和末行文本可能会被裁掉。启用页面重叠可以避免这一问题：

顶部菜单 / / 页面重叠

渲染模式：该选项决定 KOReader 如何呈现页面。默认设置为网页且通常无需改变。当某本书籍（或缓存的网页）使用了复杂排版（指定了页面宽度或页边距，使用了负边距或浮动元素等），版式出现错乱或内容溢出屏幕时可尝试其它渲染模式。

缩放（dpi）：该选项可视为文档全局缩放比例（不会影响字号）。在默认设置 96 dpi 下，书籍中的图片将以原始尺寸呈现。简单来说该选项可以在放大图片的同时保持文字大小不变。

文字间距和文字扩展这两项设置彼此关联，共同决定文字在两端对齐时的样子。文本两端对齐时，词与词之间的空白会被加大，使每行文字的左右边缘都与页边距对齐。由于每行的字数并不总是相同，两端对齐时文字需要被压缩或拉伸以填满一行。

文字间距：为容纳更多文字，一行文字中的空白允许被压缩的程度。该选项不会影响文字，只会改变文字的间隔。

文字扩展：当一行文字中有太多空白时，将这些空白分拆到字母之间而使单词被拉伸的程度。该选项将影响单词的样式。若不希望单词被拉伸，请将该选项设置为无。

请自行探索各种选项组合，让文本呈现自己喜欢的样式，然后在各选项对话框中将所选设置保存为默认值。

对比度和字重影响文字笔画浓淡。这两个选项都可以让文本呈现某种样式，但它们的技术原理不同。当然，这两项可以同时生效。

两个选项间的区别可以这样概括：

对比度

+ 不改变字体宽度，不影响书籍总页数

+ 无需对书籍进行重渲染，调整速度快

- 在 LCD 或低 DPI 屏幕上可能影响观感

字重

+ 如果已安装，将使用适当字重的字体

+ 在 LCD 和低 DPI 屏幕上观感更佳

- 需要重新渲染字体，调整速度慢

字距微调是调节特定字母组合之间的间距以提升视觉效果的功能。默认的最佳选项可能会拖慢书籍打开速度（受阅读设备性能影响），但对连字（如下图所示）、连笔阿拉伯字形及某些书体的支持更好。若阅读设备性能较差可将改为较好选项，在保证拉丁字母书体正确显示的前提下提升设备响应速度。

字体微调是一种排版技术，通过调整字体中的字形来适配低分辨率的像素网格（例如电子墨水屏）。启用后字形会更清晰、更易辨认，代价是原始字体设计会略微变形。

字体微调的差异在标准分辨率屏幕上或使用较小字号时更明显。在分辨率非常高的屏幕上，由于像素足够小，差异要小得多。

下面是更详细的对比：

关闭字体微调

  • KOReader 按字体真实的数学轮廓显示字形，不强制它对齐到像素网格。

开启字体微调

  • 字体会被调整以适配屏幕的像素网格，字形可能与原始字体略有差异。
  • 字体可能显得略微柔和、模糊或不够均匀（例如字母「M」的两条竖线看起来粗细不一）。
  • 字体显得更清晰、更锐利、更扎实，各字母的笔画粗细一致。

在 KOReader 中，字体微调默认启用，并使用 FreeType 库的微调算法，而非字体内置的指令（出于稳妥考虑，字体内置指令可能存在缺陷）。不过也可以改用字体设计师嵌入字体文件中的指令，看看效果是否更好：

  1. 关闭 已禁用字体微调。
  2. 原生 KOReader 使用字体内置的微调指令。
  3. 自动（默认开启）KOReader 使用 FreeType 的微调算法，忽略字体内置的微调指令，对中日韩文字的处理更好。

顶部状态栏是对 EPUB、HTML、DOCX、RTF、TXT 等可重排格式的文档启用一块补充状态栏。启用该功能后，可通过下列路径详细配置顶部状态栏：

顶部菜单 / / 状态栏 / 顶部状态栏

图片缩放决定书籍中的插图如何呈现。最佳选项可获得更好的观感，但会拖慢阅读设备。

4.5 页码编号

KOReader 状态栏中的页码会因文档类型而异；有些是固定的，另一些则会动态调整。下图概览了 KOReader 的页码编排体系。阅读本节时，可随时回看这张图表。

如图所示，KOReader 能够打开的文档可分为以下两类，下文将分别说明：

固定版式文档

PDF，DjVu 和 CBR/CBZ 都属于这类文档。这类文档又称不可重排文档，其版式是静态的。这意味着页面上的每个元素（文字与图像）都有精确定位，无论在大屏还是小屏设备上阅读，位置都不会改变。您所看到的版式始终与印刷页面完全一致。

固定版式文档只有静态页码。在 KOReader 中打开这类文档时，状态栏中看到的页码属于文档本身。静态页码不会随阅读设备的类型或屏幕尺寸而改变。

可重排文档

EPUB、MOBI、AZW、HTML 都属于这类文档。这类文档的版式并不固定。也就是说，文字及其他内容会自行调整（重排），以适配您阅读文档时所用屏幕或窗口的大小。

可以把这类文档想象成很长的文本文件或网页，它们本身自然没有分页。打开这类文档时，KOReader 会在首次打开时把这份长文档切分为屏幕大小的页来计算页码。因此，若在 10 英寸阅读器上打开文档，书的总页数会少于 6 英寸阅读器，因为更大的屏幕单页能容纳更多文字（每页字数越多 = 总页数越少）。

这也意味着，如果您改动文字外观，例如把字体调大，页码也会随之变化。因为字号变大后，屏幕能容纳的文字变少，总页数就会增加。

固定页码

由于页码会不断变化，可重排文档的页码并不太适合用作引用参照。如果您同时在电子书阅读器和电脑上打开某个 PDF 文件（固定版式文档），第 42 页在两台设备上显示的内容始终相同。但对 EPUB 文件而言，一台设备上的第 42 页与另一台并不相同。

此时您可能会问：“像 EPUB 这样的可重排文档，能不能拥有固定不变的页码？”可以，借助 固定页码功能即可实现。KOReader 提供两种固定页码：


- 出版方页码：

KOReader 支持出版方页码功能，出版方可利用该功能把印刷版书籍的页码直接嵌入电子版中。启用该功能后，KOReader 不会自行计算页码，而是显示出版方提供的内嵌页码。这样一来，您在状态栏中看到的页码便与印刷版一致。

若要启用该功能，请按照下列路径操作：

顶部菜单 / / 设置 / 固定页码 / 使用固定页码

如果同时勾选了该菜单中的在边缘显示固定页码选项，这些出版方页码将以小号字体显示在正文旁。


- 每页字符数：

如果您的书没有出版方页码（大多数书都没有），却仍需要固定页码，该怎么办？

此时可以启用 KOReader 的 每页字符数功能。使用该功能后，KOReader 会按照设定的 每页字符数来计算页码，而不再依据屏幕尺寸。例如，您可以把 KOReader 设为“把 1500 个字符算作一页”（这是该设置的默认值，大致相当于英文 250 个单词）。而约 250 个单词正是标准大众市场平装本/PA5 开本图书一页的容量。

因此启用该功能后，书的总页数会接近按上述尺寸印刷的实体书。当然，您也可以在菜单中调整 每页字符数设置，以模拟不同开本的书籍。

如果您手头有某本书的纸质版，可以调整 每页字符数的数值，使总页数与纸质版一致，这样便更容易在另一版本中定位到同一段落。

启用固定页码功能后的变化

为某份文档启用固定页码后，会发生以下变化：

  • 状态栏中的已读、剩余及总页数会切换为固定页码。
  • 文件浏览器会按固定页码显示这份文档的总页数。
  • 书签、目录和页面预览也会显示固定页码。
  • 若从这份文档导出高亮，导出文件中高亮与笔记的位置信息将使用固定页码。

有写书籍或文档可能附有大篇幅的脚注或参考书籍。比如一本 250 页的科学类书籍最后 50 页全是附录、专业术语索引及参考文献。通常情况下这些页码仍会被计入阅读进度条和阅读时间统计。但这些章节大多只作为参考，并不需要逐页阅读，因此可能希望将其排除使页码计数和预估阅读用时更加准确。再比如一本选集中包含了一些已经读过的篇章。自定义隐藏页功能可以将这类章节排除出去。

页码段被隐藏后的表现：

当按照上述步骤创建隐藏页后 KOReader 会将其视作不存在，类似于从纸版书中撕下部分书页：

  • 翻页时将直接跳过隐藏页。例如将第十章标记为隐藏页后，从第九章的最后一页继续翻页将直接显示第十一章。
  • 页码计数将无视被隐藏的页码段继续增加。
  • 被隐藏的章节将不会显示在进度条上（请另行阅读下方解释），且不会被计入阅读用时。但这些页码仍可通过快速翻页工具访问。
  • 链接到位于被隐藏页页面的引用仍然有效。隐藏页的页面也可通过目录、书籍地图、页面预览和快速翻页工具访问。

如上所述，隐藏页将不会被计入进度条。但如果使用上一条提到的几种方式访问隐藏页的某一页，进度条将临时变为该隐藏页的章节进度条。可以把这想象成进度条放大到了被隐藏的章节。当翻到隐藏页最末页、或使用其它页面定位工具离开被隐藏的章节，进度条将恢复为显示全书阅读进度，此时自定义隐藏页将从进度条上消失。

5.1 如何保存设置

设置完这些之后，您可能会问：“我的其他书也会变成这样吗？”不会，并不会自动生效。因为所有这些改动只对当前书籍有效。

在其他阅读器应用中，当你更改某项设置（例如书籍所用字体）时，更改会全局生效。也就是说，如果你把默认字体改为 Verdana，此后打开的所有书籍——包括你正在阅读的——都会以这种 Verdana 字体显示。

KOReader 的做法与此不同。外观设置是按书籍分别保存的。这使你可以灵活地更改当前书籍的设置，而不影响其他书籍。例如你有一些奇幻小说，可以只把这些书的字体换成中世纪风格。也可以将某些书籍设为以横屏或双栏模式打开。

KOReader 的机制是这样的：

  1. 字号、行间距等 KOReader 设置都有默认值。
  2. 打开一本新书时，KOReader 会参照这些默认值来设定书籍外观。
  3. 在某本书里所做的改动（例如调整文字大小）只影响这一本书。因为这些改动不会修改默认值，所以新打开的书不受影响。
  4. 不过你也可以把改动保存为默认值，这样一来，新打开的书籍同样会采用这些设置。

在刚才的操作中，我们把书籍的 字重调到了 +1.00。现在打开 字重菜单，点按 字重设置行末尾的 三个点。此时会弹出一个对话框，显示 默认值：+0.00。这表示打开另一本书时，其字重仍为 0（默认值），而不是我们之前设定的 +1。

KOReader 字体系统的技术细节与故障排除 

如果在向 KOReader 添加字体时遇到字重方面的问题，本节可帮助你理解 KOReader 的字体处理机制：

  1. 启动时，KOReader 会读取各字体内嵌的字体元数据/信息来整理可用字体，并按字体系列和字重分类。KOReader 会尝试从字体所含元数据中判断字体系列信息，因此把字体复制到设备时字体名称并不重要。
  2. 如果某个字体系列有多个字体文件，KOReader 会尝试把它们归入以下 4 类之一：Regular, Bold, Italic & BoldItalic。理想情况如下：
    • Luciole-Regular.ttf 映射到 字重：0 (Regular 400)
    • Luciole-Bold.ttf 映射到 字重：+3 (Bold 700)
    • Luciole-Regular-Italic.ttf
    • Luciole-Bold-Italic.ttf
    如果某个字体变体不存在，或需要进行小数级的微调，KOReader 会从最接近的可用字重合成得到。
  3. 如果某款字体只提供一个文件、且并非 Bold，KOReader 会把它指定为 (Regular 400) 的 字重：0，并自行合成其余所有字重与变体。换句话说，KOReader 会为这款字体“伪造”斜体和粗体。（如果这唯一的字体文件是 Bold，KOReader 则会由这个粗体合成出 Regular 字重。）

 如果在底部菜单中长按 字重标签，就会显示当前字体提供了哪些字重级别。

 如果你的字体还有其他变体，情况就可能变得复杂。假设你把一整个字体系列复制到了设备上，启动时 KOReader 读到了该字体的以下变体，顺序为：Light、Thin、Normal、Medium、ExtraBlack、SemiBold、Bold、Black。你可能以为 Normal 变体会被用作文档的正文字体（因为它的名字就叫 Normal），但 KOReader 实际会选用 Light，因为它是列表中第一个不带粗体标记的字体。而 Thin、Normal 和 Medium 变体会被忽略，因为 KOReader 已经为文档找到了一个“非粗体”字体。

同样按这个列表，ExtraBlack 会被用作粗体字体，因为它是列表中第一个带有粗体标记的字体。而 SemiBold, Bold, Black 变体会被 KOReader 忽略，因为它已经找到了所需的“粗体”字体。

小结一下：我们复制了整个字体系列，本以为会选中 Normal 和 Bold 变体，结果 KOReader 却用了 Light 和 ExtraBlack。这是因为字体送入 KOReader 的顺序不受我们控制，只能“先到先得”。

解决办法是只传入你希望使用的字体文件，例如：

  • Thin、Extra Light、Light、Normal、Medium 中只保留一个：它会被用作常规字体（如果你的 Regular 字体太细，且手头有 Medium 字重，换成它即可）。
  • Semi Bold、Bold、Extra Bold、Black、Extra Black 中只保留一个：它会被用作粗体字体。
  • 也可以额外加入同字重的斜体变体（例如 medium/medium-italic）。
5.3 样式微调 

KOReader 的样式微调功能允许你修改 KOReader 显示书籍的方式。我们不会在这里进行完整的 CSS 课程。我们只想向你展示一些基本的东西，这样当你看到一个样式微调时，你至少会有一个大致的概念。

什么是样式微调？

我们可以将 EPUB 文档描述为 HTML 文件 + 一些 CSS 规则。这些 CSS 规则决定了书籍的不同部分（标题、粗体文本、引用等）在阅读应用中的显示方式。借助样式微调，你可以通过添加新规则和/或覆盖书籍中嵌入的、由出版方编写的规则，来更改书籍的呈现方式。

让我们看一个样式微调的例子：

img { width: 10px !important; height: 10px !important }

用通俗的语言来说，这条规则是：忽略它们的原始大小，让这本书中的所有图片都有 10 个像素宽，10 个像素高。因此，如果你将此样式微调添加到 KOReader，你书中的所有图片都将显示的很小。

现在让我们逐项解释这个调整：

  • img - 这是一个 CSS 选择器，目标是书籍中的所有 img（图片）元素。
  • { width: 10px !important; height: 10px !important; } - 这是声明块。它包含将应用于所选 img 元素的样式。
  • width: 10px !important; - 第一部分将目标 img 元素的宽度设置为 10 像素。!important 声明是一个覆盖开关，它确保您的宽度值优先于应用于这些图片的任何其他现有 width 声明。
  • height: 10px !important; - 这部分将目标 img 元素的高度设置为 10 像素。同样，!important 是一个覆盖开关，可确保您的高度值优先于应用于这些图片的任何其他现有 height 声明。

总之，这个 CSS 规则旨在将你的书中的所有 img 元素设置固定宽度和高度为 10 像素，并忽略其原始样式。

一些有用的样式微调示例

这些是一些有用的样式微调，你可以直接使用或根据自己的喜好进行修改。下一个标题解释了如何在 KOReader 中使用它们。

  • 在书籍中的每个标题上方添加分隔线：

    H1, H2, H3, H4 { border-top: 2px solid black; }

  • 在标题上方添加一些边距：

    H1, H2, H3, H4 { margin-top: 2em !important; }

  • 或者，如果书的标题上方的边距过多，请将其删除：

    H1, H2, H3, H4 { margin-top: 0 !important; }

  • 在段落之间添加一个小间隙，使文本更具可读性：

    p + p { margin-top: 0.5em !important; margin-bottom: 0.5em !important; }

  • 禁用EPUB中的所有图片：

    img { display: none !important; }

  • 使图片非常小，而不是禁用它们：

    img { width: 10px !important; height: 10px !important }

  • 使计算机科学书籍中的代码块部分更整洁、更易读（在这里你可以看到一个例子）：

    pre,code { font-size: 0.6em !important; line-height: 1.8em !important; background-color: #eee !important; margin: 1em 0 !important; padding: 1em 0 !important; }

2. 将文件传输到你的设备：

要在快捷菜单中添加微调，首先必须将其添加到上述标题中描述的操作列表中。然后，你可以按照本指南快捷菜单部分的说明进行操作。

你甚至可以将这两种方法结合起来，为你的样式微调创建一个特殊的快捷菜单，然后将其分配给一个手势。这样只需一个简单的手势，你就可以访问所有的样式微调，并根据需要激活它们。

查找要修改的元素

请注意，在某些书籍中，标题可能不在 <H1> 或 <H2> 元素中，而是在类似 <p class="tit123"> 的内容中。你可以通过检查源代码来查找用于文本部分的选择器。要实现这一点，请选择你感兴趣的元素周围的文本，然后从对话框中选择查看 HTML。在上面的示例中，你的样式微调看起来像这样：

P.tit123 { border-top: 2px solid black; }

而不是这样：

H1 { border-top: 2px solid black; }

6.1 高亮模式

KOReader 提供两种不同的高亮模式：

普通模式

普通模式与在手机或平板电脑上用手指选择文本类似，适用于高亮文段在同一页内的情况。

  1. 在要高亮文段的首字上长按
  2. 移动手指到要高亮文段的末尾
  3. 抬起手指

当划到页面边界时，KOReader 会自动翻页以保持高亮连贯（仅对 EPUB 和 HTML 文档有效）。该功能可通过下列路径禁用：

顶部菜单 / / 点按与手势 / 在文字上长按 / 在选区到达书角时自动滚动页面
 当你想长按靠近边角的文字时，边角长按手势可能会造成干扰。我们提供了专门的手势管理器动作，可用来切换或临时禁用边角长按手势。你可以将这些动作指定给某个手势，或放入快捷菜单中使用。可在此处找到它们：
顶部菜单 / / 手势管理器 / 「任意手势」 / 设备 / 切换┆忽略边角长按
选择并进入高亮模式

选择并进入高亮模式更适合跨页的长段落高亮。在该模式下无需用手指在屏幕上滑动即可完成高亮，因此对阅读设备的触控灵敏度不佳，或用户较难控制手部运动的情况尤为有用。

 如果开启查阅词典功能，在长按某个文字时需拖动才能启动该模式。
顶部菜单 / / 点按与手势 / 在文字上长按 / 在词典中查询选中单字

高亮的方法：

  1. 在要高亮文段的首字上长按（如果启用了查找词典功能则是对首字拖拽）呼出菜单。
  2. 点按多选选项进入高亮模式，此时屏幕左上角将出现一枚图标（可点击该图标获得更多信息）。再次点按高亮起始处可取消高亮。在高亮模式下可使用点按或滑动翻页，并可使用目录或快速翻页工具前往任意页。
  3. 在高亮的末字上长按菜单会再次显示；若启用了查询词典功能，则通过拖拽末字呼出菜单。
  4. 现在点按高亮即可完成对文段的高亮。

通常情况下该对话框将显示在屏幕中间。如果希望对话框显示在高亮位置附近，可以将菜单第二页的中间选项改为手势位置：

顶部菜单 / / 点按与手势 / 在文字上长按 / 高亮对话框位置
 若不需要上图所示的文字长按菜单，有更简单的方式进入该模式。在完全禁用长按文字的弹出菜单后，长按将直接进入选择及高亮模式。这种方式更快捷，只需点按两次即可高亮任意长度的文段。启用下列选项来使用该功能：
顶部菜单 / / 点按与手势 / 在文字上长按 /选择并高亮
 KOReader 可以高亮包含不同样式的整篇文章。浅色选项将使文段背景变为灰色。受限于 e-ink 技术特性屏幕无法直接从白切换为灰色，所以被高亮的文段将先变黑然后再变灰。要避免这种屏幕闪烁，请选择反色作为高亮样式。该选项将使文段背景变黑所以无需屏幕闪烁。请在下列路径中调整高亮选项：
顶部菜单 / / 高亮样式
 同一文段可被多次高亮及添加笔记。若多层高亮重叠在一起，点按高亮处会弹出菜单以供选择想要编辑的高亮。
高亮时自动纳入标点

在进行高亮操作时，KOReader 会尝试将与选段相关的标点符号纳入高亮。例如，当从头到尾高亮一个句子时，KOReader 会自动将句子两端的标点符号一并高亮。

但如果从句子中间开始高亮，KOReader 会认为用户只是想高亮句子片段，因此不会自动包含句末标点。若要将标点包含在高亮中，请在选择时选中完整句子。之后也可长按编辑高亮按钮补上标点符号。

编辑被高亮的文段文本

除了添加笔记，KOReader 还支持直接编辑书签列表中显示的高亮文本。在某些情况下，这可能比为高亮添加笔记更实用。比如要标记包含多项日期的句子但其中一项日期有误，而要添加一条笔记来指出错误，得在笔记中明确写明。但如果可以直接编辑被高亮文本，就可以直接在有误的日期后写上「该日期需要再次核对」。

请注意，此编辑操作不会改变页面上显示的被高亮文段，阅读时看到的仍是书籍原文。编辑内容要在书签列表界面查看；在导出高亮时，被导出的文本会是编辑后的版本。

要编辑被高亮的文本，请按如下步骤操作：

  1. 点按高亮文段
  2. 在弹出菜单中点按详情
  3. 在详情对话框中点按编辑文本

你也可以从书签窗口中进行操作：

  1. 通过点按菜单或手势打开书签列表
  2. 长按想要编辑的被高亮文段
  3. 在菜单中点按编辑文本
  4. 在弹出对话框中修改文字，然后点按保存按钮

若要将编辑后的文本撤回到书籍原文，按上方所属步骤操作但在第三步时不要点按编辑被高亮文本，而是点按还原原始文本按钮。

更改添加的笔记在书签列表中的显示方式

通常情况下，书签列表中仅会列出用户对文段的高亮。如果高亮附带笔记，只会在书签列表中显示一枚铅笔图标。可以长按列表中的某一项高亮以查看（并编辑）附带的笔记。若要在书签列表中同时展示笔记，可按照下列路径设置：

顶部菜单 / / 设置 / 书签 / 书签界面中的展示元素

有如下几种显示方式可供选择：

  • 仅显示高亮文段（默认设置）
  • 同时显示高亮文字及笔记
  • 存在笔记时仅显示笔记，否则显示高亮文段
 通常情况下，书签窗口中的项目是数量固定且均匀分布的。若要使用更加灵活的版式，可在下列菜单中调整每份书签的最大行数选项：
顶部菜单 / / 设置 / 书签 / 每条书签的最大行数
6.3 导出高亮

在读完一本书后，可以将其移到指定文件夹作为存档。启用移至存档插件，指定存档目录路径（设置存档文件夹）。完成设置后，可通过下列方式将书籍移入存档：

  • 移至存档插件菜单
  • 利用指定的手势或者
  • 使用快捷菜单中的入口

KOReader 提供多种导出高亮和笔记的方式：

1、使用导出高亮插件

这款多功能插件可以将高亮导出为本地文档或上传到云服务。


本地导出

高亮可被导出为以下几种文件格式：

  • 纯文本（.txt）
  • HTML 网页（.html）
  • Markdown 文档（.md）
  • Kindle 笔记与摘录（.txt）
  • JSON 文件（.json）

可以在下列菜单中选择想要使用的导出格式：

顶部菜单 / / 导出高亮 / 选择文件格式及服务商

可以在下列菜单中查看（或修改）导出文件存放目录：

顶部菜单 / / 导出高亮 / 选择存放文件夹

在线服务

还可通过网络将高亮导出到下列服务平台：

  • Joplin - 一款笔记应用程序
  • Readwise - 一款在线书签及高亮软件
  • Memos - 一款自托管的开源备忘录
  • Flomo - 一款在线笔记服务
  • XMNote - 一款安卓平台的中文界面书签管理软件

这些服务的详细操作指南可以在维基页上查阅。


在选择导出格式后，可以在该插件菜单中导出当前书籍或个人书库中全部书籍的笔记。

KOReader 中普通高亮的工作原理

当用户在 KOReader 中高亮文段，不管是在 EPUB 还是 PDF 文档中，这段高亮会被写入一个设置文件。例如在阅读 Alice in Wonderland.epub 时，在书籍文件所在目录会生成一个名为 Alice in Wonderland.sdr 的文件夹。高亮数据会存储到这个 .sdr 文件夹中的文件里。倘若这个与书籍关联的 .sdr 文件夹被删除，书籍中的高亮也会丢失。


KOReader 中 PDF 文档高亮的工作原理

PDF 文档的高亮功能与上述说明有所不同。如前所述，保存 PDF 高亮时，高亮数据会被直接写入到 PDF 文档中，成为文档的一部分。这就是为何该 PDF 被发送给其它用户后对方可使用兼容的 PDF 阅读软件查看高亮。对方无需获得包含了高亮记录的关联 .sdr 文件夹，因为高亮已被直接嵌入 PDF 文档中。

让我们通过一个例子来解释使用此功能时可能出现的问题。想象一下，你正在使用 KOReader 在电子阅读器上阅读 PDF 书籍:

  1. 若将高亮保存到 PDF 文档选项开启，KOReader 会在做下高亮的同时将高亮写入 PDF 文档。
  2. 你想继续用 KOReader 在你的手机上阅读这本书，所以你把这个 PDF 文件从你的电子阅读器复制到你的手机上（但是你没有复制 .sdr 文件夹，只有 PDF 文件）。
  3. 当用手机上的 KOReader 打开书籍，可以看到高亮仍保留在书籍中。

此时两处设备上的情况是一致的，电子书阅读器和手机上的 KOReader 都能查看 PDF 文档中的高亮。但两者仅是看起来一样，实际却有很大不同。

电子书阅读器上的 KOReader 知道此 PDF 文档中的哪些高亮是由 KOReader 添加的，因为它有关联的 .sdr 文件夹。但手机上的 KOReader 则不知道这些信息，它只能读取 PDF 文档。

在尝试删除或导出 PDF 高亮时差异就更大了。电子书阅读器上的 KOReader 即可删除也可导出高亮，但手机上的 KOReader 则不能。如前所述，它缺少文档关联的 .sdr 文件夹，所以它无法区分哪部分是高亮，而只能将高亮视作原文的一部分。

所以简单来说，如果打算之后导出 PDF 高亮，务必在备份或复制 PDF 文档到其它设备时将关联的 .sdr 文件夹一并复制。

8.4 优化漫画

对喜欢在电子墨水屏设备上阅读漫画的用户，下面有一些提升阅读体验的小技巧。若漫画在设备上的呈现方式不尽如人意，对漫画书文件进行预处理是最佳解决方案。

使用哪种文件类型

MOBI 和 EPUB 等文件类型不适合主要处理图片内容（例如漫画/漫画）。KOReader 中的 MOBI 支持几乎为零，而 EPUB 的文本渲染优先级在显示整页图片时可能会导致问题。有关更多技术细节，请访问对应 GitHub 工单。

最好的选择是创建一份在 KOReader 中效果更好的 CBZ 格式文件。.cbz 扩展名的文件本质上是将未压缩处理的图片集打包而成的 ZIP 压缩包，内含通常为 .png 或 .jpeg 格式、按照漫画页码排序的多个图片文件。KOReader 也支持打开 CBT 格式文件，它与 CBZ 相似，区别是使用 TAR 格式打包。

将漫画转换为 CBZ 的最简单方法是从各种网站获得漫画图片，然后使用 Kindle Comic Converter 转换它们。有一些有用的设置，如自动将跨页双页旋转为横向并应用抖动，使墨水屏渲染的渐变平滑抖动，没有锯齿层。

使用哪种分辨率

通过将图片大小调整为电子阅读器屏幕尺寸，可以获得最佳效果。特定于屏幕的 CBZ 针对设备的确切屏幕尺寸，可防止在读取期间重新缩放。KOReader 在阅读时将图片缩放到屏幕尺寸，但不建议这样做，因为 KOReader 在缩放之前添加了抖动通道，这会导致质量损失。

但是，如果你想在多台设备上使用手工制作的 CBZ，或者你想保留高分辨率以备将来使用，那么最好的选择可能是为你的最高分辨率设备制作 CBZ。或者选择可能与源分辨率匹配的"高"分辨率。300 PPI 或更高（450 甚至 600），当然，除非来源较低。我们假设屏幕尺寸为8"，1500×2000，这是一个不错的目标分辨率。对于较大的图片，你应该在你的设备上尝试一下，看看它是否可以处理它。例如，内存不足的旧 Kindle 可能会难以处理 3000×4000 等大小。如果你要自动化该过程，则可能需要考虑创建较低和较高质量的两个版本（例如 200/400 或 300/600 DPI）。

- 第三种方式：通过文件搜索功能筛选书籍。该方式可十分高效地处理分散于多处目录的多本书籍。例如，要将书单中所有作者是托尔金的书籍移至同个文件夹，请按下列步骤操作：

  5. 点按所有要处理的文件，然后点按对号图标（√）。该图标位于屏幕左上角，点按后会弹出对话框，其中包含在文件浏览器选择选项。选择该选项。
  6. 现在，你将回到文件浏览器，你在搜索对话框中选择的文件也将在此处选择。
  7. 点按对号图标（√），它位于屏幕右上角。现在可从弹出的对话框中选择要对这些文件执行的操作。

查看文本文件

如果你有 .txt 格式的书籍（在中文和西里尔文语言中更常见），你可以尝试启用自动检测 txt 文件布局功能。在某些情况下，它可以改善渲染效果，使文本更"像书"。启用后，渲染引擎将使用启发式方法（文本被包裹在一些最大行长下，标记段落的单行或双空行，缩进或被视为标题的居中文本…）来猜测如何更好地渲染文本，并尝试创建一个目录。

你可以在此处启用此功能（仅当你正在读取 .txt 文件时才可见）：

顶部菜单 / / 样式 / 自动识别TXT文件的版式

请注意，此功能可能会弄乱 ASCII 艺术绘图和基于空格字符的格式。如果你的书籍具有这些功能，最好使用默认模式，在该模式下，文本文件以等宽字体按原样呈现。

查看存档文件

KOReader 可以读取存储/压缩在 ZIP 压缩包中的文件。你可以使用存档查看器打开 ZIP、CBZ 和 EPUB（因为它们也是 ZIP 压缩包）文件以查看包含的文件：

  1. 在文件浏览器长按文件名
  2. 点击打开方式…
  3. 点击存档查看器

ZIP 压缩文件可以包含多种类型的文档，如 HTML、TXT 或图片。只有当你提示 ZIP 压缩包中的文件类型时，KOReader 才能正确打开你的 ZIP 压缩包。如果你只给文件一个 .zip 扩展名，KOReader 将假定该压缩包仅包含图片，并尝试像 CBZ 文件一样打开它。

默认情况：文件名.zip，假定为图片的 ZIP 压缩包（并由 MuPDF 引擎打开）

如果你的 ZIP 压缩包含这些类型之一（而不仅仅是图片），请相应地命名它：

  • FB2格式（FictionBook） - 文件名.fb2.zip
  • HTML - 文件名.htm.zip / 文件名.html.zip
  • 文本日志文件 - 文件名.log.zip
  • Markdown 文件 - 文件名.md.zip
  • 富文本格式 - 文件名.rtf.zip
  • 纯文本 - 文件名.txt.zip

如果文档没有这样命名，则可能使用了错误的读取器/格式引擎，你将看到此文件没有读取器引擎或文件无效消息。你可以按照上述说明重命名此文件，也可以长按文件名，然后选择打开方式…选择正确的引擎。

  1. 在文件浏览器长按文件名
  2. 点击打开方式…
  3. 点击图片查看器
查看 Markdown 文件

KOReader 提供了两种读取 Markdown 文档的选项。

  1. 你可以通过点击它直接打开文档就像一本书。此模式不提供格式设置。所以你的 .md 文件看起来就像在文本编辑器中打开一样。
  2. 你可以将 Markdown 文档转换为 HTML。此操作将呈现具有正确格式的 Markdown 文档中的 HTML 文件，并根据标题创建目录。

要转换 .md 文件，请在文件浏览器中长按该文件，然后从弹出菜单中点击转换按钮。将在同一目录中创建一个同名但扩展名为 HTML 的新文件。请注意，转换可能需要一段时间，具体取决于你的 Markdown 文件和设备速度。

你还可以为 KOReader 无法自动识别的文件类型设置文件关联。要将文件与 KOReader 提供程序之一相关联，请首先在文件浏览器中长按你的文件，然后选择一个提供程序引擎来处理此文件。你可以选择：

  • 或者选择始终对文件类型使用此引擎，将此提供程序与所有与此提供程序具有相同扩展名的文件相关联
  • 在同一对话框中，你可以通过点击查看默认文件类型来查看所建立的关联
9.3 书单

KOReader 的书单功能可以让个人书库的管理更加高效。简单来说，书单就是由用户创建的书籍清单。例如可以创建标题分别为文学和非文学的书单，将对应的书籍编入其中。当然按文件夹存放书籍也可实现类似目的，但书单用起来更加灵活。

使用书单整理书籍相比文件夹的一些优势：

  • 将书籍编入书单并不会移动书籍文件位置，因此存放在不同文件夹中的多本书籍可以被编入同一份书单。
  • 同一本书可以被编入多份书单，这很难通过文件夹实现。例如，一本书可以同时被编入科幻题材书单和战争文学书单。
  • 配置文件 可以应用于书单。如果对 KOReader 的配置文件功能不熟悉，请查阅下文说明。（当然，配置文件也可应用于文件夹，但书单无需移动书籍文件即可临时套用配置文件。）

用户可创建多份书单来对应各种书籍分类方式，例如：

  • 作品体裁：虚构文学、非虚构文学、报告文学等。
  • 阅读状态：在读、想读、已读、搁置等。
  • 丛书：《指环王》、《哈利·波特》等。
  • 文档类型：书籍、科研论文、网页等。
创建并编辑书单

若要创建书单，请按照下列路径找到书单对话框：

顶部菜单 / / 书单

该对话框可在阅读视图或文件浏览器中使用。打开时菜单会列出现有书单。默认情况下将显示一份标题为收藏的书单，其中包含已被添加到收藏列表的书籍。

  • 创建新书单：点按屏幕左上角的汉堡状菜单键 ⇨ 点按创建新书单
  • 删除书单：在书单标题上长按 ⇨ 点按删除该书单
  • 修改书单标题：在书单标题上长按 ⇨ 点按修改书单标题
  • 更改书单顺序：点按屏幕左上角的汉堡状菜单键 ⇨ 点按书单排序
将书籍添加到书单

有三种方式可以将书籍添加到书单中：


一、通过文件浏览器及历史记录视图

可以在文件浏览器或历史记录视图中将书籍添加到书单。历史记录视图下可将书籍逐本添加到书单中。在书籍上长按，选择书单…，然后可以选择将该书添加到一份或多份书单中。

若要一次性添加多本书籍，请在文件浏览器中按照下列方式操作：

  1. 长按某本书
  2. 在弹出菜单中点按多选
  3. 选择其它书籍
  4. 点按右上角的对号（✔️）图标
  5. 点按书单

二、通过书单管理菜单

该方法可以将一本或数本书籍添加到书单中。与在文件浏览器中操作不同，这种方法可以将整个文件夹及下层文件夹内的全部书籍一次性添加到书单。如果书籍文档已经按照文件夹分类，该方法将十分高效。例如，如果全部科幻类书籍都在同一个文件夹内，可以创建标题为科幻题材的书单，然后将该文件夹添加进去。

如上图所示，方框 1 标出了添加书籍选项。该菜单可点按当前书单的汉堡状菜单键呼出：

  • 将整个文件夹加入书单：如选项标题所示，该选项可以将所选文件夹中的全部书籍一次性编入当前书单。请注意，所选文件夹的次级文件夹中的书籍不会被添加。例如，用户选中名为虚构作品的文件夹，其中包含名为科幻作品和战争文学的两个次级文件夹，这两个次级文件夹内的书籍不会被添加到当前书单中。
  • 将所选文件夹及次级文件夹中添加到书单：该选项会将所选文件夹的次级文件夹一同加入书单，使用时应当谨慎，因为该功能会遍历所选的文件夹目录。若其中包含多个目录层级，添加的书籍数量可能会远超用户预期。

给书单中的书籍排序

书单可能十分冗长，因此 KOReader 提供多种筛选方式以便更容易地找到要读的书籍。如前图所示，方框 2 和方框 3 标出了书籍筛选选项。方框 2 可以按照书籍阅读状态（未读、在读、已读、搁置）筛选；方框 3 可以通过书籍元数据（作者、丛书、语种、关键词）筛选。两种筛选方式还可组合使用，你也可以像这个例子一样组合这两组过滤器："向我展示这份书单中 Isaac Asimov（按作者 -> Isaac Asimov）编写的我还没有开始阅读的新书（按状态 -> 未读）。"

在文件浏览器中长按某本书，可以更新书籍元数据或查看书籍信息。在弹出的对话框中长按任意项，可以编辑作者或关键词等书籍元数据。该操作也可通过 Calibre 完成，这是一款便捷管理书籍元数据的第三方软件。

 请注意，Calibre 会改写书籍内部的元数据，因此将文件从 Calibre 中导出后，修改过的元数据仍然有效；但 KOReader 不会修改书籍文件，而是将自定义的书籍元数据以独立文件的形式存储于与书籍关联的 .sdr 文件夹中，因此这些改动的元数据仅可使用 KOReader 查看。
在书单中检索

在书单中有两种不同的搜索操作：在书名及元数据检索关键词，或者在书籍内文搜索。搜索对话框可通过下列路径呼出：

  • 这种搜索可能非常缓慢（书单中的每本书大约耗时 2 秒），如果书单很长，搜索耗时将会非常久。

9.4 优化文档

KOReader 的设计目标是在电子书阅读器有限的硬件条件下也能高效运行。但总会遇到格式糟糕、拖慢 KOReader 的文档。下面将按文件类型给出一些优化文档的建议。

EPUB 文件
  • EPUB 文件基本上由文本和图片组成，并带有一些规则来确定这些项目在屏幕上的格式。在理想情况下，这是一个相当简单的过程，因此 EPUB 文件在 KOReader 中通常速度很快。但是一些 EPUB 书籍添加了大量格式规则，KOReader 必须进行许多计算才能显示哪怕是一个句子。这将减慢打开书籍、翻页和更改外观属性（如字体粗细或行间距）的速度。
     KOReader 不支持固定版式 EPUB 文档。这类文档仍可在 KOReader 中打开，但会作为可重排 EPUB 渲染，版面可能会错乱或难以阅读。
  • EPUB 文件格式本质上是包含 .html 文件的 ZIP 压缩包。有的书籍仅包含单个 .html 文件，而有的则由多个 .html 文件构成，比如每一章节都被拆分为了独立的 .html 文件。如果当前书籍仅包含单个 .html 文件，分段渲染功能就无法启用，因此样式调整会比章节拆分的书籍更慢，因为每次调整 KOReader 都需要对整本书籍进行处理，而不是仅渲染当前章节。
  • 另一种罕见的缓慢情况是内容被包装在 HTML 表格标签中。KOReader 必须在每次翻页时渲染/绘制每个单元格，因此如果一个单元格（包含许多段落）跨越 50 页，这将使翻页速度非常慢。有关解决方案，请参阅下文。

解决方案：

  • 你可以在底部菜单中将内置样式设置为关闭，看看忽略所有文档样式表是否会使其更快（当然，你可能会丢失任何漂亮的格式，但你会知道罪魁祸首是什么）。
  • 如果你具备 HTML 和 CSS 知识，你可以直接从 KOReader 检查 HTML 和 CSS 文件，并自行判断它们的质量或不必要的复杂性。为此，你可以长按某些文本并在弹出菜单中选择查看 HTML。
  • 如果你有上面问题部分提到的"内容包装在表格中"的问题，你可以将这个 table, tr, td { display:block; } 仅本书样式调整添加到：
    顶部菜单 / / 样式微调 / 仅本书调整
  • Calibre 的电子书编辑器可以检查 EPUB 文件是否存在问题，并具有修复某些问题的工具。

    Calibre 可从其项目页面下载。

    书籍检查工具的使用说明可以在 Calibre 的使用指南中查阅。

  • EPUBCheck 软件可用于检查 EPUB 文档的有效性并侦测多种类型的错误。可参阅这条使用 EPUBCheck 检测问题的示例工单。

PDF 文件

PDF 文件可能因以下问题而变慢：

  • PDF 文件本身对于你的设备内存来说可能太大。
  • PDF 文档可能内嵌大尺寸图片文件。即使带有正常文本层的文档（可选中并高亮），仍可能叠加了另一个图片层（页面的整体扫描件）；这会拖慢文档打开及翻页速度，因为大尺寸图片需要被压缩到屏幕尺寸以供显示，而该过程非常消耗 CPU 算力。
  • PDF 文件可能包含许多需要精确定位的单个元素，例如包含大量图片和文本框的杂志页面。在这种情况下，KOReader 必须计算和绘制所有这些元素，这可能需要时间。
  • 自动校直功能（允许你调整页面的倾斜）也可能会减慢你的阅读器速度。
  • 如果你将渲染质量设置为高质量，而重排是开启，文本将更令人愉悦，但它可能比默认慢得多（每页翻几秒钟），具体取决于你的文档。
    底部菜单 / / 渲染质量

不幸的是，对于糟糕的 PDF 文件，没有太多解决方案。通常，处理有问题的 PDF 最好的办法是尝试找到更好的版本。或者，如果有其他文件类型可供下载，例如用 EPUB 代替 PDF（或反过来），也可以尝试该格式。

你也可以尝试把文档转换为更灵活的 EPUB 格式。以下几款软件可在处理 PDF 时提供帮助：

  • Calibre 可以将文档转换为多种格式。它的内置编辑器还可直接修改 EPUB 和 Kindle 等常见电子书格式并修正文档错乱。
  • K2pdfopt 可以为便携阅读设备及手机改善 PDF 和 DJVU 文档。该软件可以对分栏的文档进行编辑，甚至对扫描版 PDF 文件进行文字重排。同时，它可以作为一款通用的 PDF 复制、裁切、调整大小、OCR 等的编辑软件。
  • OCRmyPDF 是一款为扫描版 PDF 文档添加 OCR 文本层的命令行软件，使处理后的文档可以检索及复制粘贴。在阅读扫描版旧书时格外有用。它也可用于压缩图片文件大小。

TEXT 文件

KOReader 拥有非常高效的文本处理引擎，并且会在首次打开书籍时将其缓存，以便下次更快打开。但即便有这些优化，异常庞大的文本文件仍可能耗时更久才能打开。例如，网络上的中文小说动辄数千万字，且通常保存为文本文件。

大型文本文件的问题在于首次渲染书籍以及后续修改文字外观时的延迟。若尝试修改一本非常大的 .txt 书籍的字号，每次调整后都可能明显卡顿，因为整本书都要重新渲染。KOReader 带有分段渲染机制，可大幅缩短此类延迟。但该功能无法用于文本文件，因为这类文件没有按章节拆分（关于分段渲染的更多说明见此处）。

若要享受分段渲染带来的提速，可把大型文本文件转换为 EPUB 格式，方法是使用 Calibre 软件。Calibre 会在转换时自动把文本文件切分为多个较小的独立文件，并打包成标准的 EPUB 文件。转换完成后，更改书籍外观的速度会快得多。可从 Calibre 的页面下载，并查找有关TXT 转 EPUB 操作的在线教程。

9.6 同步阅读进度

如果你在电子书阅读器、手机、平板或台式机等多个设备上使用 KOReader，它可以在这些设备之间同步阅读进度。借助进度同步功能，例如从家里的阅读器切换到通勤路上的手机时，也能无缝续读。

该功能由进度同步插件负责。同步的设置包含以下三个步骤，下面逐一说明：

  1. 创建同步账号
  2. 在希望同步的所有设备上登录你的同步账号
  3. 自动或手动同步阅读进度
1. 创建同步账号

要创建同步账号，请先让设备连接网络，然后打开 KOReader 中的进度同步插件：

顶部菜单 / / 进度同步

然后点按注册/登录按钮。

在弹出的窗口中输入用户名和密码，然后点按注册按钮。这会在 KOReader sync server 上创建一个账号，用于保存你的阅读进度。

2. 登录同步账号

在希望同步的设备上打开同一菜单，输入用户名和密码，这次点按登录按钮。之后，这些设备就会连接到你的同步账号。

你可以为设备设置便于辨识的名称。同样在该菜单中，点按设备主机名，为当前设备输入一个名称。

3. 同步阅读进度

全部设置完成后，即可自动或手动同步阅读进度：

  • 自动同步：要自动同步，请启用自动同步文档菜单项。此后每当关闭书籍或休眠/唤醒设备时，KOReader 都会把阅读进度发送到服务器（当然这需要可用的网络连接）。
  • 手动同步：如果设备因省电或网络条件无法持续联网，可选择手动同步。触发同步的方式有很多种：
    1. 通过菜单：在进度同步插件的菜单中，点按立即上传本设备的进度菜单项，可把当前设备的进度发送到服务器；点按立即从其他设备拉取进度菜单项，可获取服务器上的最新进度。
    2. 通过手势：这些操作（推送/拉取进度）可在手势管理器中找到，你可以把它们指定给任意喜欢的手势。
    3. 使用快捷菜单：你可以将这些操作添加到快捷菜单中。
    4. 通过配置文件：你可以把这些操作添加到配置文件中。尤其配合配置文件的自动执行功能，还能用各种筛选条件触发同步。
文档匹配方法选项

要在两台不同设备上同步某个文档的进度，KOReader 首先必须判定这两个文件是「同一个」。有时这并不容易，因此提供两种方法供你根据使用习惯选择。可在文档匹配方法选项中更改，它位于进度同步菜单内。


二进制匹配（默认）

默认情况下，进度同步使用二进制匹配方法来识别文件。此方法会为文件内容生成一段部分 MD5 哈希（形如 0b229176d4e8db7f...）。文件哪怕只有极小的改动，也会彻底改变这段哈希，因此二进制匹配方法只在两个文件完全一致时才有效。

如果你手动把完全相同的文件复制到所有设备，这种方法应该可行。但如果用 Calibre 向设备发送书籍，二进制匹配就会失效。

因为 Calibre 会把自己的信息（如阅读进度）直接写入文件，从而改变文件哈希的计算结果，KOReader 就会把这两个文件（原始文件与经 Calibre 修改的文件）当成两本不同的书。若遇到这种情况，可改用下面介绍的替代方法。


文件名匹配

这是一种「更宽松」的匹配方法，专为那些文件在不同设备间可能略有差异的用户设计——如上文所述，Calibre 等软件对文档的修改会造成这种差异。

在此方法下，KOReader 只检查两份文档的文件名（含扩展名）是否相同，以此判定匹配。因此，如果你使用 Calibre 或其他书库管理软件跨设备管理书库，可以改用文件名匹配。

 你也可以查阅本指南的书籍元数据存储选项一节，了解更深入的信息。
同步过程的隐私与安全性
  • KOReader sync server 是负责处理 KOReader 同步流程的软件，属于开源项目。你可在其GitHub 页面查看更多信息及源代码。
  • 同步服务器不存储文件名或文件内容。也就是说，服务器无法知道你在读什么。同步某个文档的进度时，只有以下信息会被传输并保存在服务器上：
    1. 用户名（由你自己选定）
    2. 文档的唯一标识（文件的 MD5 哈希，形如 0b229176...）
    3. 本文档的最远阅读位置
  • 你的密码不会存储在服务器上（仅保留其 MD5 哈希）。
  • KOReader 与同步服务器之间的所有通信均通过 HTTPS 加密保护。

9.7 书籍元数据存档

我们先说明 KOReader 的文件删除行为，以便你更好地理解书籍元数据存档功能：

通常，当你把文档复制到设备并首次打开时，KOReader 会新建一个名称类似 your_document_name.sdr 的目录，用来保存该文档的设置、标注和阅读进度。

当你使用 KOReader 的文件浏览器删除文档时，KOReader 也会一并删除这个 .sdr 目录。这意味着该文档的所有设置、标注和阅读进度都会丢失。如果之后再把这份文档复制到阅读器并用 KOReader 打开，就等同于第一次打开它。

但举个例子：如果你想删掉已读完的书（也许是不想让书库杂乱，或者存储空间不足），却又不想丢失这些书里的高亮，该怎么办？书籍元数据存档功能就能帮你做到。


此功能的工作原理：

  1. 首先需要在下列位置选择一个存档位置以启用该功能：
    顶部菜单 / / 文档 / 书籍元数据存档 / 存档位置：
  2. 此后，当你从文件浏览器删除文档时，确认对话框中会出现已启用的该选项：[ ] 保存书籍元数据以归档
  3. 删除时若勾选该选项，KOReader 会把该文档的设置文件复制到你在第一步所选的存档目录中。
  4. 随后 KOReader 会删除该文档及其关联的 your_document_name.sdr 目录。

文档虽已删除，但其设置仍保存在存档中。如果再次把该文档复制到设备并打开，KOReader 会发现存档中存有它的设置，并提示：「此书曾在本设备上打开过。是否从存档恢复其元数据？」点按恢复按钮即可用这份存档设置为该文档找回设置、标注和阅读进度。

你可以在此处查看已归档文档列表：

顶部菜单 / / 文档 / 书籍元数据存档 / 已归档书籍列表

在此列表中，点按文档名称即可查看已归档文档的信息/元数据和书签；也可以把该文档从存档中删除。


当关闭书籍时将元数据保存至存档

如果在上述同一菜单中启用该选项，KOReader 会在关闭每份文档时保存一份设置文件的副本。此后即使你在 KOReader 之外（例如通过 Android 的文件应用，或连接电脑时）删除了文档及其 .sdr 文件夹，仍会保留该文档设置的备份。

 如果启用了当关闭书籍时将元数据保存至存档选项，却在文件删除对话框中取消了保存书籍元数据以归档选项，KOReader 将删除此前为该文档创建的设置存档文件。

 KOReader 通过文件哈希识别被删除的文件。这意味着重新复制回设备的文件必须与被删除的文件完全一致。任何改动（例如写入文件的 Calibre 元数据或添加的 PDF 高亮）都会改变文件哈希。此时 KOReader 无法提供恢复选项，因为它会把该文件视为另一份文件。更详细的信息请参阅本指南的下一节：书籍元数据存储

  • 你可以手动备份和还原每本书的设置。
  • 当你使用 Syncthing 或 Dropbox 等系统执行目录同步或备份时，你的设置将与你的书籍同步。
  • 你可以重命名书籍所在的父目录，这不会导致 KOReader 混淆。

坏处

  • 如果你在 KOReader 文件浏览器之外通过其他方式移动/重命名书籍文件或其附带的 .sdr 文件夹来重新组织你的库，你将在没有任何警告的情况下丢失这些书籍的元数据。
  • 当你使用其他文件浏览器或从计算机浏览库目录时，这些 .sdr 文件夹将可见，这可能会使你的视图变得混乱。
2.单个 KOReader 目录下的元数据目录
顶部菜单 / / 文档 / 书籍元数据文件夹：./docsettings

此方法与上面的默认方法基本相同。不同的是，在这种方法中，你的所有书籍的 .sdr 文件夹都将位于 KOReader 主目录结构下的单个目录下，而不是书籍文件旁边的库目录下。

好处

  • 书籍.sdr 文件夹仅对 KOReader 可见并由其使用。当你使用另一个文件浏览器或从计算机浏览库时，它们不会打乱你对库目录的查看。

坏处

  • 如果你通过在 KOReader 文件浏览器之外移动/重命名移动/重命名库目录、书籍文件或其附带的.sdr文件夹来重新组织你的库，你将在没有任何警告的情况下丢失这些书籍的元数据。
  • 由于你的书籍元数据不在库文件夹中，因此库的任何同步或备份都不会包含它们。
3.单个 KOReader 目录下的单个 HASHED 元数据目录
顶部菜单 / / 文档 / 书籍元数据文件夹：./hashdocsettings

此方法与前一种方法类似，因为 .sdr 文件夹将位于内部目录下。但这种方法是为了解决以前方法的缺点而开发的。因为，通常如果你在 KOReader 之外重命名一本书（使用设备的本机文件浏览器/阅读器或从连接的计算机），其 .sdr 文件夹名称将不再匹配，并且该书的元数据将丢失。如果你只使用 KOReader 文件浏览器进行文件操作，则会自动处理，因此不会产生任何影响。

在这种 HASHED 方法中，.sdr 文件夹不是由书籍的文件路径/文件名标识的。相反，将使用部分 MD5 哈希将书籍链接到其设置。此哈希用作书籍的唯一 ID，并根据书籍文件的内容计算。同样的哈希也用于命名其 .sdr 文件夹。

好处

  • 书籍 .sdr 文件夹仅对 KOReader 可见并由其使用。当你使用另一个文件浏览器或从计算机浏览库目录时，它们不会弄乱你对库目录的视图。
  • 你可以使用其他文件浏览器或从计算机重命名、移动和复制书籍。经过这些操作后，KOReader 仍将识别这些书籍。
  • 在这种方法中，KOReader 将同一个 .sdr 文件夹与书籍的所有副本相关联，即使这些副本位于不同的设备上。例如，如果你正在使用 Syncthing，此方法使你能够在安装了 KOReader 的许多设备上同步你的 /hashdocsettings 文件夹以及你的书籍文件。尽管这些书在每个设备上的相对路径不同，但你仍然可以在设备之间同步标注和进度。这在其他方法中是不可能的。

坏处

  • 任何直接修改文件的操作（如将高亮写入 PDF 文档或从 Calibre 下载高亮）都会使文件发生变化，导致文件的 MD5 校验值发生变化（不过重命名文件或移动文件对此没有影响）。此时 KOReader 无法识别该书籍，因此该书籍的元数据将会丢失。
  • 在浏览较大目录时，计算文件 ID 可能会减慢文件浏览器的导航速度。

快捷菜单是 KOReader 的最新功能，它允许你拥有一个快速访问的个性化菜单，如下图所示。你可以将此菜单分配给一个手势，并通过一次滑动访问它。你甚至可以有一个比你的屏幕更长的菜单，它是可滚动的。

基本上，你可以指定手势的任何操作都可以添加到快捷菜单中。其优点是：

  1. 你不需要为每个动作记住很多手势。
  2. 一些不常见的动作可能不值得一个手势，但在菜单系统中找到它可能太麻烦了。你可以将这种很少使用的操作添加到此菜单中。
  3. 如果你正在为亲戚或朋友安装 KOReader，则可以将他们喜欢的操作添加到此菜单中，以便他们在使用 KOReader 时甚至不需要进入菜单系统。

快捷菜单示例：

创建快捷菜单有两种方法：简单方式和高阶方式。如果你只需要一个菜单，简单方式应该足够你。如果你想用不同的手势显示不同的菜单，你需要使用高阶方式。高阶方式的另一个优点是更容易进行手势重新分配。如果要更改菜单的手势，可以使用高阶方式菜单轻松将其移动到另一个手势。如果你想在使用简单方式时使用其他手势，则必须在新手势下重新创建菜单。

简单方式
  1. 通过以下方式转到手势管理器菜单：
    顶部菜单 / / 点按与手势 / 手势管理
  2. 决定打开菜单的手势并点击它。
  3. 从手势配置菜单中选择要在菜单中显示的动作。当然，你可以一次选择多个操作。
  4. 选择所有动作后，你将告诉 KOReader 将此手势视为菜单。你可以通过在第二页上启用显示为快捷菜单项来实现这一点，如下图中所示。
  5. 你可以使用同一菜单中的排序操作和快捷菜单分隔符选项对菜单项进行排序。

现在，你可以使用所选的手势启动菜单。如果要更改菜单项，可以打开手势页面并添加/删除项目。

高阶方式
 如上所述，如果不打算添加多个快捷菜单，则无需阅读本节。

快捷菜单本质上是一套配置文件，只是以菜单形式显示在屏幕上。使用该功能须先对配置文件有所了解。若是如此请继续阅读，否则请转至配置文件一节（即下一节），创建一套包含若干项的配置文件再回来继续阅读。

在继续之前，我们假设你已经按照上一段中的说明创建了配置文件。现在，我们将把配置文件转换为快捷菜单。

（1）转到新创建的配置文件，在下图所示的菜单中启用显示在操作列表中，这将使该配置文件列入手势管理列表中。在同一菜单中启用显示为快捷菜单，这样该配置文件会显示为菜单列表，而不是在后台静默执行。

（2）现在，我们需要一种访问菜单的方法。转到手势管理器，并从列表中选择一个手势以分配给菜单。假设我们想点击屏幕的一角来显示菜单。现在点按在屏幕四角点按，然后选择左下角。现在点击常规并转到第二页。你将发现你的配置文件显示为「配置文件 X」，其中 X 是你为此配置文件指定的标题。点击其复选框，将你的配置文件分配给该手势。

完成所有步骤后，现在当你点击左下角时，应该会看到你的菜单。你可以通过转到其配置文件页面来编辑菜单，你可以在其中添加或删除项目。此外，那里还有一个排序项，因此你可以更改菜单项的顺序。

如前所述，快捷菜单实际上是一套配置文件。这意味着你可以有多个菜单。如果需要，可以创建另一个配置文件，并按照相同的步骤创建另一菜单。

11.2 快捷菜单相关技巧
使用后保持菜单打开

通常快捷菜单会在选择菜单项后从屏幕上消失。有时，你可能希望在选择项目后保持菜单打开。这允许你像以下示例一样调整设置：

  • 增量更改，如亮度增加/减少、较大/较小字号、上一页/下一页或章节等。
  • 你连续激活的一组选项（但不是同时激活），如打开 Wi-Fi，之后启动 SSH 服务器

如果你具有基于手势管理器（简易方法）的快捷菜单，则可以从以下菜单中启用此选项：

顶部菜单 / / 点按与手势 / 手势管理 / 「用户指定的手势」 / 保持快捷菜单开启

若已创建基于配置文件（高阶操作）的快捷菜单，请在下列菜单中选择：

顶部菜单 / / 配置文件 / 「用户指定的快捷菜单配置文件」 / 编辑行为 / 保持快捷菜单开启
在手势位置打开快捷菜单

通常，快捷菜单在屏幕中间居中打开。如果你用一只手使用电子阅读器，则可以激活一个设置，该设置将在手势位置打开菜单。这样，菜单将更接近你的手指，更容易访问。要使用此功能，请启用此选项：

顶部菜单 / / 点按与手势 / 手势管理 / 「用户指定的快捷菜单手势」 / 将快捷菜单锚定在手势位置
 此选项仅适用于通过手势管理器（即前文的简单方式）创建的快捷菜单。
将配置文件作为菜单项添加到快捷菜单

除了向快捷菜单添加操作外，你还可以将配置文件作为菜单项添加进去。这样，通过这一个菜单项就能一次执行多项操作。

假设你已经有一个可用的快捷菜单和一个想要添加到该菜单的配置文件。准备就绪后，请按以下步骤操作：

  1. 前往要作为「菜单项」使用的配置文件的设置，启用显示在操作列表中。这将使该配置文件显示在手势管理器中。
  2. 现在可以在手势管理器中将该配置文件作为常规操作添加到快捷菜单。该配置文件位于常规子菜单（手势管理器内）的最后一页。

将配置文件添加为菜单项后，你可以打开快捷菜单并点按该项，以执行该配置文件中的所有操作。你也可以将配置文件添加为子菜单，从而形成嵌套菜单。下一节将介绍这一方法。

创建嵌套快捷菜单

你还可以将一个快捷菜单作为菜单项添加到另一个快捷菜单中，从而形成嵌套菜单结构。当你有多个快捷菜单却不想给每个都分配不同手势时，这一功能很有用。

  1. 前往要作为「子菜单」使用的配置文件的设置，启用显示在操作列表中。这将使该配置文件显示在手势管理器中。
  2. 然后进入编辑操作菜单（位于该配置文件的同一设置中），并针对该子菜单配置文件启用位于第二页的显示为快捷菜单选项。这样 KOReader 就会把该配置文件当作另一个可进入的菜单，而不是在点按它时执行其中的所有操作。
  3. 现在可以将该配置文件作为常规操作添加到父级快捷菜单，就像在手势管理器中添加其他操作一样。该子菜单配置文件位于常规选项卡的最后一页。
 如果上述第二步中没有为子菜单启用显示为快捷菜单，你仍可在父菜单中长按子菜单的名称来访问其菜单项。这还会在子菜单顶部提供一个全部执行项。
11.3 配置文件

配置文件本质上是一套操作集合（就像宏命令），可通过单个手势触发。

例如在阅读某种类型的书籍时总会应用如下设置：

  • 将屏幕切换到横向显示模式
  • 增大字号并提高对比度
  • 打开屏幕前光

借助配置文件插件，只需执行单次操作即可完成这些调整。

 启用另一套配置文件后，前一套配置文件所执行的修改将不可撤销。例如，用户启用了一套配置文件将字号从 20 改为 24，然后又启用了另一套配置文件调整了前光，此时字号将保持为 24。KOReader 没有退出或撤销配置文件的操作选项。

要创建配置文件，首先确保配置文件插件已激活。如果你在下面看不到它：

顶部菜单 / / 配置文件

然后必须从以下位置打开：

顶部菜单 / / 更多工具 / 插件管理
创建配置文件

在配置文件菜单中，轻触新建，并为配置文件指定一个描述性标题。现在，你应该可以在菜单中看到新的配置文件。点按后将看到左侧的屏幕。你还可以从此菜单中删除、重命名或复制配置文件。

当你点击编辑操作菜单项时，你将看到右侧的菜单。这与手势选择菜单相同，并且在许多类别中都有动作。这意味着你可以使用配置文件执行任何手势动作。

现在，你可以从所有这些类别中选择多个项目。激活该配置文件时，将执行你在此处选择的操作。

启用一套配置文件

有许多方法可以激活配置文件：

  1. 通过其菜单中的执行操作。
  2. 你可以使用手势激活配置文件。为此，你必须从配置文件的菜单中启用显示在操作列表中。现在，你可以通过以下方式选择它：
    顶部菜单 / / 点按与手势 / 手势管理 / “任意手势” / 通用类 / 配置文件 「自定义标题」
  3. 从你的快捷菜单中。
  4. 你还可以根据某些条件自动激活配置文件。请参阅下一个标题以了解如何使用此强大的功能。

逐一执行配置文件中的操作

通常执行配置文件时，其中的所有操作会按照你在排序操作菜单中选定的顺序依次执行。

但你也可以选择让它们逐一执行。也就是说，每次调用该配置文件时，只执行其中一项操作（下一项），而非全部执行。

下面举一个实用的例子：

  1. 创建一套包含以下操作的配置文件
    • 转到锁定页
    • 返回前一位置
  2. 为其指定一个简便的手势，例如点按右下角
  3. 从配置文件的编辑操作菜单中启用逐一执行选项

现在，每次点按右下方边角，你都会在锁定页与当前阅读位置之间切换。例如，这可用于快速跳转到参考文献章节再返回。

配置文件问题排查

为避免与 KOReader 的其他操作/事件相互干扰，配置文件在自动执行时会带有极小的延迟。但在某些情况下（例如关闭文档时），配置文件必须立即执行才能完成其操作。

可通过以下路径启用该即时执行选项：

顶部菜单 / / 配置文件 / 「你的配置文件名称」 / 自动执行 / 立即执行

启用此选项后，例如对于触发条件为关闭书籍时的配置文件，该配置文件将在文档关闭之前执行。在这种情况下，这一执行顺序是正确运行所必需的。

每当为配置文件启用自动执行时，建议同时启用立即执行选项。如果发现配置文件工作不正常，可以尝试禁用此选项。

 此设置也可能引发（未知的）问题，因为配置文件中的操作组合几乎是无限的，我们无法预知它们会如何相互影响。因此该选项默认不启用。
配置文件与快捷菜单的技术细节 

KOReader 有操作组/设置组的概念，这种成套的操作组合可以通过两种方式创建：

  1. 「高阶操作」编制成配置文件（保存于 settings/profiles.lua 中）
  2. 「简单方法」作为指定手势的操作项（保存于 settings/gestures.lua 中）

操作组合也可以通过两种不同的方式执行：

  1. 在触发后按照指定的顺序依次逐项执行（作为配置文件）
  2. 将其显示为快捷菜单

对操作组合进行添加/删除及对快捷菜单项进行启用/排序都是通过相同的操作菜单完成。唯一的区别是，手势管理器中的操作菜单还有两个项目（忽略），导致显示为快捷菜单和排序这两个选项被挤到第二页上。

 你可以将配置文件备份并转移到其他设备。详情请参阅备份 KOReader 设置一节。

12.1 插件种类

插件是小型 KOReader 程序，类似于扩展基本程序功能的浏览器插件。KOReader 有 3 类插件：

内置插件

内部插件是核心程序的一部分。

  • 它们可以直接从 KOReader 插件菜单访问。
  • 他们不需要安装。你可以从菜单中启用它们。
  • 它们由我们的开发人员检查，因此它们被认为是安全的。
  • 它们会随 KOReader 更新而自动更新。

你可以通过以下方式启用/禁用它们：

顶部菜单 / / 更多工具 / 插件管理
贡献插件 

该组包含非官方插件，这些插件不属于 KOReader 的核心逻辑。

  • 它们必须手动安装，然后从插件菜单激活。
  • 它们应当被手动更新。
  • 它们在添加到存储库时由我们的开发人员进行检查，因此它们被认为是安全的。

你可以访问这个页面。通常，它们是通过从上面的页面下载插件的目录并将其复制到设备上的 koreader/plugins 文件夹下来安装的。但请检查插件的页面以获取其他可能的说明。

外部插件 

这些是独立于 KOReader 团队开发的插件。

  • 它们必须手动安装，然后从插件菜单激活。
  • 它们应当被手动更新。
  • 我们的开发人员不会检查它们，因此请注意使用它们可能存在风险。

这些外部插件的一些著名示例，带有指向其 GitHub 页面的链接：

  • 可借助云端或本地模型与正在阅读的文本交互的 AI 插件：
    1. KOAssistant 插件：一款功能强大且可高度自定义的 AI 插件。你可以通过创建带有额外上下文和指令的自定义操作来翻译/解释文本、比较书籍/文章等。借助 Ollama 兼容性，可支持在你的计算机上运行的本地模型。插件所链接的 GitHub 页面中有非常详细的说明。
    2. Assistant（AI 助手插件）：可用此插件简化、解释、讨论文本，或将文本翻译成其他语言。支持多种 AI 服务提供方以及内置/自定义提示词。

12.3 用户补丁 

用户补丁是用 Lua 语言编写的小文件。他们可以更改 KOReader 的功能，而无需永久修改你的安装。它们可以由开发人员、其他用户编写，也可以自己编写（如果你对 KOReader 内部结构有必要的广泛了解）。

当前可用的用户补丁列表可以在项目的维基页上查阅，或查看 Github 议题列表工单列表中带有 User patch available 标签的工单项，请点击此链接访问。

基本用法 – 将已编写的补丁添加到 KOReader：
  1. 在设备上的 KOReader 目录下创建名为 patches 的目录（在 Android 上，该文件夹位于 SD 卡上）
  2. 下载扩展名为 .lua 的补丁文件并将其放入此 patches 目录中
  3. 重启 KOReader
补丁管理器

按照说明创建补丁目录并重新启动 KOReader 后，在插件菜单中将出现名为补丁管理的新插件。通过使用此插件，你可以查看用户补丁的列表和状态并启用/禁用它们。你可以点击关于补丁管理器菜单项以查看更多信息。

命名补丁

补丁的执行顺序由补丁名称中数字的第一位数字决定。例如：2-TOC-title-patch.lua 如果有多个以同一数字开头的补丁，则执行顺序为自然顺序（1<10<11<12<13<…<109<…<10010）。如果你只是下载已制作的补丁，则无需更改文件名。

名称以：

  • 0 - 最早执行，并且仅在更新后执行一次
  • 1 - 在每次启动 KOReader 时很早执行（但在 0 之后，如果适用）
  • 2 - 在每次启动 KOReader 时 UIManager 准备就绪后执行
  • 3-7 - 保留
  • 8 - 在退出之前和保存设置之前执行
  • 9 - 在退出前执行

如果用户补丁有问题，可以通过删除补丁文件来恢复到以前的配置。

13.1 快速阅读插件
1. 感知扩展器插件

启用后，该插件会在阅读区域靠近左右边缘处添加两条竖线，如下图所示。阅读一行文字时，这两条线充当眼睛的起止标记。该插件的原理是：你其实不必直视一行的首尾单词，稍加练习就能用周边视觉感知到它们。

  • 灰色竖线：感知扩展器指示线
  • 红线：眼睛正常跟随文字移动
  • 蓝线：眼睛在指示线之间跳动（距离更短）

要使用该插件，需先通过以下路径启用：

顶部菜单 / / 更多工具 / 插件管理 / 感知扩展器

启用插件后，此处会新增一个菜单项：

顶部菜单 / / 快速阅读模块 — 感知扩展器

你可以在此菜单中切换扩展线的显示，并根据自己的喜好和周边视觉熟练程度配置指示线。启发这款插件的 Tim Ferriss 视频可在此观看。

2. FastReader 插件

这款插件是一个 RSVP（快速序列视觉呈现） 阅读器。该技术的做法是在屏幕中央快速闪现单词。这样阅读时眼睛无需移动，因此阅读速度可以更快。熟练之后还能一次感知多个单词，进一步提升阅读速度。

要使用该插件，需先通过以下路径启用：

顶部菜单 / / 更多工具 / 插件管理 / FastReader

启用插件后，此处会新增一个菜单项：

顶部菜单 / / 更多工具 / FastReader

你可以从此菜单启动该插件，并配置以下设置：

  • RSVP 速度 - 以 WPM（每分钟词数）计的闪现速度
  • 预览字数 - 一次显示多少个词

你可以先用单词模式和低 WPM（较慢）开始，熟练后再逐步提高。

13.2 特殊字体

本节介绍一些可能改善阅读体验的字体。这些字体并非 KOReader 独有功能，但用户常在工单和讨论中问起，故收录于此。

本节字体概览（注意，图中所有字体字号相同，均为 11 pt，但宽度、行高和可读性差别很大）：

Atkinson Hyperlegible

该字体系列由 Braille Institute 设计，旨在提升低视力人群的易认性与可读性，字母和数字清晰且辨识度高。可从 Braille Institute 查看并下载该字体。


B612

B612 是一款易认性极高的字体系列，最初为空客飞机驾驶舱屏幕设计。其清晰的字形特别适合条件欠佳的阅读环境，可减轻视觉疲劳与认知负担。这些设计原则同样使它适合电子阅读器。可在 Google Fonts 查看并下载该字体。


Lexend

这款字体的设计源自旨在提升学生阅读表现的教育研究结论。可在此了解该字体，并从 Google Fonts 下载。


Luciole

这款字体遵循十余项专门的设计准则，力求为视障人士提供最佳阅读体验。它强调字母的“内部”空间，数字与数学符号极为清晰易辨。可在此查看并下载该字体。


Open Dyslexic

这款字体专为提升阅读障碍读者的可读性而设计。字母底部加重以强调方向，每个字母的独特字形可避免翻转、混淆。可在此下载。


Shantell Sans

这款字体由一位有阅读障碍的设计者打造，易认、易用、便于阅读。得益于较宽的字母和宽松的字距，它在小字号下表现也很好。可从 Google Fonts下载。


Fast Font

这是一种特殊字体，会把单词开头的几个字母替换为粗体变体（字母数量按单词长度计算）。 This bold letters then act as artificial fixation points for the eye to jump on as you can see in this sentence. 理论上这可能提高阅读速度，但当然实际效果因人而异。有趣的是，ADHD 读者普遍反映有所获益。

这款字体依赖 KOReader 支持的特殊 OpenType 特性，因此只需下载字体、复制到设备即可像其他字体一样使用。可在其 GitHub 查看示例并下载该字体及其变体（衬线、等宽和点阵版）。

用文档制作屏保壁纸

有些书没有合适的书籍封面。或者他们的封面可能位于第二页，因此无法正确显示。或者封面可能不适合电子墨水（太亮或太暗）。或者你更喜欢将书中的一些图片设置为封面。

遇到这类情况，可以快速截屏并将其设为当前书籍的封面。根据所处界面，截屏手势有两种：

  1. 默认截屏手势 长对角线滑动，适用于阅读模式和文件浏览器
  2. 另一种截屏手势 双指对角大幅点按边角，适用于图片查看器

在图片查看器中，可在截屏前缩放和平移图片，使其按设备的精确尺寸和宽高比裁剪，而不会被拉伸。

截屏后，可在对话框中选择 设置为书籍封面。

你可以在此处删除此自定义书籍封面：

顶部菜单 / / 书籍信息

在书籍信息页面，长按封面图片项，然后选择重置自定义。

你还可以使用重置对话框重置书籍封面，你可以通过在文件浏览器中长按文件名来访问该对话框。

 使用该 重置 对话框时务必谨慎，确保仅勾选 自定义封面图片 一项，否则可能意外重置与该书籍相关的全部内容。

顶部菜单 / / 点按与手势 / 链接类操作 / 点按前往链接

禁用此设置后，要跟踪链接，必须长时间点击它，然后从弹出菜单中选择跟踪链接。如果你有相反的问题，并且希望更容易点击链接，则可以从同一菜单中启用允许链接周围有更大的点击区域。

阅读竖排书籍

目前官方 KOReader 尚不支持渲染竖排文字的书籍（tategaki，即日文「縦書き」），但有一位用户做出了可实现该功能的分支。它基本上是 KOReader 的复刻，额外加入了竖排文字渲染。

日文竖排书写是该分支的主要目标。但由于其实现在渲染引擎层面支持 EPUB writing-mode: vertical-rl，它也可能适用于其他竖排书写的语言。据中文用户反馈，它至少也能渲染中文。

请注意，这是一个分支（不是插件，也不是用户补丁），会完全替换你现有的 KOReader。不过普通横排书籍的表现与官方 KOReader 基本一致，因此这种替换在功能上应当是等效的。

无需先卸载当前的 KOReader 即可切换到该分支，只需按照该分支仓库中的说明操作。我们仓库中的开发讨论在此。

电池耗电问题

KOReader 的耗电非常克制。因此，如果在使用 KOReader 时阅读器电池开始异常掉电，通常首先要怀疑的是电池老化。

但如果你确认电池状态良好，且掉电只在使用 KOReader 时发生，原因可能是：

  • 有问题的固件更新
  • 某个第三方插件
  • 一个用户补丁

若遇到掉电问题，可按以下步骤排查：

  1. 将设备更新到最新固件版本。若设备没有可用的固件更新，请跳到下一步。
  2. 若更新固件仍未解决掉电问题，请移除已安装的所有第三方插件和用户补丁，然后重启 KOReader。
  3. 若前两步之后掉电问题依旧，最后的办法是将设备恢复出厂设置并重新安装 KOReader（别忘了备份主书库文件夹）。

如果问题仍然存在，可以在我们的 GitHub 页面新开工单。

我的书很慢

请参阅指南的优化文档一节，获取特定文件运行缓慢时的建议和解决办法。

如果所有书籍都运行缓慢，则问题可能与设备有关：

  • CPU 速度非常慢或 RAM 不足。
  • 你的闪存（你的书籍所在的位置）可能会退化，这通常是由于设备老化造成的。
  • 你的存储空间可能不足。
  • 如果你使用的是基于 Android 的设备，你的 Android 系统可能会干扰 KOReader 的运行，或者某些后台进程可能会使用你的系统资源。

新开工单：

如果你要就这个问题提交一个工单，对我们来说检查有问题的文件非常重要。你可以在将其压缩成 ZIP 压缩包后，直接通过拖放的方式将文件分享到你的 GitHub 消息中。如果你的书是 EPUB，并且由于版权或隐私问题，你不想共享该文件，有一个名为 ScrambleEbook 的 Calibre 插件，你可以从Mobileread 论坛页面访问下载和说明。

此插件将读取未加 DRM 保护的电子书文件（EPUB/KEPUB/AZW3），并创建一本文本被随机字符替换的书的副本。你可以在你的工单中与我们分享这个混乱版本。书中的文本将无法阅读，也不会有任何版权侵犯，但我们仍然可以使用此文件进行诊断目的。

翻页时的重影

即使 KOReader 设置为在每页完全刷新，你仍然可能在翻页后看到一些重影/残留。这是电子墨水屏幕技术的局限性，可以在最新一代设备上观察到，尤其是在阅读混合内容（文本+图片）文档时。作为解决方法，你可以在翻页后再次手动刷新，以消除这些伪影（默认为短对角线滑动手势）。

在 Android 设备上重置 KOReader

在 Android 设备上，KOReader 将设置保存在 Internal Storage/koreader/ 目录下。这是有意设计，与其他 Android 应用不同。该目录用户可直接访问，便于备份和同步 KOReader 设置。

但当你卸载 KOReader，或在 Android 系统设置菜单中清除其数据时，这个 KOReader 设置目录并不会被删除。因此，卸载后重新安装 KOReader，它仍会沿用旧设置启动。

若想把 KOReader 彻底重置为出厂默认状态，需手动删除该目录。删除后再次启动 KOReader 时，它会自动以默认设置重新创建。

在 Amazon Kindle 设备上禁用广告

这在技术上可行，但遗憾的是我们无法更改这些阅读器上默认的屏保行为。因为这可能引发 Amazon 的负面反应，进而封锁 Kindle 生态（Kindle 上将不再能用 KOReader），甚至危及整个项目（KOReader 不复存在）。更多信息可在此查看我们与开发者的讨论。我们的立场与 MobileRead 论坛一致，可在此阅读。

文本缩进问题

如果标题、小标题或分隔符没有正确居中，或者出现意外的文本缩进，请尝试切换文档的样式，把 epub.css 改成 html5.css。发生这种问题是因为一些出版方认为他们的书只会在基于网络浏览器引擎的阅读器上阅读，因此他们不会费心“重置”样式。

顶部菜单 / / 样式
  • 默认 HTML/EPUB (epub.css) 是我们面向书籍的样式表，带有 text-align: justify, text-indent on P。它更适合无样式的书籍，并且可能会使具有样式的书籍更具可读性。
  • 如果您的书籍存在上述缩进问题，您可以尝试切换到 HTML5 (html5.css)，这种样式提供了一个基本样式表，就像 Web 浏览器在渲染时所做的那样： text-align: left, no text-indent on P, spacing between P。但是当出版方没有做任何样式时，它看起来并不漂亮。

删除文件缓存

当您阅读 PDF/DJVU 文档时，KOReader 会保留您阅读的最后一页的缓存。所以当你重新打开这本书时，它会更快。但是，如果您长时间使用 KOReader 并阅读许多 PDF/DJVU 文档，则此缓存可能会变大。这些缓存文件保存在 KOReader 安装目录下的缓存文件夹下。要删除此缓存并回收空间，您可以转到：

什么是每夜版？

KOReader 有两个不同的版本分支：

  • 稳定版 该类版本是 GitHub 上 Releases 发布页提供的主力版本，其文件名形如「KOReader 2024.11」，意为该版软件发布于2024年11月。该类版本大致上按月度发布，但有时发布间隔也会更久。
  • 每夜版 该类版本会每天持续编译发布以便及时合并优化和修复。每夜版面向尝鲜者及开发者这类小群体用户，因此软件稳定性可能欠佳。

通常来说，稳定版是适合普通用户的版本。但某些特殊情况下，用户可能需要每夜版：

  • 你的设备非常新（例如最近发布的 Kobo 型号），并且刚刚在最近的一个晚上添加了 KOReader 支持。
  • 存在特定于你的设备的错误或问题，该错误或问题已修复但尚未发布。而且你不想等待稳定版本进行此修复。
  • 更新 KOReader 后，你注意到你正在使用的功能已被删除。你不想丢失此功能，因此你可以安装仍然具有此功能的夜间版本。当然，你也可以返回到以前的稳定版，但每夜版会更新，因此可能会有更多功能和修复。

本节只是对该主题的一般介绍。有关每夜版的详细信息和寻求帮助，你可以访问讨论页面：FAQ: 如何跟踪最新的每夜版

 在 Android 设备上使用 KOReader 时，可利用 Android 系统的 Work Profile（工作资料） 功能测试每夜版，而不会影响主力安装的 KOReader。Shelter 和 Island 等开源应用可以帮你实现这一点。
