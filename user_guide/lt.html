2 BASIC USAGE
2.1 Transferring Documents

KOReader supports PDF/PDB/XPS, EPUB/MOBI/FB2, DJVU, CBR/CBT/CBZ, DOCX/RTF, HTML/HTMLZ, TXT/MD and CHM files. It can also open ZIP archives and show image files.

Yra daug būdų perkelti dokumentus į įrenginį. Atkreipkite dėmesį, kad gali reikėti iš naujo paleisti KOReader, kad perkeltimi dokumentai būtų indeksuoti (arba atnaujinti aplanką, jei naudojate Pocketbook/Android).

Be failų perkėlimo tokiu pačiu būdu, kaip ir su įrenginio standartine skaityklės programa, priklausomai nuo įrenginio, galimos ir kitos parinktys:

  1. USB masinės atminties režimas KOReader viduje: Šis režimas galimas KOBO ir kai kuriuose CERVANTES įrenginiuose.
  2. Debesų saugykla (Dropbox/FTP/Webdav): Norėdami naudoti šią funkciją, turite pridėti debesų saugyklos serverio paskyras per žemiau nurodytą meniu. Procesas paaiškintas naudojant info mygtukus meniu pridedant paskyras:
    VIRŠUTINIS MENIU (Failų naršyklėje) / / Debesų saugykla
  3. SSH/SFTP prieiga: KOReader gali veikti kaip SSH serveris, prie kurio galite prisijungti iš kompiuterio failams perkelti (galima Kobo, Kindle, Cervantes įrenginiuose). Galite naudoti SFTP programą (pvz., Filezilla) arba pasiekti per savo failų tvarkyklę, jei tai palaiko jūsų operacinė sistema. Kaip tai padaryti, žr. mūsų wiki ir taip pat žemiau pateiktą įspėjimo langelį.
  4. Calibre perkėlimas: Naudodami Calibre įskiepį, galite siųsti dokumentus iš savo Calibre bibliotekos tiesiai į KOReader įrenginius per Wi-Fi ryšį. Kaip tai padaryti, žr. mūsų wiki.
  5. Naujienų atsisiuntimo priemonė: Naudodami šį įskiepį galite atsisiųsti RSS ir Atom naujienų įrašus kaip HTML failus. Kaip tai padaryti, žr. wiki.
  6. OPDS (Open Publication Distribution System) catalogs: You can access public catalogs or use your own servers to access your library. More info here: Using OPDS Catalogs
  7. Wallabag: Naudodami šį įskiepį galite gauti straipsnius iš Wallabag, serveryje veikiančios „skaityti vėliau“ paslaugos, panašios į Pocket. Daugiau informacijos žr. wiki puslapyje.
 Be careful if you decide to use the SSH feature without a password, because this allows open access to your device. But if you are using a local wifi and turn on your device wifi for a short time, this risk is negligible.

2.5 Auto Warmth / Night Mode

Šis įskiepis leidžia koreguoti priekinio apšvietimo šilumą įrenginiuose su natūralia (geltona/oranžine) šviesa ir automatiškai nustatyti nakties režimą (apverstos ekrano spalvos – baltas tekstas juodame fone) pagal tvarkaraštį. Jis gali valdyti abu, arba galite pasirinkti tik šilumos valdymo arba tik nakties režimo valdymo režimą, kad kitą galėtumėte reguliuoti rankiniu būdu.

Šis įskiepis įdiegus KOReader yra įjungtas numatytai. Jei dėl kokios nors priežasties jo nėra meniu, galite jį įjungti čia:

Font kerning adjusts the spacing between letters to achieve a visually pleasing result. Default is best option, which might be slower when opening files (depending on your device) but has better support for ligatures (see the image below for an example), joined Arabic glyphs and some other scripts. Font hinting is a typographical technique that adjusts the characters in a font to fit in a low-resolution grid, like an e-ink screen. When enabled, the result is sharper and easier to read characters, at the cost of slight distortion of the original font design.

Difference of font hinting is more visible on standard-resolution screens or at smaller font sizes. On a very high-resolution screen, the difference is much less noticeable because the pixels are small enough.

Here is a more detailed comparison:

Hinting OFF

  • KOReader shows the font's true mathematical shape, without forcing it to snap to the pixel grid.

Hinting ON

  • The font is modified to fit the pixel grid of your screen. Letter shapes may differ slightly from the original font.
  • The font may appear slightly softer, blurrier, or have some unevenness (e.g., the two vertical lines in an 'M' might look like they have different thicknesses).
  • The font appears sharper, crisper, and more solid. The letters have consistent stroke weights.

In KOReader, font hinting is enabled by default and uses the FreeType library's hinting algorithm instead of font's internal instructions (to be safe because font internal instructions might be broken). But you can try the font designer's instructions embedded in the font file to see if it looks better:

  1. Off Hinting is disabled.
  2. Native KOReader uses the font's internal hinting instructions.
  3. Auto (on by default) KOReader uses FreeType's hinting algorithm, ignoring font's internal hinting. Handles CJK text better.

4.2 Marking Pages

After learning how to navigate, we will now learn how to mark pages in a document. This will allow us to quickly jump between different parts of our document.

Pinned page

If there is a page in a document that you frequently jump to (for example Reference pages section of a book), you can pin this page to easily jump there. You can have only one pinned page per book, so if you need more places to jump, check the Bookmarks feature below.


How to pin/unpin a page:

  1. Open the Skim widget.
  2. Press the page number in the Skim widget.
  3. A dialog will open and you will see the Pin current page button there. Press normally to pin the page or long-press to remove the pin.

    You can reach this dialog from this menu too, which you can also assign a gesture to reach:

    TOP MENU / / Go to page

How to jump to your pinned page:

  1. Open the Skim widget.
  2. Press the page number in the Skim widget.
  3. Press the Go to pinned page button in the opening dialog.

How to go back:

After jumping to the pinned page, you can return to your previous reading position with this menu action:

VIRŠUTINIS MENIU / / Grįžti į ankstesnę vietą

Also you can use the swipe left then right single finger swipe to go back.

Pinning/jumping is much faster if you assign Gestures to these actions:

  • For example you can assign a gesture to the Pin current page action.
  • Another gesture to the Go to pinned page action.
  • And some other gesture to the Back to previous location

Now you can quickly pin a page, jump to it when reading and go back with just three taps. You can also add these actions to your Quick Menu of course.

Žymės

You can add (and remove) a bookmark by tapping the top right corner of a page. This is the equivalent of folding the corner of the page on a printed book and shows a similar icon at the corner when you add a bookmark.

You can access your bookmarks from the Bookmarks window and then tap on the bookmarks to jump to the relevant page:

TOP MENU / / Bookmarks

You can open this window quickly by swipe left with double finger gesture or up then left single finger swipe.

4.3 Knygos žemėlapis

Knygos žemėlapis yra galinga ir unikali KOReader funkcija, kuri gali būti labai naudinga norint apžvelgti knygą. Pavyzdžiui, jei skaitote knygą nenuosekliai, praleisdami kai kurias dalis, kad perskaitytumėte vėliau, būtų sunku sekti savo pažangą. Knygos žemėlapis gali iš karto parodyti, kurias knygos dalis jau perskaitėte.

Papildomai galite:

  • Pamatyti, kiek laiko praleidote kiekviename puslapyje (jei įjungtas Skaitymo statistikos įskiepis)
  • Patikrinti, kuriuose puslapiuose yra žymė, paryškinimai ir pastabos
  • Naršyti tiesiai į bet kurią knygos dalį, kaip PERŽIŪROS VALDIKLYJE

Knygos žemėlapį galite pasiekti per meniu, taip pat galite priskirti gestą greitesniam pasiekimui:

VIRŠUTINIS MENIU / / Knygos žemėlapis

  1. Skyrių ribos
  2. Juodos juostelės žymi perskaitytus puslapius. Aukštesnės juostelės reiškia daugiau laiko, praleisto puslapyje.

  8. Vertikali slinkties juosta rodo dabartinį rodinio lygį.
  9. Vertikali slinkties juosta rodo dabartinį puslapio pločio lygį.

- Pirmiausia pabandykite braukti KAIRĖN ir DEŠINĖN palei apatinį ekrano kraštą, kad pakeistumėte puslapius žyminčių stulpelių plotį, ir stebėkite, kaip tai keičia žemėlapio mastelį.

- Tada pabandykite braukti AUKŠTYN ir ŽEMYN palei kairįjį ekrano kraštą, kad pakeistumėte skyrių pavadinimų gylį ir persijungtumėte į Plokščią rodinį. Žr. pavyzdžius žemiau.

Be aukščiau esančio numatytojo Tinklelio rodinio, čia kairėje matote Plokščią rodinį, o dešinėje - Tinklelio rodinį be skyrių pavadinimų. Jei norite grįžti prie numatytojo rodinio, ilgai paspauskite informacijos piktogramą viršutiniame kairiajame kampe.

Palietę meniu piktogramą Knygos žemėlapio ekrane, matysite aukščiau pateiktą meniu. Meniu parinktys paaiškintos žemiau:

  • Apie knygos žemėlapį: Trumpas Knygos žemėlapio naudojimo ir piktogramų aprašymo paaiškinimas.
  • Galimi gestai: Gestai, kuriuos galite naudoti Knygos žemėlapio nustatymams keisti vietoj šio meniu naudojimo.
  • Puslapių naršyklė palietus: Jei tai pažymėta, paliesdami puslapį Knygos žemėlapyje, atversite Puslapių naršyklę. Tai parodo pasirinktos srities apžvalgą. Jei šią parinktį išjungiate, palietimas Knygos žemėlapyje tiesiogiai nuveda jus į tą puslapį. Bet atminkite, priklausomai nuo tokių veiksnių kaip ekrano dydis, jutiklinio ekrano jautrumas, palietimo tikslumas ir t. t., galite atsidurti gretimuose puslapiuose.
  • Perjungti dabartinį/pradinį rodinį: Jei pritaikėte Knygos žemėlapio rodinį, palietus tai persijungiama tarp numatytojo rodinio ir jūsų pritaikyto rodinio.
  • Perjungti tinklelio/plokščią rodinį: Persijungti tarp atskirų skyrių ir tęstinio skyrių rodinių.
  • Skyrių lygiai: Keisti skyrių/poskyrių lygių gylį.
  • Puslapio langelio plotis: Padaryti kiekvieną puslapio langelį platesnį ar siauresnį.
  • 10 puslapių žymekliai: Didinant šią reikšmę, pirmiausia žymekliai bus pridedami prie kiekvieno 10-o puslapio, tada jie taps didesni, o galiausiai žymekliai bus pridedami prie kiekvieno 5-o puslapio.
4.4 Puslapių naršyklė

Puslapių naršyklę galima naudoti naršyti tarp puslapių kaip fotoalbume, rodant puslapių miniatiūras tinkleliu. Puslapių naršyklę galite atverti paliesdami Knygos žemėlapį arba iš meniu. Taip pat galite priskirti gestą lengvesniam pasiekimui.

VIRŠUTINIS MENIU / / Puslapių naršyklė

Puslapių naršyklės naudojimas paaiškintas žemiau. Taip pat galite paliesti viršutinio kairiojo kampo meniu mygtuką šiame ekrane, kad pamatytumėte šiuos paaiškinimus. Ilgas paspaudimas ant to paties mygtuko prideda/pašalina skyrių pavadinimus iš apatinės juostelės.

  1. Braukite kairėn / dešinėn per šį viršutinį kraštą, kad padidintumėte / sumažintumėte stulpelių skaičių.
  2. Braukite aukštyn / žemyn per šį kairįjį kraštą, kad padidintumėte / sumažintumėte eilučių skaičių.
  3. Braukite per puslapių sritį, kad perkeltumėte peržiūrimus puslapius. Aukštyn / žemyn - slinkti viena eilute (2 puslapiai šiame pavyzdyje), kairėn / dešinėn - slinkti vienu ekranu (4 puslapiai šiame pavyzdyje).
  4. Palieskite bet kurį puslapį, kad atvertumėte jį skaitymo rodinyje.
  5. Apatinėje srityje palietus puslapį, miniatiūrų rodinys sufokusuojamas ties tuo puslapiu. Braukimas kairėn / dešinėn peršoks vienu juostelės pločiu.

4.5 Page Numbering

Page numbers in KOReader status bar behave differently depending on the document type; some are fixed, while others adjust dynamically. In the image below, you can see an overview of the page numbering system of KOReader. You can come back to this chart while reading this section.

As you can see, documents that KOReader is able to open, can be divided into two categories which we will explain below:

1. Fixed-Layout Documents

PDF, DjVu and CBR/CBZ are examples of this type of documents. Also known as non-reflowable, these documents has a static layout. This means, every element on the page (text and image) is precisely positioned and their position never changes, whether you are reading it on a small screen or big. The design that you see, is always an exact replica of a printed page.

Fixed-layout documents have only static page numbers. When you open these type of documents in KOReader, page numbers that you see in the status bar, belong to the document itself. Static page numbers don't change with the type or screen size of the reader device.

2. Reflowable Documents

EPUB, MOBI, AZW, HTML are examples of this type of documents. The layout of these documents is not fixed. This means, the text and other content can adapt (reflow) to fit the size of the screen or window that you are viewing the document in.

You can imagine these type of documents as very long text files or web pages, which naturally don't have page breaks. When you open these documents, KOReader calculates the page numbers on the first opening by dividing this long document into screen sized pages. As a result of this, if you open a document on a 10-inch reader, your book will have less pages than a 6-inch reader because more words can fit on a single page of bigger screen (more words per page = less pages in total).

This also means that if you change the appearance of the text, for example by making the font bigger, this will change your page numbers. Because with a bigger font size, less text will fit on the screen, increasing the total number of pages.

Stable page numbers

Due to their changing nature, reflowable document page numbers are not very useful for referencing. When you open a PDF file (which is a fixed-layout document) on your e-reader and on your computer at the same time, page 42 will always show the same content on both devices. But for an EPUB file, page 42 on one device will be different from the other.

So now you might ask: "Is it possible to have non-changing page numbers on a reflowable document like EPUB?" Yes it is possible with the stable page numbers feature. There are two types of stable page numbers in KOReader:


- Publisher page numbers:

KOReader supports documents with publisher page numbers feature, which allows publishers to embed page numbers from printed books directly to the e-book version. When you enable this feature, KOReader doesn't calculate the page numbers itself. Instead, it shows you the embedded page numbers from the publisher. This means, the page number you see in your status bar matches the print version of the book.

Šią funkciją galite įjungti čia:

TOP MENU / / Settings / Stable page numbers / Use stable page numbers

If you also check the Show stable page numbers in margin option from the same menu, these publisher page numbers will be shown next to the text in a small font.


- Characters per page:

What if your book doesn't have publisher page numbers (majority of them don't) but you still need stable page numbers?

Then you can enable the characters per page feature of KOReader. When you use this feature, KOReader calculates the page numbers according to a defined number of characters per page (instead of your screen size). So, for example you can set KOReader to "count 1500 characters as a single page" (default value of this setting which roughly equals to 250 words in English language). And approximately 250 words is the single page of a standard mass market paperback/PA5 format book.

So when you enable this feature, your page count will be similar to a real book printed at the mentioned size. Of course you can change this characters per page setting from the menu to simulate different book sizes.

If you have the printed version of a book, you can adjust the characters per page number to match the total page numbers to the printed book so it would be easier to find a passage in the other version.

Changes after enabling the stable page numbers feature

When you enable the stable page numbers for a document, these changes happen:

  • Your status bar switches to stable page numbers for the read/remaining/total page counts.
  • File browser shows stable page numbers for this document for the total page count.
  • Bookmarks, Table of Contents and Page browser shows stable page numbers.
  • If you export your highlights from this document, export file will have the stable page numbers for the highlight and note locations.

5.1 How To Save Settings

So after all these settings, you might ask "Will my other books look like this too?" No, not automatically. Because all these changes are valid only for the current book.

In other reader applications, when you change a setting, let's say the font used for books, it changes globally. Which means, if you change the default font to Verdana, any books you open after this change -including the ones that you are already reading- will be shown in this Verdana font.

KOReader's approach is different from this. We save appearance settings per book. This gives you the flexibility to change your settings for the current book without affecting others. For example if you have some fantasy books, you can change the font to a medieval looking one only for these books. Or you can set some books to open in landscape orientation or double column mode.

So this is how KOReader works:

  1. KOReader settings like font size, line spacing etc. have default values.
  2. If you open a new book, KOReader refers to these default values to set the appearance of your book.
  3. When you make changes in a book, like adjusting the text size, they affect only this specific book. Because your changes won't modify the default values, so newly opened books won't be affected.
  4. But you have the ability to save your changes as defaults and when you do this, they will be used for the newly opened books too.

Let's see on an example:

During this exercise, we increased the Font weight of our book to +1.00. Now open the Font weight menu and press the three dots at the end of the Font weight setting line. A dialog window will open and you will see this: Default value: +0.00. This means that when you open another book, its font weight will still be 0 (Default value), instead of +1 as we have set before.

So to make a setting permanent, you have to set it as default. There are two methods in KOReader for setting these default values:

  1. Setting individual settings as defaults
  2. Setting "all of the settings" as defaults at once
1. Setting individual settings as defaults

Settings in KOReader generally can be set as default with a long-press. Have a look at the screenshot below:

Values on the right side marked in blue can be long-pressed to set them as defaults. Let's say you want to make the text bolder. If you press on +1 normally, it will change only for this book. But if you long-press on it, you will see this dialog:

This "long-press to set as default" rule works in menus too. For example when changing the font from the top menu:

  • short press = change the font only for this book
  • long-press = change the font for this book and all the future books

2. Setting "all of the settings" as defaults at once

You also have the ability to set all of the current book settings as defaults instead of one-by-one. This is useful if you make many changes to a book and you want all your books to look like this one.

But what we can do about already opened books? Well, if you pressed the menu item above and have set your new defaults, you can easily apply them to any book now. Just open the book that you want to change, go to the same menu and press this item:

  • How to set your changes as defaults so all books can use them

Now we will see another use case: Imagine that you have modified your defaults to your liking so whenever you open a new book, it now looks exactly as you want. Technical details of KOReader font system and troubleshooting 

If you are having problems with the font weights when adding fonts to KOReader, this section can help you to understand how KOReader's font processing works:

  1. When starting up, KOReader compiles the available fonts by reading their embedded font metadata/info and classifies them according to family and weights. KOReader tries to determine the font family information from the metadata included in the font, so font names are not important when copying to your device.
  2. If you have more than one font file for a font family, KOReader will try to fit fonts in one of these 4 categories: Regular, Bold, Italic & BoldItalic. An ideal case looks like this:
    • Luciole-Regular.ttf mapped to Font weight: 0 (Regular 400)
    • Luciole-Bold.ttf mapped to Font weight: +3 (Bold 700)
    • Luciole-Regular-Italic.ttf
    • Luciole-Bold-Italic.ttf
    If a font variation is not available, as well as for fractional adjustments, it will be synthesized from the nearest available weight.
  3. If your font provides only one file and it is not Bold, KOReader will assign it as (Regular 400) Font weight: 0 and synthesize all other weights and variants itself. In other words KOReader will fake italic and bold for this font. (If your single font file is a Bold font, then KOReader will synthesize the Regular weight from this bold font.)

 If you long-press on the Font weight label in the bottom menu, it will tell you which weight classes your current font provides.

 If your font also has other variants, things can get confusing. Let's say you copied a font family to your device. And upon startup, KOReader has read these variants of the font: Light, Thin, Normal, Medium, ExtraBlack, SemiBold, Bold, Black in this order. You would expect to see Normal variant to be used as the document's normal font (because it is named as Normal) but KOReader will use the Light variant because that is the first font in the list that doesn't have the bold flag. And it will ignore the Thin, Normal and Medium variants because it has already found a "not bold" font for the document.

And again according to this list, ExtraBlack will be used as the bold font because it is the first font in the list with the bold flag. And KOReader will ignore the SemiBold, Bold, Black variants, because KOReader has already found the "bold" it is looking for.

As a summary of the above: We copied the whole family and expected Normal and Bold variants to be chosen but instead, KOReader used Light and ExtraBlack variants. This happened because the order of the fonts that are fed to KOReader is not under our control so "first come is first served".

Solution is, transferring only the font files that you want to be used, like this:

  • Keep only one of Thin, Extra Light, Light, Normal, Medium: It will be used as the regular font (If your Regular font is too thin, just replace it with Medium weight if you have it).
  • Keep only one of Semi Bold, Bold, Extra Bold, Black, Extra Black: It will be used as the bold font.
  • You can also add italic variants of the same weight (i.e. medium/medium-italic).
5.3 Style tweaks 

KOReader stiliaus pakeitimų funkcija leidžia keisti, kaip KOReader atvaizduoja knygą. Čia neapžvelgsime viso CSS kurso. Norime tik parodyti pagrindus, kad pamatę stiliaus pakeitimą, bent apytiksliai suprastumėte, ką jis daro.

Kas yra stiliaus pakeitimas?

EPUB dokumentą galime apibūdinti kaip HTML failą + kai kurias CSS taisykles. Šios CSS taisyklės nustato, kaip skirtingos knygos dalys (antraštės, paryškintas tekstas, citatos ir t. t.) bus rodomos skaityklės programoje. Naudodami stiliaus pakeitimus, galite keisti, kaip knyga bus atvaizduojama, pridėdami naujas taisykles ir/arba pakeisdami leidėjo parašytas taisykles, įterptas jūsų knygoje.

Pažiūrėkime tai stiliaus pakeitimo pavyzdyje:

img { width: 10px !important; height: 10px !important }

Paprasta kalba ši taisyklė sako: „Ignoruok jų originalų dydį ir padaryk visus šios knygos vaizdus 10 pikselių pločio ir 10 pikselių aukščio.“ Taigi, jei pridėsite šį stiliaus pakeitimą į KOReader, visi jūsų knygos vaizdai bus rodomi maži.

Dabar paaiškinkime šį pakeitimą po elementą:

  • img - Tai CSS selektorius, nukreiptas į visus img (vaizdo) elementus knygoje.
  • { width: 10px !important; height: 10px !important; } - Tai deklaracijos blokas. Jame yra stiliai, kurie bus taikomi pasirinktiems img elementams.
  • width: 10px !important; - Ši pirma dalis nustato tikslinių img elementų plotį iki 10 pikselių. Deklaracija !important yra perrašymo jungiklis, užtikrinantis, kad jūsų pločio reikšmė turės pirmenybę prieš bet kokią kitą esamą width deklaraciją, taikomą šiems vaizdams.
  • height: 10px !important; - Ši dalis nustato tikslinių img elementų aukštį iki 10 pikselių. Vėlgi, deklaracija !important yra perrašymo jungiklis, užtikrinantis, kad jūsų aukščio reikšmė turės pirmenybę prieš bet kokią kitą esamą height deklaraciją, taikomą šiems vaizdams.

Apibendrinant, ši CSS taisyklė skirta nustatyti fiksuotą 10 pikselių plotį ir aukštį visiems img elementams jūsų knygoje, ignoruojant jų originalų stilių.

Keletas naudingų stiliaus pakeitimų pavyzdžių

Tai keletas naudingų stiliaus pakeitimų, kuriuos galite naudoti tiesiogiai arba modifikuoti pagal savo pageidavimus. Kita antraštė paaiškina, kaip juos naudoti KOReader.

  • Pridėti skiriamąją liniją virš kiekvienos knygos antraštės:

    H1, H2, H3, H4 { border-top: 2px solid black; }

  • Pridėti šiek tiek paraštės virš antraščių:

    H1, H2, H3, H4 { margin-top: 2em !important; }

  • Arba, jei knygoje virš antraščių yra per daug paraštės, ją pašalinti:

    H1, H2, H3, H4 { margin-top: 0 !important; }

  • Pridėti nedidelį tarpą tarp pastraipų, kad tekstas būtų lengviau skaitomas:

    p + p { margin-top: 0.5em !important; margin-bottom: 0.5em !important; }

  • Išjungti visus vaizdus EPUB faile:

    img { display: none !important; }

  • Padaryti vaizdus labai mažus vietoj jų išjungimo:

    img { width: 10px !important; height: 10px !important }

  • Padaryti kodo blokų skyrius kompiuterių mokslo knygose tvarkingesnius ir skaitomesnius (Čia galite pamatyti pavyzdį):

    pre,code { font-size: 0.6em !important; line-height: 1.8em !important; background-color: #eee !important; margin: 1em 0 !important; padding: 1em 0 !important; }

Gerai, dabar matėme, kas yra stiliaus pakeitimai. Bet kaip galime juos naudoti? KOReader yra trys stiliaus pakeitimų tipai:

1. Įtaisyti (built-in) stiliaus pakeitimai

Šie pakeitimai yra įtraukti į KOReader. Jie lengviausiai naudojami, nes tiesiog įjungiate juos meniu, kad jais naudotumėtės. Jums nereikia rašyti jokio CSS kodo:

  1. Ši sritis rodo pakeitimo pavadinimą ir aprašymą
  2. Šiame langelyje rodomas pakeitimo CSS kodas. Galite paliesti šią sritį, kad nukopijuotumėte kodą į iškarpinę. Tada šį kodą galite įklijuoti ir modifikuoti savo Knygai skirtame pakeitime, kaip paaiškinta kitoje antraštėje.

Sukūrę šio tipo pakeitimą, jei nuspręsite, kad jis reikalingas ir kitoms knygoms (pvz., to paties leidėjo), galite jį konvertuoti į naudotojo stiliaus pakeitimą, kurį paaiškinsime toliau.

3. Naudotojo stiliaus pakeitimai

Ši pakeitimų grupė skiriasi nuo ankstesnių jų kūrimo būdu. Taip pat, skirtingai nuo ankstesnio tipo, jie neapsiriboja viena knyga. Juos galima taikyti visuotinai visoms jūsų knygoms.

Procedūra maždaug tokia, kurią paaiškinsime išsamiai:

  1. Sukurkite savo naudotojo pakeitimo failą
  2. Perkelkite jį į savo įrenginį
  3. Įjunkite savo pakeitimą iš meniu

1. Naudotojo pakeitimo failo kūrimas:

Naudotojo stiliaus pakeitimas iš tikrųjų yra paprastas teksto failas su .css plėtiniu. Šį failą galite sukurti:

  • Savo kompiuteryje
  • Savo įrenginyje, jei jis turi teksto redaktorių (kaip Android OS pagrindu veikiantys įrenginiai)
  • KOReader integruotame teksto redaktoriuje, kurį rasite įskiepiuose

Į savo failą galite kopijuoti / įklijuoti aukščiau minėtus pavyzdžius.


2. Failo perkėlimas į įrenginį:

Suteikite failams aprašomuosius pavadinimus, nes failo pavadinimas bus pakeitimo antraštė KOReader meniu sistemoje. Failų pavadinimuose galite naudoti pabraukimus „_“, jie meniu bus traktuojami kaip tarpai. Perkėlę failus, turite iš naujo paleisti KOReader, kad jis galėtų juos įkelti.

Jei norite, kad šis pakeitimas būtų įjungtas visoms knygoms, ilgai paspauskite jo pavadinimą. Atsiras dialogo langas. Palieskite meniu elementą Naudoti visoms knygoms. Šalia jo pavadinimo meniu pasirodys žvaigždutė (★), žyminti, kad šis pakeitimas bus taikomas visoms knygoms. Tai galite išjungti tais pačiais žingsniais. Žr. pavyzdį žemiau:

Galbūt pastebėsite, kad šalia pirmojo pakeitimo taip pat yra rodyklė į dešinę piktograma. Tai reiškia, kad šį pakeitimą galima aktyvuoti gestais. Tai bus paaiškinta kitoje antraštėje.

8.4 Optimizing Manga

Jei mėgstate skaityti mangą el. rašalo įrenginyje, yra keletas patarimų, galinčių pagerinti patirtį. Savų mangos failų paruošimas yra geriausias sprendimas, jei nesate patenkinti, kaip komiksai atrodo jūsų įrenginyje.

Kokį failo tipą naudoti

Failų tipai, tokie kaip MOBI ir EPUB, netinka daugiausia vaizdinio turinio (pvz., mangos/komiksų) tvarkymui. MOBI palaikymas KOReader minimalus ar jo iš viso nėra, o EPUB teksto atvaizdavimo prioritetai gali sukelti problemų rodant viso puslapio vaizdus. Daugiau techninių detalių žr. šioje GitHub problemoje.

Geriausias jūsų pasirinkimas - sukurti CBZ failą, kuris geriau veikia KOReader. Failas su .cbz plėtiniu yra zip failas (be suspaudimo), kuris yra vaizdų rinkinys. Jame saugomi keli vaizdai, dažniausiai .png ar .jpeg failai, sutvarkyti į komikso puslapius. KOReader taip pat gali atverti CBT failus, kurie panašūs į CBZ failus, bet naudoja TAR archyvo formatą.

Easiest way to convert a manga to CBZ is to get the manga as images from various websites, then convert them using Kindle Comic Converter. There are some useful settings like auto-rotating two-page splits to landscape and applying dithering so that e-ink rendered gradients are smoothly dithered without jagged layers.

Kokią skiriamąją gebą naudoti

Geriausius rezultatus galite pasiekti pakeisdami vaizdų dydį tiksliai iki el. skaityklės ekrano dydžio. Ekranui specifinis CBZ, orientuotas į tikslų įrenginio ekrano dydį, apsaugo nuo mastelio keitimo skaitymo metu. KOReader sumažina vaizdus iki ekrano dydžio skaitymo metu, bet tai nerekomenduojama, nes KOReader prieš mastelio keitimą pridedą diterinimo (dithering) perėjimą, o tai sukelia kokybės praradimą.

Bet jei norite naudoti savo rankomis sukurtą CBZ daugiau nei viename įrenginyje arba norite išsaugoti didelę skiriamąją gebą ateičiai, geriausias jūsų pasirinkimas gali būti sukurti CBZ savo didžiausios skiriamosios gebos įrenginiui. Arba pasirinkti savavališką „didelę“ skiriamąją gebą, galbūt atitinkančią šaltinį. 300 PPI ar geriau (iki 450 ar net 600), nebent šaltinis, žinoma, mažesnis. Jei darysime prielaidą, kad ekrano dydis 8 col., 1500×2000 yra geras tikslinis skiriamosios gebos pasirinkimas. Didesniems vaizdams turėtumėte išbandyti savo įrenginyje ir pamatyti, ar jis su tuo susitvarko. Ypač seni Kindle su maža atmintimi gali turėti sunkumų su tokiais dydžiais kaip 3000×4000, pavyzdžiui. Jei automatizuojate procesą, gali būti verta apsvarstyti galimybę sukurti ir žemesnės, ir aukštesnės kokybės versiją (pvz., 200/400 ar 300/600 DPI).

 KOReader doesn't parse spine page-progression-direction="rtl" attribute of the books. So it doesn’t change page turning direction even though the file was created with right-to-left reading. Users can switch this via:
VIRŠUTINIS MENIU / / Palietimai ir gestai / Puslapio vertimai / Apversti puslapio vertimo palietimus ir braukimus / mygtukus
Pažangus mangos paruošimas

Toliau pateikiama pavyzdinė vieno mangos failo apdorojimo procedūra:

  • Atsisiųskite Kindle Comic Converter (KCC) iš https://github.com/ciromattia/kcc
  • Atsisiųskite savo mangą iš pasirinkto šaltinio (pvz., HakuNeko)
  • Išpakuokite mangos failą. Dabar turėtumėte turėti katalogą, kuriame yra tik vaizdai (arba pakatalogiai su vaizdais, be archyvų)
  • Apdorokite šį katalogą su KCC. Kiekvienas katalogas sukurs vieną CBZ failą, todėl jei norite sukurti kelis tomus vienu metu, pasirinkite kelis katalogus vienu metu

8.5 Other Manga Tips
Getting rid of rainbow effect on color e-ink screens

Due to the color e-ink screen technology, it is possible to see rainbow like color artifacts when reading black-and-white comics/manga with fine shading or dots. If you are having this problem, there is a KOReader plugin named Derainbowify that solves it. You can see the detailed info and install instructions on the GitHub page of this plugin.

Įtraukiantis (immersive) režimas KOReader

Jei norite mėgautis manga labiau įtraukiančiu būdu, kurdami CBZ failą KCC programoje būtinai pasirinkite tikslią tokią pat skiriamąją gebą, kaip jūsų įrenginio ekrano. Taip pat galite paslėpti apatinę eigos juostą skaitydami mangą KOReader. Taip turėsite įtraukiantį viso ekrano mangos vaizdą be trukdžių.

Extra step for smooth gradients 

Naudodami KCC sukūrę CBZ failą, galite vaizdams pritaikyti papildomą diterinimą (dithering). Taip el. rašalo atvaizduojami gradientai bus sklandžiai diterinti be dantytų sluoksnių. Šis žingsnis sukurs tiksliai sureguliuotus mangos tomus, kurie geriau atrodo KOReader.

Vaizdams apdoroti galite naudoti ImageMagick. ImageMagick yra galinga atvirojo kodo programų rinkinys, skirtas rodyti, kurti, konvertuoti, modifikuoti ir redaguoti rastrinius vaizdus. ImageMagick galite atsisiųsti ir naudoti komandinėje eilutėje daugeliui vaizdų apdoroti vienu metu.

  1. Išpakuokite paruoštą CBZ failą, kurį sukūrėte su KCC,
  2. Atsisiųskite šį failą dither_pack.zip (esantį „Yandex Disk“), kuriame yra du paketiniai failai (.BAT) ir GIF spalvų šablonas.
  3. Ištraukite šiuos tris failus šalia vaizdų, kurie bus apdorojami
  4. Redaguokite _magick_manga_ditherN_resize.bat ir pakeiskite skiriamąją gebą į savo įrenginio skiriamąją gebą (abiejose vietose BAT faile).
     Next step will replace all the images in the directory with the processed ones. So make sure that you have a copy of them in some other directory if you want to keep the originals.
  5. Paleiskite _magick_manga_ditherN_resize.bat, kad pakeistumėte vaizdų dydį ir pritaikytumėte diterinimą (dithering).
  6. Darant prielaidą, kad turite įdiegtą 7-Zip, paleiskite _batch_archive.bat, kad supakuotumėte visus apdorotus vaizdus į CBZ archyvą.
Reversing the page turn direction for authentic Japanese manga 

KOReader galite priversti versti puslapius iš kairės į dešinę, kad braukimai ir palietimo zonos apsikeistų vietomis. Norėdami tai įjungti, pridėkite šias eilutes:

["/storage/emulated/0/Books/manga"] = {
["inverse_reading_order"] = true,
["kopt_zoom_direction"] = 0,
},

į šį failą:

/koreader/settings/directory_defaults.lua

kur /storage/emulated/0/Books/manga yra absoliutus kelias iki katalogo, kuriame yra jūsų mangos. Po šio pakeitimo, atverdami failą iš minėto katalogo, jūsų braukimai ir palietimo zonos bus apsikeistos.

Showing hidden files and directories in File Browser

Normally, KOReader file browser doesn't show these two groups of files and directories:

  1. Hidden files and directories: These are files and directories that start with a dot (.) character, like .screensavers. If you want to see these directories and files, enable this option:
    (FILE BROWSER) TOP MENU / / Settings / Show hidden files
  2. Unsupported file types: These are the file types that KOReader can't open directly, like font files with a .ttf extension. KOReader can directly open these file types: PDF, EPUB, DJVU, MOBI, CBR, CBZ, CBT, DOCX, RTF, HTML, HTMLZ, TXT, XPS, FB2, PDB, CHM and MD document types, image files and ZIP/RAR archives, so only these files are visible in the file browser. If you want to see the unsupported file types too, you can enable this option:
    (FILE BROWSER) TOP MENU / / Settings / Show unsupported files
Darbas su keliais failais

Failų naršyklė leidžia atlikti kai kurias operacijas (pvz., kopijuoti, perkelti, trinti, eksportuoti paryškinimus) su daugeliu failų vienu metu. Šiai procedūrai pirmiausia turite pasirinkti failus. Šiuo metu failų naršyklėje yra trys skirtingi failų pasirinkimo masinėms operacijoms būdai:

- Pirmuoju metodu, ilgai paspauskite failo pavadinimą ir iškylančiajame dialoge pasirinkite Pažymėti. Tai aktyvuos Pažymėjimo režimą. Dabar galite paliesti kitus failus, kad pridėtumėte juos į pažymėjimą. Baigę žymėti failus, palieskite varnelės piktogramą viršutiniame dešiniajame ekrano kampe. Dialoge galite pasirinkti, ką daryti su šiais failais. Arba tame pačiame dialoge išeiti iš pažymėjimo režimo.

- Antruoju metodu, paspauskite + (pliuso) piktogramą viršutiniame dešiniajame kampe ir dialoge pasirinkite Pažymėti failus. Tai aktyvuos Pažymėjimo režimą, o toliau viskas taip pat, kaip pirmajame metode.

- In the third method, you can choose your files based on a File search . This is useful if you need to perform an operation on many files distributed in different folders. For example you want to move all files in your collection authored by Tolkien, to a new folder. Steps for this action will be:

  1. Viršutiniame meniu paspauskite Paieškos skirtuką (su lupos piktograma) ir pasirinkite Failų paieška.
  2. Jei norite ieškoti ir aplankuose, pažymėkite parinktį Įtraukti poaplankius. Jei norite, kad KOReader ieškotų ir knygos metaduomenyse, pažymėkite Taip pat ieškoti knygos metaduomenyse. Priešingu atveju KOReader ieškos įvesto žodžio tik failų pavadinimuose.
  3. Paiešką galite pradėti nuo bibliotekos Pagrindinio aplanko arba Dabartinio aplanko, paspausdami atitinkamą mygtuką.
  4. Baigus paiešką, pamatysite failų sąrašą (jei paieškos terminas, žinoma, rastas). Dabar galite paliesti meniu piktogramą viršutiniame kairiajame ekrano kampe, kad įjungtumėte Pažymėjimo režimą.
  5. Palieskite visus failus, su kuriais norite atlikti operacijas, ir palieskite Varnelės piktogramą viršutiniame kairiajame ekrano kampe. Pamatysite dialogo langą su Pažymėti failų naršyklėje. Pasirinkite šią parinktį.
  6. Dabar būsite grąžinti į Failų naršyklę, ir failai, kuriuos pažymėjote Paieškos dialoge, čia taip pat bus pažymėti.
  7. Palieskite Varnelės piktogramą viršutiniame dešiniajame ekrano kampe. Dabar galite pasirinkti, ką daryti su šiais failais iš dialogo.
Aplankų nuorodos

KOReader leidžia pridėti mėgstamus aplankus į greitai pasiekiamą Aplankų nuorodų meniu. Pavyzdžiui, jei bibliotekoje turite Archyvo aplanką, esantį Home>Straipsniai>Moksliniai>Archyvuoti, galite priskirti aplanko nuorodą šiam Archyvuoti aplankui ir greitai jį pasiekti net skaitydami knygą.

Aplanko nuorodos pridėjimas:

Yra du būdai pridėti aplanką į Aplankų nuorodų sąrašą:

  2. Būdami Failų naršyklėje, ilgai paspauskite aplanko pavadinimą, kad atvertumėte kontekstinį meniu. Palieskite Pridėti į aplankų nuorodas elementą ir įveskite aprašomąjį šios nuorodos pavadinimą. Tai pridės aplanką, kurį paspaudėte.

Aplankai, esantys jūsų Aplankų nuorodų sąraše, Failų naršyklėje turės žvaigždutę (★).

Aplanką iš nuorodų galite pašalinti taip pat, ilgai paspausdami ant jo ir pasirinkdami Pašalinti iš aplankų nuorodų.


Aplankų nuorodų peržiūra:

Aplankų nuorodas galite atverti iš Failų naršyklės ar Skaitymo ekrano skaitydami knygą.

  • Iš Failų naršyklės: Viršutinis dešinysis kampas + (pliuso) meniu, tada pasirenkant Aplankų nuorodas arba priskiriant gestą.
  • Iš skaitymo ekrano: Priskiriant jam gestą.

Tai yra Gestų tvarkyklės skyriuje Failų naršyklė. Kaip nustatyti gestus, galite sužinoti atitinkamame šio vadovo skyriuje.

Teksto failų peržiūra

  2. Palieskite Atverti su…
  3. Palieskite Archyvo peržiūros priemonę

Jei failui suteiksite tik .zip plėtinį, KOReader manys, kad šiame archyve yra vaizdai, ir bandys jį atverti kaip CBZ failą.

9.3 Kolekcijos

KOReader Rinkinių funkcija gali padėti efektyviau tvarkyti biblioteką. Paprastai tariant, rinkiniai yra naudotojo sukurti knygų sąrašai. Pavyzdžiui, galite sukurti du rinkinius, pavadintus Grožinė literatūra ir Negrožinė literatūra, kad atitinkamai sutvarkytumėte knygas. Kai kurie rinkinių privalumai, palyginti su aplankais pagrįstu organizavimu:

  • Pridėjus knygą į rinkinį, knygos failas nėra perkeliamas. Taigi jūsų knygos gali būti skirtinguose aplankuose, bet vis tiek gali atsirasti tame pačiame rinkinyje.

  • Rinkiniais galite aktyvuoti profilius. Tai bus paaiškinta žemiau, jei nesate susipažinę su KOReader profilių funkcija. (Žinoma, profilius galite aktyvuoti ir aplankais, tačiau rinkiniai nereikalauja perkelti knygų, kad, pavyzdžiui, naudotumėte laikinus profilius.)

Galite sukurti rinkinius, atspindinčius bet kokią kategorizaciją. Keletas pavyzdinių idėjų:

  • Žanrai: Grožinė literatūra, negrožinė literatūra, memuarai...
  • Knygos būsena: Šiuo metu skaitoma, noriu perskaityti, kita, nebaigta...
  • Serijos: Žiedų valdovas, Haris Poteris...
  • Dokumento tipas: Knygos, moksliniai straipsniai, tinklalapio straipsniai...

Knygų pridėjimas į rinkinius

KOReader yra trys skirtingos vietos, kur galite pridėti knygas į rinkinius:


1. Iš Failų naršyklės ir Istorijos ekrano

Knygą į rinkinius galite pridėti iš Failų naršyklės ar Istorijos ekrano. Iš Istorijos ekrano knygas galite pridėti po vieną. Ilgai paspauskite knygą ir pasirinkite Rinkiniai.... Tada galite pasirinkti, į kurį rinkinį (-ius) norite pridėti šią knygą.

Jei pridedate kelias knygas, tai galite atlikti iš Failų naršyklės. Kelioms knygoms procedūra tokia:

  1. Ilgai paspauskite knygą
  2. Iškylančiajame meniu pasirinkite Pažymėti
  3. Pažymėkite kitas knygas
  4. Palieskite varnelės (✔️) piktogramą viršutiniame dešiniajame kampe
  5. Palieskite Rinkiniai

Norėdami pridėti vieną knygą, tiesiog ilgai paspauskite ją Failų naršyklėje ir iškylančiajame meniu pasirinkite Rinkiniai.


2. Iš Rinkinių meniu

Šis metodas leidžia pridėti vieną ar kelias knygas į Rinkinius. Didžiausias skirtumas nuo Failų naršyklės metodo yra tas, kad galite pridėti visus aplankus ir jų poaplankius į rinkinius vienu metu. Tai labai naudinga, jei jūsų knygos jau sutvarkytos aplankuose. Pavyzdžiui, jei visos jūsų mokslinės fantastikos knygos yra viename aplanke, galite sukurti rinkinį Mokslinė fantastika ir vienu metu pridėti šį aplanką.

Aukščiau esančiame paveikslėlyje 1 langelyje parodytos knygos pridėjimo parinktys. Šį meniu galite pasiekti iš rinkinių ekrano meniu piktogramos:

VIRŠUTINIS MENIU / / Rinkiniai / jūsų rinkinio pavadinimas /
  • Pridėti visas knygas iš aplanko: Kaip ir sako pavadinimas, ši parinktis leidžia pasirinkti aplanką, kad į šį rinkinį būtų pridėtos visos jame esančios knygos. Atkreipkite dėmesį, kad ši parinktis nepridės pasirinkto aplanko poaplankiuose esančių knygų. Pavyzdžiui, jei pasirenkate aplanką Grožinė literatūra, o po juo turite aplankus Mokslinė fantastika ir Karo romanai, jie nebus pridėti šia parinktimi.
  • Pridėti visas knygas iš aplanko ir jo poaplankių: Ši parinktis pridės visus poaplankius jūsų pasirinkto aplanko. Būkite atsargūs su šia parinktimi, nes pridedant knygas ji eis iki pat žemiausio lygio. Taigi, jei turite daug įdėtų aplankų lygių, gali atsirasti gerokai daugiau knygų, nei manėte.
  • Pridėti knygą į rinkinį: Tai pagrindinė parinktis, leidžianti pridėti vieną knygą.
Knygų pašalinimas iš rinkinių

Knygą iš rinkinių galite pašalinti iš Failų naršyklės, Istorijos ar Rinkinių ekrano. Failų naršyklėje ir Istorijos ekranuose ilgai paspauskite knygą ir pasirinkite Rinkiniai.... Matysite varnelę šalia rinkinių, į kuriuos pridėjote šią knygą. Panaikinkite tų, iš kurių norite pašalinti knygą, žymėjimą jas paliesdami. Taip pat iš Rinkinių ekrano galite ilgai paspausti knygą ir pasirinkti Pašalinti iš rinkinio.

Knygų tvarkymas rinkiniuose

Rinkiniai gali būti labai perkrauti, tačiau KOReader leidžia lengvai rasti knygas, teikdamas daug filtravimo parinkčių. Jei pažvelgsite į aukščiau esantį paveikslėlį, matysite filtravimo parinktis 2 ir 3 langeliuose. 2 langelis leidžia filtruoti pagal knygos būseną (nauja, skaitoma, baigta, sulaikyta), o 3 langelis leidžia filtruoti pagal knygos metaduomenis (autorių, seriją, kalbą, raktinius žodžius). Taip pat šias dvi filtrų grupes galite derinti, pavyzdžiui: „Parodyk man naujas šio rinkinio knygas, parašytas Isaac Asimov (Filtruoti pagal autorius -> Isaac Asimov), kurių dar nepradėjau skaityti (Filtruoti pagal būseną -> Nauja).“

Knygos metaduomenis galite atnaujinti ilgai paspausdami knygą Failų naršyklėje ir meniu pasirinkdami Knygos informacija. Iškylančiajame lange galite ilgai paspausti bet kurį lauką, kad pakeistumėte metaduomenis, tokius kaip autorius ar raktiniai žodžiai. Šiai užduočiai taip pat galite naudoti Calibre - trečiosios šalies programą, žymiai palengvinančią knygos metaduomenų tvarkymą.

 Be aware that Calibre changes the metadata within the book itself, so the changed metadata is visible outside of Calibre. But KOReader doesn't change the book file, it only adds custom metadata as a file in the book's .sdr folder, so this metadata is visible in KOReader only.
Paieška rinkiniuose

Rinkiniuose galite atlikti du paieškos tipus: galite ieškoti frazės knygų pavadinimuose ir metaduomenyse, arba galite ieškoti knygų tekstuose. Paieškos dialogą galite atverti iš:

VIRŠUTINIS MENIU / / Rinkiniai / / Rinkinių paieška

Jei norite atlikti paiešką knygų tekstuose, atkreipkite dėmesį į šiuos punktus:

  • Šis paieškos tipas galimas tik atvėrus rinkinius iš failų naršyklės. Jis negalimas iš skaitymo ekrano.
  • Ši paieška gali būti lėta (apie 2 sekundes vienai knygai rinkinyje). Taigi, jei turite perkrautą rinkinį, ji gali užtrukti ilgai.

Paieškos funkcija priklauso nuo to, kur esate rinkinių lange. Jei esate šakniniame lygyje, kur matote visus savo rinkinius, paieška bus atlikta visuose rinkiniuose. Jei norite ieškoti tik konkrečiame rinkinyje, turite paliesti ir įeiti į rinkinį. Tai ypač svarbu, jei taip pat ieškote knygų tekstuose, nes tai lėta operacija.

Atlikus paiešką, rezultatai bus automatiškai išsaugoti kaip naujas rinkinys.

Sukūrę rinkinius ir pridėję į juos knygų, tikriausiai norėsite juos sinchronizuoti su kai kuriais aplankais. Pavyzdžiui, įsivaizduokite, kad sukūrėte rinkinį Mokslinė fantastika.   • Prijungiant aplanką prie rinkinio

  • Rodant rinkinį
  • Paleidus programą

Kaip atjungti aplanką nuo rinkinio:

  1. Eikite į Rinkinių ekraną, matomą aukščiau esančiame paveikslėlyje.
  2. Ilgai paspauskite rinkinio pavadinimą, prie kurio norite prijungti aplankus (1).
  3. Iškylančiajame meniu pasirinkite Prijungti aplankus (2).
  4. Atsivers Prijungtų aplankų sąrašo ekranas.
  5. Ilgai paspauskite aplanką, kurį norite atjungti, ir iškylančiajame meniu pasirinkite Atjungti aplanką.

9.4 Optimizing Documents

KOReader is designed to work efficiently even on the limited hardware of e-book readers. But there will always be poorly formatted documents which slow down KOReader. Here we will give some tips for optimizing your document depending on the file type.

EPUB files
  • EPUB failus iš esmės sudaro tekstas ir vaizdai su tam tikromis taisyklėmis, nurodančiomis, kaip šie elementai formatuojami ekrane. Idealiomis sąlygomis tai gana paprastas procesas, todėl EPUB failai KOReader paprastai veikia greitai. Bet kai kuriose EPUB knygose yra tiek daug formatavimo taisyklių, kad KOReader turi atlikti daugybę skaičiavimų vien tam, kad parodytų vieną sakinį. Tai sulėtins knygos atvėrimą, puslapių vertimą ir išvaizdos savybių, tokių kaip šrifto svoris ar eilučių tarpas, keitimą.
     KOReader doesn't support fixed layout EPUBs. They will open, but will render as reflowable EPUBs and probably won't look nice or readable.
  • EPUB files are actually ZIP archives that contain HTML files. Some books can be a single HTML file while others may be composed of multiple HTML files like each chapter of the book is a separate HTML file. If your book is only a single HTML file, partial rendering can not work. So appearance changes will be slower than the divided chapter books, because for each change, KOReader still has to calculate the whole book instead of only the current chapter.
  • Another rare case of slowness is when the content is wrapped in a HTML table tag. KOReader has to render/draw each cell on each page turn, so if a cell (containing many paragraphs) spans 50 pages, this will make page turning quite slow.

Solutions:

  • Apatiniame meniu galite nustatyti Įterptus stilius į IŠJUNGTA, kad pamatytumėte, ar dokumento stilių lentelių ignoravimas pagreitina veikimą (žinoma, prarasite gražų formatavimą, bet sužinosite, kas yra kaltininkas).
  • Jei turite HTML ir CSS žinių, galite tiesiogiai patikrinti HTML ir CSS failus iš KOReader ir patys įvertinti jų kokybę ar nereikalingą sudėtingumą. Norėdami tai padaryti, ilgai paspauskite ant teksto ir iškylančiajame meniu pasirinkite Žiūrėti HTML.
  • Jei turite „turinys įterptas lentelėje“ problemą, minėtą aukščiau esančiame problemų skyriuje, galite pridėti šį table, tr, td { display:block; } knygai skirtą stiliaus pakeitimą į:
    VIRŠUTINIS MENIU / / Stiliaus pakeitimai / Knygai skirtas pakeitimas
  • Calibre el. knygų redaktorius gali patikrinti EPUB failus dėl problemų ir turi įrankių kai kurioms problemoms taisyti.

    Calibre galite atsisiųsti čia.

    Calibre Knygos tikrinimo įrankio instrukcijas galite rasti čia.

  • Programa EPUBCheck gali patikrinti EPUB failų teisingumą ir aptikti daug klaidų tipų. Pavyzdinę problemą, aptiktą naudojant EPUBCheck, galite paskaityti čia.

    Komandinės eilutės versiją galite atsisiųsti čia.

    Arba atsisiųskite grafinės naudotojo sąsajos versiją čia.

PDF files

PDF files can be slow because of these problems:

  • PDF failas gali būti per didelis jūsų įrenginio atminčiai.
  • PDF faile gali būti labai didelių vaizdų failų. Net dokumentuose su įprastu teksto sluoksniu (kurį galima pažymėti ir paryškinti) gali būti įterptas kitas vaizdo sluoksnis (paprastai puslapio nuskaitymas). Tai lėtina atvėrimą ir puslapio vertimą, nes šie dideli vaizdai turi būti pakeisti dydžiu, kad tilptų ekrane, o šis procesas gali reikalauti daug procesoriaus resursų.
  • PDF faile gali būti daug atskirų elementų, kuriems reikia tikslaus pozicionavimo, pvz., žurnalo puslapyje su daug vaizdų ir teksto langelių. Šiuo atveju KOReader turi apskaičiuoti ir nubrėžti visus šiuos elementus, o tai gali užtrukti.
  • Funkcija Automatinis ištiesinimas (leidžianti koreguoti puslapio pasvirimą) taip pat gali sulėtinti skaityklę.
  • Jei nustatote ATVAIZDAVIMO KOKYBĘ į AUKŠTĄ, kai PERTVARKYMAS ĮJUNGTAS, tekstas atrodys patraukliau, bet gali būti daug lėtesnis (iki kelių sekundžių vienam puslapio vertimui) nei NUMATYTASIS, priklausomai nuo dokumento.
    APATINIS MENIU / / Atvaizdavimo kokybė

Unfortunately, for bad PDF files there are not many solutions. Generally best solution with problematic PDFs is trying to find a better version of it. Or if another file type is available for download, like EPUB instead of PDF (or reverse) you can try that format.

Also you can try to convert your documents into the more flexible EPUB format. Here are some apps that can help you when working with PDFs:

  • Calibre gali konvertuoti dokumentus tarp daugelio formatų. Ji taip pat turi įtaisytą redaktorių, leidžiantį redaguoti el. knygas (ir taisyti problemas) populiariausiuose el. knygų formatuose, EPUB ir Kindle.
  • K2pdfopt optimizuoja PDF/DJVU failus mobiliosioms el. skaityklėms ir išmaniesiems telefonams. Ji gerai veikia su kelių stulpelių PDF/DJVU failais ir gali pertvarkyti tekstą net nuskaitytuose PDF failuose. Ją taip pat galima naudoti kaip bendrą PDF kopijavimo/apkarpymo/dydžio keitimo/OCR įrankį.
  • OCRmyPDF yra komandinės eilutės programa, galinti pridėti OCR teksto sluoksnį prie nuskaitytų PDF failų (kuriuose yra tik vaizdai be teksto), leidžiant juose ieškoti ar kopijuoti tekstą. Tai gali būti ypač naudinga skaitant senas nuskaitytas knygas. Ji taip pat gali optimizuoti vaizdus, kad failo dydis būtų mažesnis.

TEXT files

KOReader has a very efficient text processing engine. Also books are cached on first opening so KOReader can open them faster next time. But despite these optimizations, unusually large text files might still take longer to open. For example, online Chinese novels are known to reach tens of millions of words and generally saved as text files.

Problem with large text files is the delay when first rendering the book and when modifying the text appearance later. If you try to change the font size of a very large .txt book, you might see a big delay after each adjustment because all of the book has to be rendered again. KOReader has a partial rendering system which shortens this type of delay considerably. But this feature can't be used with text files because these files are not divided into chapters (you can read more about partial rendering here).

To benefit from partial rendering speed-up, you can convert your large text file to EPUB format using the Calibre application. Calibre will automatically divide your text file into smaller individual files during conversion and pack them into a standard EPUB file. After this conversion, you can change your book appearance much faster. You can download Calibre from this page and find online tutorials for the TXT-to-EPUB conversion procedure.

Web pages

SingleFile is a browser extension for Mozilla Firefox, Google Chrome and Microsoft Edge. This extension allows saving a web page as a single .html file with all the resources (images, stylesheets, scripts) embedded. Then you can copy this single file to your device and read with KOReader.

9.6 Synchronizing Progress

If you are using KOReader on several devices like e-reader, phone, tablet or desktop computer, KOReader can synchronize your reading progress between them. Using the progress sync feature, you can continue reading seamlessly when switching from your e-reader at home to your phone on the commute for example.

This feature is handled by the progress sync plugin. Setting up synchronization involves these three steps which we will explain below:

  1. Create a sync account
  2. Login to your sync account from all the devices you want to synchronize
  3. Automatically or manually synchronize your reading progress
1. Creating a sync account

To create a sync account, connect to a network on your device and open the progress sync plugin in KOReader:

TOP MENU / / Progress sync

and press the Register/Login button.

In the opening window, enter a username and password then press the Register button. This will create an account on KOReader sync server which will hold your reading progress.

2. Login to your sync account

Open the same menu on the devices that you want to sync. Enter your username and password and this time press the Login button. After this, your devices will be connected to your sync account.

You can give recognizable names to your devices. Again from the same menu, press the Device hostname and enter a name for the current device.

3. Sync your progress

After everything is set up, you can synchronize your reading progress automatically or manually:

  • Automatic sync: To synchronize automatically, enable the Automatically keep documents in sync menu item. Now whenever you close a book or suspend/resume your device, KOReader will send your reading progress to the server (of course this requires an available network connection).
  • Manual sync: If you don't have constant internet connection on your device for battery or availability reasons, you can choose to synchronize manually. You have many options to trigger a synchronization:
    1. From the menu: In the Progress sync plugin's menu you can press the Push progress from this device now menu item to send your progress on the current device to the server. To receive the latest progress from the server, press Pull progress from other devices now menu item.
    2. With gestures: These actions (push/pull progress) are available in the Gesture manager so you can assign them to any gesture you like.
    3. With quick menu: You can add these actions to your Quick Menu.
    4. From profiles: You can add these actions to your Profiles. Especially with the auto-execute feature of profiles, you can trigger sync with various filters and conditions.
Document matching method options

In order to sync the progress of a document on two different devices, KOReader first has to identify these two files as "same". Sometimes this can be tricky, so we have two methods that you can choose from, depending on your usage of KOReader. You can change the method from the Document matching method option in the progress sync menu.


Binary matching (default)

By default, progress sync uses Binary matching method to identify the files. In this method, KOReader generates a partial MD5 hash of the file’s content (which looks like this: 0b229176d4e8db7f...). Any tiny change to the file, completely changes this hash so binary matching method works only if both files are perfectly identical.

If you are copying the exact same file manually to all your devices, this method should work. But for example if you are using Calibre to send books to your devices, binary matching will fail.

Because Calibre writes its own information like viewer progress directly into the file, which changes the file hash calculation, so KOReader will treat these files (original and Calibre modified) as two different books. If you have this problem you can use the alternative method explained below.


Filename matching

This is a "looser" matching method designed for users whose files might vary slightly between devices due to the changes made to the documents by other software like Calibre, as explained above.

In this method, KOReader only checks if the filenames (including the extension) of the two documents are identical to match them. So if you are using Calibre or some other library management software to manage your library across different devices, you can change to Filename matching.

 You can also have a look at the Book metadata storage options section of the guide for in-depth information.
Privacy and security of the synchronization process
  • KOReader sync server, the software that handles KOReader's synchronization process is an open-source project. You can find more information including the source code on its GitHub page.
  • Synchronization server does not store file name or content. This means, the server can't know what you are reading. When you synchronize the progress of a document, only this information is transferred and kept on the server:
    1. User name (that you have chosen)
    2. Unique id of the document (MD5 hash of the file which looks like this: 0b229176...)
    3. Furthest reading position for this document
  • Your password is not stored on the server (only a MD5 hash is kept).
  • All communication between KOReader and the sync server is secured with HTTPS.
Hosting your own sync server 

You also have the option to host your own sync server if you wish. You can use the official KOReader sync server or one of the alternatives you can see on this page.

There are also other projects like Calibre-Web which are library management solutions with an integrated KOReader sync server.

9.7 Book Metadata Archive

First we will explain KOReader's file deletion behavior so you will better understand the Book Metadata Archive feature:

Normally when you copy a document to your device and open it for the first time, KOReader creates a new directory with a name like your_document_name.sdr and uses this directory to keep the settings, annotations and progress for this document.

When you delete a document using KOReader's File Browser, KOReader deletes this .sdr directory too. Which means that you lose all the settings, annotations and progress for the deleted document. If you copy this document to your e-reader again and open it with KOReader, it will be like opening it for the first time.

But for example, what if you want to delete the finished books (maybe you don't like clutter in your library or you are out of space), but also you don't want to lose the highlights from these books? Book Metadata Archive feature allows you to do this.


How this feature works:

  1. First you have to activate the feature by choosing an archive location here:
    TOP MENU / / Document / Book metadata archive / Archive location:
  2. Now when you delete a document from the File Browser, you will see this option is enabled in the confirmation dialog: [ ] save book to metadata archive
  3. If you check this option when deleting, KOReader will copy the settings file for this document to your archive directory which you have chosen at the first step above.
  4. Then KOReader will delete your document and its associated your_document_name.sdr directory.

Your document is deleted, but its settings are in the archive. If you copy this document to your device again and open it, KOReader will notice that the settings for this document are in the archive and tell you this: "This book was previously opened on this device. Would you like to restore its metadata from the archive?" Restore button will use this archived settings file for this document so you will get back the settings, annotations and progress for this document.

You can see the list of archived documents here:

TOP MENU / / Document / Book metadata archive / Archived books list

From this list, you can access the archived document's information/metadata and bookmarks by tapping on the name of the document. Also you can delete the document from the archive.


Save metadata to archive on book closing

If you enable this option from the same menu mentioned above, KOReader will save a copy of the the settings file of every document when closing it. Even if you delete a document and its .sdr folder outside of KOReader (Android file manager, when connected to your pc...) you will still have a backup of your document's settings.

 If Save metadata to archive on book closing option is enabled, but you uncheck the save book to metadata archive option in the file delete dialog, KOReader will delete the previously created settings archive file for this document.

 KOReader recognizes deleted files from their file hashes. This means the file you copied back to your device should be identical to the deleted file. Any changes like Calibre metadata written into the file or PDF highlights added, will change the hash of a file. In this case KOReader can't offer you the Restore option because it will see this as a different file. See the next section of the guide for more detailed info: Book Metadata Storage

1. Atskiri metaduomenų aplankai šalia knygos failų - NUMATYTASIS NUSTATYMAS
VIRŠUTINIS MENIU / / Dokumentas / Knygos metaduomenų vieta: knygos aplankas

Tai yra numatytasis metodas, naudojamas naujai įdiegus KOReader. Šiuo metodu, nukopijavus Alice in Wonderland.epub į įrenginį ir pirmą kartą jį atvėrus, tame pačiame kataloge bus sukurtas aplankas, pavadintas Alice in Wonderland.sdr. Šiame kataloge yra failai su šios knygos nustatymais, anotacijomis ir pažanga.

Privalumai

  • Kiekvienos knygos nustatymus galite rankiniu būdu atsargiai kopijuoti ir atkurti.
  • Atliekant katalogo sinchronizavimą ar atsargines kopijas su sistema, tokia kaip Syncthing ar Dropbox, nustatymai bus sinchronizuojami kartu su knygomis.
  • Galite pervadinti tėvinius katalogus, kuriuose yra jūsų knyga, tai nesutrikdo KOReader.

Trūkumai

  • Jei pertvarkote biblioteką perkeldami/pervadindami knygos failus ar jų kartu esantį .sdr aplanką ne per KOReader failų naršyklę, be jokio įspėjimo prarasite tų knygų metaduomenis.
  • Šie .sdr aplankai bus matomi naršant bibliotekos katalogus kita failų naršykle ar iš kompiuterio, o tai gali užkrauti jūsų vaizdą.
2. Metaduomenų katalogai po vienu KOReader kataloge
TOP MENU / / Document / Book metadata location: ./docsettings

Šis metodas iš esmės toks pat, kaip numatytasis aukščiau. Skirtumas tas, kad šiuo metodu visi knygų .sdr aplankai bus po vienu katalogu, esančiu KOReader pagrindinio katalogo struktūroje, o ne bibliotekos kataloge, šalia knygos failų.

Privalumai

  • Knygos .sdr aplankai bus matomi ir naudojami tik KOReader. Jie neužkrauna bibliotekos katalogų vaizdo, kai naršote biblioteką kita failų naršykle ar iš kompiuterio.

Trūkumai

  • Jei pertvarkote biblioteką perkeldami/pervadindami bibliotekos katalogus, knygos failus ar jų kartu esantį .sdr aplanką ne per KOReader failų naršyklę, be jokio įspėjimo prarasite tų knygų metaduomenis.
  • Kadangi knygos metaduomenys nebus bibliotekos aplankuose, jokia bibliotekos sinchronizacija ar atsarginės kopijos jų neįtrauks.
3. Atskiri MAIŠOS (HASH) metaduomenų katalogai po vienu KOReader kataloge
TOP MENU / / Document / Book metadata location: ./hashdocsettings

Šis metodas panašus į ankstesnį, nes .sdr aplankai bus vidiniame kataloge. Bet šis metodas sukurtas siekiant išspręsti ankstesnio metodo trūkumus. Kadangi paprastai, jei pervadinate knygą ne per KOReader (naudodami įrenginio vietinę failų tvarkyklę/skaityklę ar iš prijungto kompiuterio), jos .sdr aplanko pavadinimas nebeatitiks, ir tos knygos metaduomenys bus prarasti. Jei failų operacijoms naudojate tik KOReader failų naršyklę, tai automatiškai tvarkoma, todėl pasekmių nėra.

Šiuo MAIŠOS (HASH) metodu, .sdr aplankai identifikuojami ne pagal knygos failo kelią/pavadinimą. Vietoj to, knygoms su jų nustatymais susieti bus naudojama dalinė MD5 maišos suma. Ši maišos suma naudojama kaip unikalus knygos ID ir apskaičiuojama pagal knygos failo turinį. Taip pat ta pati maišos suma naudojama jos .sdr aplanko pavadinimui.

Privalumai

  • Knygos .sdr aplankai bus matomi ir naudojami tik KOReader. Jie neužkrauna bibliotekos katalogų vaizdo, kai naršote bibliotekos katalogus kita failų naršykle ar iš kompiuterio.
  • Knygas galite pervadinti, perkelti ir kopijuoti kita failų naršykle ar iš kompiuterio. KOReader vis tiek atpažins knygas po šių operacijų.
  • Šiuo metodu KOReader susieja tą patį .sdr aplanką su visomis knygos kopijomis, net jei šios kopijos yra skirtinguose įrenginiuose. Pavyzdžiui, jei naudojate Syncthing, šis metodas leidžia sinchronizuoti /hashdocsettings aplanką kartu su knygos failais keliuose įrenginiuose, kuriuose visuose įdiegtas KOReader. Nepaisant skirtingų šių knygų santykinių kelių kiekviename įrenginyje, vis tiek galėsite sinchronizuoti anotacijas ir pažangą tarp savo įrenginių. Su kitais metodais tai neįmanoma.

Trūkumai

  • Bet kokios operacijos, tiesiogiai modifikuojančios failą (pvz., paryškinimų įrašymas į PDF failus ar atsisiuntimas iš Calibre), pakeis failą, todėl jo MD5 ID pasikeis (skirtingai nei pervadinimas ar perkėlimas, kurie su šiuo metodu saugūs). Šiuo atveju KOReader negalės atpažinti knygos, todėl šios knygos praras savo metaduomenis.
  • Failų ID skaičiavimas gali sulėtinti Failų naršyklės navigaciją naršant didelius katalogus.

11.1 Quick Menu

Greitasis meniu yra neseniai atsiradusi KOReader funkcija, leidžianti turėti greitai pasiekiamą asmenišką meniu, kaip parodyta žemiau esančiame pavyzdiniame paveikslėlyje. Šį meniu galite priskirti gestui ir pasiekti jį vienu braukimu. Galite turėti net ilgesnį nei ekranas meniu, jis slenkamas.

Iš esmės bet kokį veiksmą, kuriam galite priskirti gestą, galima pridėti į Greitąjį meniu. Jo privalumai:

  1. Nereikia įsiminti daugybės gestų kiekvienam veiksmui.
  2. Kai kurie retai naudojami veiksmai gali neverti gesto, tačiau juos rasti meniu sistemoje gali būti per didelis vargas. Vietoj to tokius retai naudojamus veiksmus galite pridėti į šį meniu.
  3. Jei diegiate KOReader giminaičiui ar draugui, į šį meniu galite pridėti jų mėgstamiausius veiksmus, kad naudodamiesi KOReader jiems net nereikėtų eiti į meniu sistemą.

Pavyzdinis Greitasis meniu:

Yra du Greitojo meniu kūrimo metodai: Paprastas ir Pažangus. Jei reikia tik vieno meniu, Paprasto metodo turėtų pakakti. Jei norite rodyti skirtingus meniu su skirtingais gestais, turite naudoti Pažangų metodą. Kitas Pažangaus metodo privalumas - lengvesnis gesto perpriskyrimas. Jei norite pakeisti meniu gestą, naudodami Pažangaus metodo meniu galite lengvai jį perkelti prie kito gesto. Jei norite naudoti kitą gestą naudodami Paprastą metodą, turite iš naujo sukurti meniu prie naujo gesto.

Paprastas metodas
  1. Eikite į Gestų tvarkyklės meniu per:
    VIRŠUTINIS MENIU / / Palietimai ir gestai / Gestų tvarkyklė
  2. Nuspręskite, kuris gestas atvers meniu, ir palieskite jį.
  3. Gesto konfigūravimo meniu pasirinkite veiksmus, kuriuos norite matyti meniu. Žinoma, galite pasirinkti kelis veiksmus iš karto.
  4. Pasirinkę visus veiksmus, nurodysite KOReader traktuoti šį gestą kaip meniu. Tai atliekama antrame puslapyje įjungiant elementą Rodyti kaip Greitąjį meniu, kaip matote žemiau esančiame paveikslėlyje.
  5. You can sort your menu items with the Arrange actions and QuickMenu separators option from the same menu.

Dabar meniu galite paleisti pasirinktu gestu. Jei norite pakeisti meniu elementus, galite atverti gesto puslapį ir pridėti/pašalinti elementus.

Pažangus metodas
 As we said above, if you are not planning to add more than one Quick Menu you don’t need this section.

Šis Greitasis meniu iš tikrųjų yra Profilis, kuris ekrane rodomas kaip meniu. Todėl pirmiausia turite sužinoti apie Profilius. Jei jau žinote, kaip juos naudoti, galite skaityti toliau, priešingu atveju pereikite prie antraštės Profiliai (kitas skyrius), sukurkite Profilį su keliais elementais ir grįžkite čia.

Prieš tęsdami, darome prielaidą, kad jau sukūrėte Profilį, kaip nurodyta ankstesnėje pastraipoje. Dabar paversime savo Profilį į Greitąjį meniu.

1. Eikite į naujai sukurtą Profilį ir įjunkite Rodyti veiksmų sąraše (parodyta žemiau esančiame paveikslėlyje). Tai padarys jūsų Profilį matomą Gestų tvarkyklėje. Taip pat įjunkite Rodyti kaip Greitąjį meniu (taip pat žemiau esančiame paveikslėlyje), kad profilis būtų rodomas kaip meniu, o ne tyliai vykdomas.

2. Dabar reikia būdo pasiekti meniu. Eikite į Gestų tvarkyklę ir iš sąrašo pasirinkite gestą, kurį priskirsime meniu. Tarkime, norime paliesti ekrano kampą, kad būtų parodytas meniu. Dabar palieskite Palietimas kampe, tada pasirinkite Apačioje kairėje. Dabar palieskite Bendra ir eikite į antrą puslapį. Rasite savo profilį kaip Profilis x, kur x yra pavadinimas, kurį suteikėte šiam Profiliui. Palieskite jo žymimąjį langelį, kad priskirtumėte profilį šiam gestui.

Atlikę visus žingsnius, dabar turėtumėte matyti meniu paliesdami apatinį kairįjį kampą. Meniu galite redaguoti eidami į jo Profilio puslapį, kur galite pridėti ar pašalinti elementus. Taip pat ten yra elementas Rūšiuoti, kad galėtumėte keisti meniu elementų tvarką.

Kaip sakėme, Greitasis meniu iš tikrųjų yra Profilis. Tai reiškia, kad galite turėti daugiau nei vieną meniu. Jei norite, galite sukurti kitą Profilį ir atlikti tuos pačius žingsnius, kad sukurtumėte kitą meniu.

Adding profiles as menu items to a Quick Menu

In addition to adding actions to your quick menu, you can also add your profiles as a menu item. This way, you can execute many actions at once with this single menu item.

We assume that you have a working quick menu and a profile, which you want to add to this menu. With these ready, follow these instructions:

  1. Go to the Settings of the profile that you want to use as the "menu item" and enable Show in action list. This will make your profile visible in the Gesture manager.
  2. Now you can add this profile to your quick menu as a regular action from the Gesture Manager. You can find this profile at the last page of General sub-menu of Gesture manager.

After adding your profile as a menu item, you can open your quick menu and tap on this item to execute all the actions in tes profile. You can also add a profile as a sub-menu which allows you to have a nested menu. This method is explained in the next heading.

Creating nested quick menus

You can also add a quick menu as a menu item to another quick menu. This will give you a nested menu structure. This is useful when you have many quick menus but you don't want to assign different gestures to each one.

  1. Go to the Settings of the profile that you want to use as the "child menu" and enable Show in action list. This will make your profile visible in the Gesture manager.
  2. Then enter the Edit actions menu in the same Settings of the child menu profile. Now enable the Show as QuickMenu option which is on the second page. This will tell KOReader to treat this profile as another menu which you can enter, instead of executing all its actions when you tap on it.
  3. Now you can add this profile to your parent quick menu like other actions in the Gesture manager. You can find your child menu profile under the General tab, last page.
 If you don't enable the Show as QuickMenu for the child menu in the second step above, you can still access its menu items with a long-press on the child menu's name in the parent menu. This will also give you an Execute all item at the top of the child menu.

  • Pridėkite savo komiksus į rinkinį, kuris gali suaktyvinti profilį, sumažinantį ekrano atnaujinimo intervalą iki kiekvieno puslapio, kad išvengtumėte šešėliavimo.
  • Suaktyvinkite profilį, koreguojantį šriftą, dydį ir nustatantį dviejų stulpelių režimą, kai failas pirmą kartą atveriamas iš aplanko Periodiniai leidiniai.
  • Pridėkite savo problemiškus PDF failus į rinkinį, todėl juos atverdami Automatinis OCR ar Pertvarkymo režimas suaktyvinamas profiliu.
  • Pakeiskite failų naršyklės rodymo režimą (viršeliai, detalus sąrašas ir t. t.), kai įeinate į tam tikrus aplankus.
  • Išjunkite skaitymo statistiką atverdami knygą iš rinkinio Žinynai. Vėl įjunkite statistiką uždarydami knygą.
  • If you expose the style tweaks in the gesture manager, you can create a profile to enable or disable them based on certain conditions. For example you can trigger a "disable publisher styles AND apply my user style tweaks" profile based on the book's location/collection or by a keyword in the metadata of the book. See the Style Tweaks section of the guide for more info.
Execute profile actions one by one

Normally when you execute a profile, all of the actions in the profile are executed following the order that you have chosen in the Arrange actions menu.

But you also have the option to execute them one by one. Which means, each time you invoke this profile, only one of the actions (next one) will be executed instead of all of them.

Here is a useful example:

  1. Create a profile with these actions
    • Go to pinned page
    • Grįžti į ankstesnę vietą
  2. Assign it to an easy gesture like Tap bottom right corner
  3. Enable Execute one by one option from the profile's Edit actions menu

Now each time you tap the right corner, you will switch between your pinned page and your reading position. This can be useful for quickly jumping to references section and going back, for example.

Profile troubleshooting

Profiles are auto-executed with a tiny delay to avoid interference with other operations/events of KOReader. But in some cases like closing a document, profile has to be executed instantly to be able to perform its actions.

You can enable this instant execution option from:

TOP MENU / / Profiles / "Your profile name" / Auto-execute / Execute promptly

When you enable this option, for example on a profile with the trigger on book closing, your profile will be executed before the document is closed. This running order is necessary for proper execution in this case.

Whenever you enable Auto-execute for a profile, we suggest enabling this Execute promptly option too. If you observe that your profile is not working correctly, then you can try disabling this option.

 This setting may also cause (unknown) issues, because the number of action combinations in a profile is almost infinite and we don't know how they might interact. This is why it doesn't come enabled by default.

13 READING IMPROVEMENTS

In this section we will first explain two KOreader plugins that might improve your reading speed. Then we will list some fonts that can improve your reading speed and comprehension.

13.1 Plugins for Faster Reading
1. Perception Expander plugin

When you enable, this plugin adds two vertical lines to the reading area, near the left and right edges as you can see in the image below. These lines serve as the start/end markers for your eyes, when reading a line from your book. Working principle of this plugin is based on the fact that, you don't really need to look at the first and last words of a line directly, because with some practice you can perceive them with your peripheral vision.

  • Vertical gray lines: Perception expander indicators
  • Red line: Your eyes following the text normally
  • Blue line: Your eyes jumping between the indicators (shorter distance)

To use this plugin, you have to first enable it by going to:

TOP MENU / / More tools / Plugin management / Perception expander

After enabling the plugin, you will have a new menu item here:

TOP MENU / / Speed reading module - perception expander

You can toggle the expander lines from this menu and also configure the indicators according to your liking and peripheral vision skill level. You can watch the Tim Ferriss video that inspired this plugin here.

2. FastReader Plugin

This plugin is a RSVP (Rapid Serial Visual Presentation) reader. This technique is based on flashing the word(s) at the center of the screen quickly. Your eyes don't need to move when reading like this so the reading speed can be faster. And if you improve the skill, you can perceive more than one word at once, which further increases the reading speed.

To use this plugin, you have to first enable it by going to:

TOP MENU / / More tools / Plugin management / FastReader

After enabling the plugin, you will have a new menu item here:

TOP MENU / / More tools / FastReader

You can start the plugin from this menu and also configure the settings like:

  • RSVP speed - Flashing speed in WPM (words per minute)
  • Preview words - How many words to show at once

You can start using the plugin in single word and low WPM (slower) mode and increase them as you get better.

13.2 Special Fonts

In this section we will show you some fonts that might improve your reading experience. These fonts are not an exclusive feature of KOReader, but we are including them here because sometimes our users ask about them in our issues and discussions.

You can install these fonts like any other font. If you don't know how to add fonts to your device, we explain it in Using Your Own Fonts section.

Overview of fonts in this section (note that all the fonts in this image have the same size - 11 pt - but very different widths, line heights and readability):

Atkinson Hyperlegible

Designed by Braille Institute, this font family aims to improve legibility and readability for individuals with low vision. It has clear, highly distinctive letters and numbers. You can see the font and download it from here


B612

B612 is a highly legible font family, designed to be used on Airbus aircraft cockpit screens. Its legible design makes it particularly suitable for degraded contexts and aims reducing visual fatigue and cognitive load. These design principles makes it a suitable font for e-readers too. You can see the font and download it from Google Fonts


Lexend

This font's design is based on the principles derived from educational studies that aim to improve reading performance of students. You can read about the font here and download it from Google Fonts


Luciole

This font adheres to a dozen specific design criteria to provide the best possible reading experience for the visually impaired. It emphasizes the "inner" space of letters and has extremely clear, distinct numbers and mathematical symbols. You can see the font and download it from here


Open Dyslexic

This font is designed to increase readability for readers with dyslexia. Letters have heavy weighted bottoms to emphasize direction. The unique shapes of each letter can prevent confusion through flipping and swapping. You can download it from here


Shantell Sans

This font is designed by a dyslexic author as a legible, accessible, and easy to read typeface. It also works nicely for small text thanks to its wider letters and relaxed spacing. You can download it from Google Fonts


Fast Font

This is a special font that substitutes the first few letters of a word with their bold variant (number of letters is calculated according to the word length). This bold letters then act as artificial fixation points for the eye to jump on as you can see in this sentence. In theory this might increase the reading speed but of course personal results may vary. Interestingly, readers with ADHD generally report benefits.

This font depends on special OpenType features which are supported by KOReader. So you can just download the font, copy it to your device and use it like any other font. You can see the examples and download this font and its variations (serif, monospace and dotted) from its GitHub repo

Reading vertically formatted books

Currently official KOReader doesn't support rendering books formatted as vertical text (tategaki - 縦書き) but one of our users has created a fork that can do this. It is basically a clone of KOReader with added vertical text rendering.

Japanese vertical writing is the main target of this fork. But since the implementation supports EPUB writing-mode: vertical-rl at the rendering engine level, it may also work for other vertical writing languages. It can at least render Chinese too, according to the feedback from Chinese users.

Be aware that this is a fork (not a plugin or a user patch), so it completely replaces your KOReader. But ordinary horizontal books behave much like they do in the official KOReader, so this replacement should be functionally equivalent.

You can switch to this fork without first uninstalling your current KOReader. Just follow the instructions in the fork's repo. Development discussion on our repo is here.

Battery drain problems

KOReader uses battery very efficiently. So if your e-reader device's battery started draining abnormally when using KOReader, generally first suspect is the battery degradation.

But if you are sure that your battery is healthy and drain happens only in KOReader, cause might be:

  • A problematic firmware update
  • A third-party plugin
  • A user patch

These are the steps to follow if you have a drain problem:

  1. Update your device to the latest firmware version. If there are no firmware updates for your device, skip to the next step.
  2. If updating your firmware doesn't solve the drain problem, remove all of the third party plugins and user patches that you have installed and restart KOReader.
  3. If the drain problem continues after the first two steps, the last option is factory resetting your device and reinstalling KOReader (don't forget to backup your main library folder).

If your problem continues, you can open an issue on our GitHub page.

Resetting KOReader on Android devices

On Android OS devices, KOReader keeps its settings under the Internal Storage/koreader/ directory. This is an intentional behavior which is different from other Android applications. This location allows you to backup and synchronize your KOReader settings easily by saving them under this user-accessible directory.

But when you uninstall KOReader or clear its data from the Android OS Settings menu, this KOReader settings directory is not removed. So if you uninstall KOReader and then install it again, it will start with your old settings.

If you want to completely reset KOReader to its factory defaults, you should delete this directory manually. When you start KOReader after deleting this directory, it will be automatically re-created with the default settings.

This is technically possible, but unfortunately we can't change the default sleep screen behavior on these readers. Because this might trigger a negative reaction from Amazon, which might lock down the Kindle ecosystem (no more KOReader for Kindles) or even endanger the whole project (no more KOReader). For further info, you can check this discussion with our developers here. Our stance is in line with the MobileRead forums' stance which you can read here.

What is a Nightly Version?

KOReader turi dvi skirtingas versijas:

  • STABILI Ši versija yra pagrindinė, kurią rasite projekto GitHub Releases puslapyje. Ji pavadinta taip: „KOReader 2024.11“, tai reiškia, kad ši konkreti versija išleista 2024 m. lapkritį. Paprastai tai mėnesinis leidimas, bet kartais gali užtrukti ilgiau.
  • NAKTINĖ (NIGHTLY) Šios versijos yra kasdien kompiliuojamos KOReader versijos su nuolat pridedamais optimizavimais ir pataisymais. Naktinės versijos skirtos siauram testuotojų ir kūrėjų ratui, todėl jos gali būti mažiau stabilios.

Paprastai, jei esate eilinis naudotojas, turėtumėte naudoti stabilią versiją. Bet kai kuriais konkrečiais atvejais gali prireikti naktinės versijos:

  • Jūsų įrenginys labai naujas (pavyzdžiui, neseniai išleistas Kobo modelis), ir KOReader palaikymas ką tik pridėtas naujausioje naktinėje versijoje.
  • Yra jūsų įrenginiui specifinė klaida ar problema, kuri jau ištaisyta, bet dar neišleista. Ir nenorite laukti stabilios versijos, kad gautumėte šį pataisymą.
  • Atnaujinę KOReader, pastebite, kad funkcija, kurią naudojote, pašalinta. Nenorite prarasti šios funkcijos, todėl galite įdiegti naktinę versiją, kurioje ji vis dar yra. Žinoma, taip pat galite grįžti prie ankstesnio stabilaus leidimo, bet naktinė versija būtų naujesnė, todėl gali turėti daugiau funkcijų ir pataisymų.

Šis skyrius buvo tik bendras įvadas į temą. Išsamios informacijos ir pagalbos dėl naktinių versijų ieškokite diskusijų puslapyje: DUK: kaip sekti naujausius naktinius leidimus

 If you are using KOReader on an Android device, you can use the Work Profile feature of the Android OS to test the Nightly versions without affecting your main KOReader installation. Open source applications like Shelter and Island can help you with this.
